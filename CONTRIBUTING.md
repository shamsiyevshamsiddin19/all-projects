# 🤝 Loyihaga Hissa Qo'shish (Contributing Guidelines)

Loyiha ochiq va barcha takliflar, tuzatishlar (pull requestlar) mamnuniyat bilan qabul qilinadi.

### 📋 Asosiy qoidalar:
1. Ish boshlashdan oldin yangi alohida branch oching (`feat/yangi-imkoniyat` yoki `fix/muammo`).
2. Kod yozing va testlar mavjud bo'lsa, ularni to'liq tekshirib chiqing.
3. Conventional commit formatida aniq sarlavha bilan commit qiling.
4. Pull Request yuboring va tavsifida nima o'zgarganini qisqacha ko'rsating.
