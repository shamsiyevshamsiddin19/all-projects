# Xatolarni boshqarish, fayl yuklash va formalar

## Bu darsda nimalarni o'rganasiz

- `HTTPException` orqali aniq, mantiqiy xato xabarlarini qaytarishni o'rganasiz
- Maxsus (custom) exception handler yozishni bilasiz
- Fayl yuklashni (`UploadFile`) va HTML formalarini (`Form`) qabul qilishni o'rganasiz
- Header va cookie'lar bilan ishlashni tushunasiz

## Nazariy qism

### `HTTPException` — biznes mantiqiy xatolarni qaytarish

1-2-bobda ko'rilgan avtomatik validatsiya (`422` xatosi) — faqat **ma'lumot shakli** (tur, uzunlik) noto'g'ri bo'lganda ishlaydi. Lekin ko'p hollarda, xato **biznes mantiqiga** bog'liq bo'ladi: masalan, "so'ralgan ID bilan mahsulot topilmadi". Bunday holatlar uchun `HTTPException` ishlatiladi:

```python
from fastapi import FastAPI, HTTPException, status

app = FastAPI()

MAHSULOTLAR = {1: {"nomi": "Noutbuk"}, 2: {"nomi": "Sichqoncha"}}

@app.get("/mahsulotlar/{mahsulot_id}")
def mahsulot_olish(mahsulot_id: int):
    if mahsulot_id not in MAHSULOTLAR:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,
            detail=f"ID={mahsulot_id} bilan mahsulot topilmadi",
        )
    return MAHSULOTLAR[mahsulot_id]
```

`raise HTTPException(...)` chaqirilganda, FastAPI darhol so'rovni to'xtatadi va mos status kod bilan, `detail` matnini o'z ichiga olgan JSON javobini qaytaradi:

```json
{"detail": "ID=99 bilan mahsulot topilmadi"}
```

### Keng tarqalgan HTTP status kodlar — xatolar uchun

| Status kod | Nomi | Qачон ishlatiladi |
|---|---|---|
| `400` | Bad Request | Umumiy, noto'g'ri so'rov (aniqroq kod topilmasa) |
| `401` | Unauthorized | Autentifikatsiya talab qilinadi, lekin taqdim etilmagan (5-bobda ko'riladi) |
| `403` | Forbidden | Autentifikatsiya bor, lekin ruxsat yetarli emas |
| `404` | Not Found | So'ralgan resurs mavjud emas |
| `409` | Conflict | So'rov, resursning joriy holati bilan ziddiyatda (masalan, allaqachon mavjud email) |
| `422` | Unprocessable Entity | Ma'lumot shakli noto'g'ri (avtomatik, Pydantic orqali) |
| `500` | Internal Server Error | Kutilmagan server xatosi |

```python
@app.post("/foydalanuvchilar")
def foydalanuvchi_yaratish(email: str):
    if email in MAVJUD_EMAILLAR:
        raise HTTPException(
            status_code=status.HTTP_409_CONFLICT,
            detail="Bu email allaqachon ro'yxatdan o'tgan",
        )
    return {"xabar": "Yaratildi"}
```

### `HTTPException`ga qo'shimcha header qo'shish

```python
raise HTTPException(
    status_code=status.HTTP_401_UNAUTHORIZED,
    detail="Autentifikatsiya talab qilinadi",
    headers={"WWW-Authenticate": "Bearer"},
)
```

### Maxsus exception va global handler

Katta loyihalarda, o'z maxsus exception klasslaringizni yaratib, ularni **markazlashtirilgan** tarzda boshqarish qulayroq:

```python
from fastapi import FastAPI, Request
from fastapi.responses import JSONResponse

class MahsulotTopilmadiXatosi(Exception):
    def __init__(self, mahsulot_id: int):
        self.mahsulot_id = mahsulot_id

app = FastAPI()

@app.exception_handler(MahsulotTopilmadiXatosi)
def mahsulot_xatosi_handler(request: Request, exc: MahsulotTopilmadiXatosi):
    return JSONResponse(
        status_code=404,
        content={"xato": f"Mahsulot (ID={exc.mahsulot_id}) topilmadi", "yol": str(request.url)},
    )

@app.get("/mahsulotlar/{mahsulot_id}")
def mahsulot_olish(mahsulot_id: int):
    if mahsulot_id not in MAHSULOTLAR:
        raise MahsulotTopilmadiXatosi(mahsulot_id)
    return MAHSULOTLAR[mahsulot_id]
```

Bu naqsh — xato xabarlarini bitta joyda, izchil formatda boshqarish imkonini beradi, ayniqsa loyiha kattalashgan sari foydali (3-bobda ko'riladigan katta loyiha strukturasi bilan birga qo'llaniladi).

### Fayl yuklash — `UploadFile`

FastAPI — `UploadFile` turi orqali, fayl yuklashni tabiiy qo'llab-quvvatlaydi:

```python
from fastapi import FastAPI, UploadFile

app = FastAPI()

@app.post("/rasm-yuklash")
async def rasm_yuklash(fayl: UploadFile):
    mazmun = await fayl.read()
    return {
        "fayl_nomi": fayl.filename,
        "fayl_turi": fayl.content_type,
        "hajmi_baytda": len(mazmun),
    }
```

| `UploadFile` atributi/metodi | Vazifasi |
|---|---|
| `.filename` | Yuklangan faylning asl nomi |
| `.content_type` | MIME turi (masalan, `image/png`) |
| `await .read()` | Faylning to'liq mazmunini o'qish (asinxron) |
| `await .write(data)` | Faylga yozish |
| `await .seek(0)` | Fayl ko'rsatkichini boshiga qaytarish |

> 📌 **`UploadFile` vs `bytes`:** FastAPI, kichik fayllar uchun `fayl: bytes` turini ham qo'llab-quvvatlaydi (butun fayl xotiraga yuklanadi), lekin `UploadFile` — katta fayllar uchun tavsiya etiladi, chunki u faylni **oqim (stream)** sifatida, xotirani tejab ishlaydi.

### Bir nechta fayl yuklash

```python
@app.post("/kop-fayl-yuklash")
async def kop_fayl(fayllar: list[UploadFile]):
    natijalar = []
    for fayl in fayllar:
        mazmun = await fayl.read()
        natijalar.append({"nomi": fayl.filename, "hajmi": len(mazmun)})
    return {"yuklangan_fayllar": natijalar}
```

### HTML formalar — `Form`

Agar ma'lumot JSON emas, balki an'anaviy HTML forma (`application/x-www-form-urlencoded` yoki `multipart/form-data`) orqali kelsa, `Form()` ishlatiladi (bu — `python-multipart` paketini talab qiladi, u `fastapi[standard]` bilan avtomatik o'rnatiladi):

```python
from typing import Annotated
from fastapi import Form

@app.post("/kirish")
def tizimga_kirish(
    foydalanuvchi_nomi: Annotated[str, Form()],
    parol: Annotated[str, Form()],
):
    return {"xabar": f"{foydalanuvchi_nomi} tizimga kirdi"}
```

> ⚠️ **Muhim cheklov:** bitta endpoint'da, **yoki** `Form()` parametrlari, **yoki** JSON request body (Pydantic modeli) ishlatilishi mumkin — ikkalasini birga bitta endpoint'da ishlatib bo'lmaydi (bu, HTTP `Content-Type` header'ining o'zi bitta formatni belgilashi bilan bog'liq).

### Forma va fayl birgalikda

```python
@app.post("/profil-yangilash")
async def profil_yangilash(
    ism: Annotated[str, Form()],
    rasm: UploadFile,
):
    mazmun = await rasm.read()
    return {"ism": ism, "rasm_hajmi": len(mazmun)}
```

### Header va Cookie'lar bilan ishlash

```python
from typing import Annotated
from fastapi import Header, Cookie

@app.get("/malumot")
def malumot_olish(
    foydalanuvchi_agent: Annotated[str | None, Header()] = None,
    sessiya_id: Annotated[str | None, Cookie()] = None,
):
    return {"user_agent": foydalanuvchi_agent, "sessiya": sessiya_id}
```

> 📌 **Avtomatik nom o'girish:** FastAPI, Python o'zgaruvchi nomlaridagi pastki chiziqni (`_`), HTTP header konvensiyasiga mos ravishda, avtomatik defis (`-`)ga o'giradi (`foydalanuvchi_agent` → `User-Agent` header'ini qidiradi).

## Amaliy misol

To'liq, xatolarni boshqarish va fayl yuklashni birlashtiruvchi amaliy misol:

```python
from typing import Annotated
from fastapi import FastAPI, HTTPException, UploadFile, Form, status

app = FastAPI()

RUXSAT_ETILGAN_TURLAR = {"image/png", "image/jpeg", "image/webp"}
MAX_HAJM_BAYT = 5 * 1024 * 1024  # 5 MB

@app.post("/mahsulotlar/{mahsulot_id}/rasm")
async def mahsulot_rasmi_yuklash(mahsulot_id: int, rasm: UploadFile):
    if mahsulot_id not in {1, 2, 3}:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,
            detail=f"ID={mahsulot_id} bilan mahsulot topilmadi",
        )

    if rasm.content_type not in RUXSAT_ETILGAN_TURLAR:
        raise HTTPException(
            status_code=status.HTTP_400_BAD_REQUEST,
            detail=f"Faqat {', '.join(RUXSAT_ETILGAN_TURLAR)} formatlariga ruxsat berilgan",
        )

    mazmun = await rasm.read()
    if len(mazmun) > MAX_HAJM_BAYT:
        raise HTTPException(
            status_code=status.HTTP_400_BAD_REQUEST,
            detail="Rasm hajmi 5 MB dan oshmasligi kerak",
        )

    # (haqiqiy loyihada, bu yerda fayl diskka yoki bulutga saqlanadi)
    return {
        "xabar": "Rasm muvaffaqiyatli yuklandi",
        "mahsulot_id": mahsulot_id,
        "fayl_nomi": rasm.filename,
        "hajmi_kb": round(len(mazmun) / 1024, 2),
    }
```

Sinash:

```bash
curl -X POST http://127.0.0.1:8000/mahsulotlar/1/rasm \
  -F "rasm=@/uy/rasmlar/mahsulot.png"
```

## Keng tarqalgan xatolar

**Xato 1:** har qanday xato uchun umumiy `400` status kodini ishlatish, muayyan holatga mos aniqroq kod (`404`, `409`, `403`) tanlamaslik.
❌ Bu — API'dan foydalanuvchi (masalan, frontend dasturchi) uchun, xatoning aniq tabiatini (resurs topilmadimi, ziddiyatmi, ruxsat yo'qmi) dasturiy tarzda ajratishni qiyinlashtiradi.
✅ To'g'ri: har doim vaziyatga eng mos status kodni tanlang — bu, API'ning REST konvensiyalariga rioya qilishini va undan foydalanishni osonlashtiradi.

**Xato 2:** katta fayllarni `bytes` turi orqali qabul qilish, natijada server xotirasi keraksiz to'lib ketishi.
❌ `fayl: bytes` — butun faylni, hajmidan qat'i nazar, to'liq xotiraga yuklaydi; katta fayllar (video, katta rasmlar) uchun bu — server resurslarini samarasiz ishlatishga olib keladi.
✅ To'g'ri: fayllar (ayniqsa hajmi noma'lum yoki katta bo'lishi mumkin bo'lganlar) uchun har doim `UploadFile` ishlating — u oqim asosida ishlaydi va xotirani samaraliroq boshqaradi.

**Xato 3:** bitta endpoint'da, Pydantic modeli (JSON body) va `Form()` parametrlarini birga ishlatishga urinish.
❌ Bu — FastAPI tomonidan qo'llab-quvvatlanmaydi va ishga tushirish vaqtida xatoga olib keladi, chunki HTTP so'rovining `Content-Type`i faqat bitta formatni (yoki JSON, yoki forma) belgilashi mumkin.
✅ To'g'ri: agar forma va fayl birga kerak bo'lsa, `Form()` parametrlarini `UploadFile` bilan birga ishlating (ikkalasi ham `multipart/form-data`ga mos keladi); agar sof JSON kerak bo'lsa, Pydantic modelidan foydalaning — ikkisini aralashtirmang.

## Mashq/topshiriq

**(Oson)** `/kitoblar/{kitob_id}` endpoint'ida, agar `kitob_id` oldindan belgilangan ro'yxatda (masalan, `{1, 2, 3}`) bo'lmasa, `404` xatosini, tushunarli `detail` matni bilan qaytaring.

**(O'rtacha)** `/hujjat-yuklash` endpoint'ini yozing, u `UploadFile` qabul qilsin va fayl kengaytmasi `.pdf` bo'lmasa, `400` xatosini qaytarsin (`fayl.filename.endswith(".pdf")` orqali tekshiring).

**(Qiyin)** `RuxsatYoqXatosi` nomli maxsus (custom) exception klassini yarating (`__init__`da `sabab: str` qabul qiluvchi), va uni `@app.exception_handler()` orqali global handler bilan bog'lang — handler `403` status kod va `{"xato": sabab}` formatidagi JSON qaytarsin. Keyin, bitta endpoint yozing, unda muayyan shart bajarilmasa (masalan, `role != "admin"`), shu maxsus xatoni "raise" qiling.

## Qisqacha xulosa

`HTTPException` — biznes mantiqiy xatolarni (resurs topilmadi, ziddiyat, ruxsat yo'q), mos HTTP status kod va tushunarli `detail` xabari bilan qaytarish uchun asosiy vosita; katta loyihalarda, `@app.exception_handler()` orqali maxsus exception klasslar uchun markazlashtirilgan handler'lar yozish tavsiya etiladi. Fayl yuklash — `UploadFile` (katta fayllar uchun samarali, oqim asosidagi) turi orqali, HTML formalar esa `Form()` orqali qabul qilinadi (ikkalasi bir endpoint'da JSON body bilan aralashtirilmaydi); `Header()` va `Cookie()` esa, mos HTTP header/cookie qiymatlarini, avtomatik nom o'girish bilan, funksiya parametri sifatida olish imkonini beradi. Keyingi bobda, loyiha kattalashganda kodni qanday tashkil etish (`APIRouter`) va Dependency Injection mexanizmini o'rganamiz.
