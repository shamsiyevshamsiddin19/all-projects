# OAuth2, parol xeshlash va JWT token

## Bu darsda nimalarni o'rganasiz

- Autentifikatsiya va avtorizatsiya orasidagi farqni tushunasiz
- Parollarni xavfsiz saqlash (`pwdlib` orqali xeshlash) usulini o'rganasiz
- JWT (JSON Web Token) nima ekanini va uni `PyJWT` bilan yaratish/tekshirishni bilasiz
- FastAPI'ning `OAuth2PasswordBearer` orqali to'liq kirish tizimini quramiz

## Nazariy qism

### Autentifikatsiya vs Avtorizatsiya

| Tushuncha | Savol | Misol |
|---|---|---|
| **Autentifikatsiya** (Authentication) | "Siz kimsiz?" | Login va parol orqali tizimga kirish |
| **Avtorizatsiya** (Authorization) | "Sizga bu amalni bajarishga ruxsat bormi?" | Faqat "admin" roli — foydalanuvchini o'chira oladi |

Ushbu darsda autentifikatsiyaga, 5.2-darsda esa avtorizatsiyaga e'tibor qaratamiz.

### Parollarni hech qachon ochiq matnda saqlamang

Foydalanuvchi paroli — ma'lumotlar bazasida **hech qachon** ochiq matn (`"parol123"`) ko'rinishida saqlanmasligi kerak. Buning o'rniga, parol — **xeshlanadi** (bir tomonlama, qaytarib bo'lmaydigan matematik funksiya orqali o'zgartiriladi):

```python
parol = "mening_parolim123"
xesh = "$argon2id$v=19$m=65536,t=3,p=4$..."  # xesh - asl paroldan qaytarib bo'lmaydi
```

Foydalanuvchi keyinroq tizimga kirmoqchi bo'lganda, u kiritgan parol **qayta xeshlanadi** va bazadagi xesh bilan solishtiriladi — asl parolning o'zi hech qachon saqlanmaydi yoki solishtirilmaydi.

### `pwdlib` — zamonaviy parol xeshlash kutubxonasi

> 📌 **Muhim yangilanish:** ilgari FastAPI'ning rasmiy hujjatlarida `passlib` kutubxonasi tavsiya etilar edi, lekin u endi faol qo'llab-quvvatlanmayapti. Hozirgi rasmiy tavsiya — **`pwdlib`** (Argon2 algoritmi bilan).

```bash
uv add "pwdlib[argon2]"
```

```python
from pwdlib import PasswordHash

parol_xeshi = PasswordHash.recommended()

# Xeshlash
xesh = parol_xeshi.hash("mening_parolim123")

# Tekshirish (login vaqtida)
togri_mi = parol_xeshi.verify("mening_parolim123", xesh)  # True
```

| Metod | Vazifasi |
|---|---|
| `PasswordHash.recommended()` | Joriy eng xavfsiz, tavsiya etilgan algoritmni (Argon2) tanlaydi |
| `.hash(parol)` | Parolni xeshlaydi (bazaga saqlash uchun) |
| `.verify(parol, xesh)` | Kiritilgan parol, saqlangan xeshga mos kelishini tekshiradi |

### JWT (JSON Web Token) nima

**JWT** — foydalanuvchi autentifikatsiyadan o'tgach, unga beriladigan, **raqamli imzolangan** token bo'lib, keyingi so'rovlarda, foydalanuvchi har safar login/parol yubormasdan, "kimligini isbotlash" uchun ishlatiladi.

JWT — uchta qismdan iborat (nuqta bilan ajratilgan): `header.payload.signature`

```
eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOiIxIiwiZXhwIjoxNzM1Njg5NjAwfQ.4f8a...
```

| Qism | Mazmuni |
|---|---|
| Header | Qaysi algoritm ishlatilgani (masalan, `HS256`) |
| Payload | Foydalanuvchi haqidagi ma'lumot (`user_id`, muddat — `exp`, va h.k.) — **shifrlanmagan**, faqat kodlangan |
| Signature | Serverning **maxfiy kaliti** bilan yaratilgan raqamli imzo — bu, tokenni **qalbakilashtirish imkonsiz** qiladi |

> ⚠️ **Muhim tushuncha:** JWT payload'i — **shifrlanmagan** (istalgan kishi uni dekodlab, mazmunini o'qiy oladi, masalan [jwt.io](https://jwt.io) saytida). Faqat **imzo** — uni o'zgartirib bo'lmasligini kafolatlaydi. Shuning uchun, JWT ichiga **hech qachon** parol yoki boshqa maxfiy ma'lumot solinmasligi kerak — faqat `user_id` kabi, oshkor bo'lishi muammo bo'lmagan ma'lumotlar.

### `PyJWT` — zamonaviy JWT kutubxonasi

> 📌 **Muhim yangilanish:** ilgari `python-jose` tavsiya etilar edi, lekin u kam qo'llab-quvvatlanadi. Hozirgi rasmiy tavsiya — **`PyJWT`**.

```bash
uv add pyjwt
```

```python
import jwt
from datetime import datetime, timedelta, timezone

MAXFIY_KALIT = "juda-maxfiy-kalit-ozgartiring"  # .env orqali saqlanishi shart!
ALGORITM = "HS256"

def token_yaratish(malumot: dict, amal_qilish_vaqti: timedelta) -> str:
    nusxa = malumot.copy()
    tugash_vaqti = datetime.now(timezone.utc) + amal_qilish_vaqti
    nusxa.update({"exp": tugash_vaqti})
    return jwt.encode(nusxa, MAXFIY_KALIT, algorithm=ALGORITM)

def token_dekodlash(token: str) -> dict:
    return jwt.decode(token, MAXFIY_KALIT, algorithms=[ALGORITM])
```

> ⚠️ **`MAXFIY_KALIT` xavfsizligi:** 4.1-darsda ko'rilgan `.env` tamoyili, bu yerda **hayotiy muhim**: agar maxfiy kalit oshkor bo'lsa, istalgan kishi, o'zi uchun soxta, "haqiqiy" JWT tokenlarni yarata oladi. Kalit — kamida 32 belgidan iborat, tasodifiy generatsiya qilingan matn bo'lishi va **hech qachon** kodga to'g'ridan-to'g'ri yozilmasligi kerak.

### `OAuth2PasswordBearer` — FastAPI'ning tayyor mexanizmi

FastAPI, login/parol asosidagi autentifikatsiya oqimini soddalashtiruvchi tayyor vositani taqdim etadi:

```python
from fastapi.security import OAuth2PasswordBearer

oauth2_schema = OAuth2PasswordBearer(tokenUrl="token")
```

Bu — `/docs` sahifasida (1.1-darsda ko'rilgan Swagger UI), avtomatik "Authorize" tugmasini paydo qiladi, orqali login/parol kiritib, keyingi barcha so'rovlarga token avtomatik qo'shiladi — bu, qo'lda `curl -H "Authorization: Bearer ..."` yozishdan ko'ra, ancha qulayroq sinov tajribasini beradi.

### To'liq kirish (login) endpoint'i

```python
from datetime import timedelta
from typing import Annotated
from fastapi import APIRouter, Depends, HTTPException, status
from fastapi.security import OAuth2PasswordRequestForm

router = APIRouter(tags=["Autentifikatsiya"])

@router.post("/token")
def kirish(shakl: Annotated[OAuth2PasswordRequestForm, Depends()]):
    foydalanuvchi = foydalanuvchini_bazadan_topish(shakl.username)

    if not foydalanuvchi or not parol_xeshi.verify(shakl.password, foydalanuvchi.parol_xeshi):
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Login yoki parol noto'g'ri",
            headers={"WWW-Authenticate": "Bearer"},
        )

    token = token_yaratish(
        malumot={"sub": str(foydalanuvchi.id)},
        amal_qilish_vaqti=timedelta(minutes=30),
    )
    return {"access_token": token, "token_type": "bearer"}
```

> 📌 **`OAuth2PasswordRequestForm` — nima uchun `Form()` ishlatiladi:** 2.2-darsda ko'rilganidek, bu — OAuth2 standartining o'zi, login/parolni JSON emas, balki forma (`Form`) ko'rinishida yuborishni talab qiladi; FastAPI buni, standart OAuth2 oqimiga mos, tayyor holda taqdim etadi.

### Joriy foydalanuvchini token orqali olish (Dependency zanjiri)

3.2-darsda ko'rilgan dependency zanjirlash naqshi, bu yerda o'zining eng muhim amaliy qo'llanilishini topadi:

```python
from fastapi import Depends, HTTPException, status

def joriy_foydalanuvchini_olish(
    token: Annotated[str, Depends(oauth2_schema)],
) -> "Foydalanuvchi":
    xato = HTTPException(
        status_code=status.HTTP_401_UNAUTHORIZED,
        detail="Yaroqsiz autentifikatsiya ma'lumotlari",
        headers={"WWW-Authenticate": "Bearer"},
    )
    try:
        malumot = token_dekodlash(token)
        foydalanuvchi_id = malumot.get("sub")
        if foydalanuvchi_id is None:
            raise xato
    except jwt.InvalidTokenError:
        raise xato

    foydalanuvchi = foydalanuvchini_bazadan_topish_id_orqali(int(foydalanuvchi_id))
    if foydalanuvchi is None:
        raise xato
    return foydalanuvchi
```

Endi, **istalgan** himoyalangan endpoint, shunchaki shu dependency'ga bog'lanadi:

```python
@router.get("/profil")
def mening_profilim(
    foydalanuvchi: Annotated["Foydalanuvchi", Depends(joriy_foydalanuvchini_olish)],
):
    return {"ism": foydalanuvchi.ism, "email": foydalanuvchi.email}
```

## Amaliy misol

To'liq, ro'yxatdan o'tish va kirish tizimi:

```python
# app/security.py
from datetime import datetime, timedelta, timezone
import jwt
from pwdlib import PasswordHash
from app.config import sozlamalar

parol_xeshi = PasswordHash.recommended()

def parolni_xeshlash(parol: str) -> str:
    return parol_xeshi.hash(parol)

def parolni_tekshirish(parol: str, xesh: str) -> bool:
    return parol_xeshi.verify(parol, xesh)

def token_yaratish(foydalanuvchi_id: int) -> str:
    tugash = datetime.now(timezone.utc) + timedelta(minutes=30)
    return jwt.encode(
        {"sub": str(foydalanuvchi_id), "exp": tugash},
        sozlamalar.maxfiy_kalit,
        algorithm="HS256",
    )
```

```python
# app/routers/auth.py
from typing import Annotated
from fastapi import APIRouter, Depends, HTTPException, status
from fastapi.security import OAuth2PasswordRequestForm
from sqlmodel import Session, select

from app.database import session_olish
from app.models import Foydalanuvchi, FoydalanuvchiYaratish, FoydalanuvchiJavob
from app.security import parolni_xeshlash, parolni_tekshirish, token_yaratish

router = APIRouter(tags=["Autentifikatsiya"])

@router.post("/royxatdan-otish", response_model=FoydalanuvchiJavob, status_code=201)
def royxatdan_otish(
    malumot: FoydalanuvchiYaratish,
    session: Annotated[Session, Depends(session_olish)],
):
    mavjud = session.exec(select(Foydalanuvchi).where(Foydalanuvchi.email == malumot.email)).first()
    if mavjud:
        raise HTTPException(status.HTTP_409_CONFLICT, "Bu email allaqachon ro'yxatdan o'tgan")

    yangi_foydalanuvchi = Foydalanuvchi(
        ism=malumot.ism,
        email=malumot.email,
        parol_xeshi=parolni_xeshlash(malumot.parol),
    )
    session.add(yangi_foydalanuvchi)
    session.commit()
    session.refresh(yangi_foydalanuvchi)
    return yangi_foydalanuvchi

@router.post("/token")
def kirish(
    shakl: Annotated[OAuth2PasswordRequestForm, Depends()],
    session: Annotated[Session, Depends(session_olish)],
):
    foydalanuvchi = session.exec(
        select(Foydalanuvchi).where(Foydalanuvchi.email == shakl.username)
    ).first()

    if not foydalanuvchi or not parolni_tekshirish(shakl.password, foydalanuvchi.parol_xeshi):
        raise HTTPException(
            status.HTTP_401_UNAUTHORIZED,
            "Login yoki parol noto'g'ri",
            headers={"WWW-Authenticate": "Bearer"},
        )

    token = token_yaratish(foydalanuvchi.id)
    return {"access_token": token, "token_type": "bearer"}
```

Sinash:

```bash
curl -X POST http://127.0.0.1:8000/royxatdan-otish \
  -H "Content-Type: application/json" \
  -d '{"ism": "Shamsiddin", "email": "shams@example.com", "parol": "xavfsizParol123"}'

curl -X POST http://127.0.0.1:8000/token \
  -d "username=shams@example.com&password=xavfsizParol123"

# Token bilan himoyalangan endpoint'ga so'rov
curl http://127.0.0.1:8000/profil \
  -H "Authorization: Bearer <olingan_token>"
```

## Keng tarqalgan xatolar

**Xato 1:** parolni ochiq matn (yoki oddiy, kriptografik bo'lmagan usul, masalan MD5) bilan bazada saqlash.
❌ Agar ma'lumotlar bazasi biror sababdan (xakerlik, chiqindi) oshkor bo'lsa, barcha foydalanuvchilarning haqiqiy parollari darhol ma'lum bo'lib qoladi — bu, foydalanuvchilar boshqa saytlarda ham shu parolni ishlatgan bo'lsa, keng qamrovli zarar yetkazishi mumkin.
✅ To'g'ri: parolni har doim, `pwdlib` kabi zamonaviy, maxsus mo'ljallangan (Argon2 kabi) kutubxona orqali xeshlab saqlang — bu, hatto ma'lumotlar bazasi oshkor bo'lsa ham, asl parollarni tiklashni amaliy jihatdan imkonsiz qiladi.

**Xato 2:** JWT maxfiy kalitini (`MAXFIY_KALIT`), kodga to'g'ridan-to'g'ri yozib, uni Git'ga commit qilish.
❌ Bu — Git va GitHub darsligining 1.2-darsida ko'rilgan xavfsizlik xatosining, autentifikatsiya tizimidagi eng jiddiy ko'rinishi: agar kalit oshkor bo'lsa, tajovuzkor, istalgan foydalanuvchi nomidan (hatto "admin" nomidan ham) soxta, "haqiqiy" ko'rinadigan token yarata oladi.
✅ To'g'ri: maxfiy kalitni har doim `.env` orqali, tasodifiy generatsiya qilingan (masalan, `openssl rand -hex 32` buyrug'i bilan), kamida 32 belgili matn sifatida saqlang, va uni hech qachon kodga yoki Git'ga qo'shmang.

**Xato 3:** JWT tokenga, muddatni (`exp`) qo'shmasdan, "abadiy amal qiladigan" token yaratish.
❌ Agar token o'g'irlansa (masalan, brauzer tarixidan yoki tarmoq orqali), u **cheksiz muddatgacha** amal qilishda davom etadi, bu esa xavfsizlik xavfini sezilarli oshiradi.
✅ To'g'ri: har doim tokenga, oqilona muddat (`exp`, masalan 15-30 daqiqa) belgilang; uzoqroq "sessiya" kerak bo'lsa, alohida, uzoqroq muddatli "refresh token" mexanizmidan foydalaning (bu — ilg'or mavzu, ko'plab production tizimlarda qo'llaniladi).

## Mashq/topshiriq

**(Oson)** `pwdlib`dan foydalanib, bitta parolni xeshlang va uni `verify()` orqali, to'g'ri va noto'g'ri parol bilan tekshiring — natijalarni solishtiring.

**(O'rtacha)** `PyJWT` yordamida, `{"sub": "42", "rol": "admin"}` ma'lumotini, 10 daqiqalik amal qilish muddati bilan tokenga kodlang, so'ng uni dekodlab, ichidagi ma'lumotni qaytadan o'qing.

**(Qiyin)** To'liq `POST /royxatdan-otish` va `POST /token` endpoint'larini (yuqoridagi amaliy misoldagi kabi) yozing, va ularni sinab ko'ring: avval ro'yxatdan o'ting, so'ng noto'g'ri parol bilan kirishga urinib `401` xatosini oling, keyin to'g'ri parol bilan kirib, tokenni oling. Nima uchun `/token` endpoint'i, `POST /royxatdan-otish`dan farqli o'laroq, JSON emas, balki `Form` (`OAuth2PasswordRequestForm`) qabul qilishini tushuntirib bering.

## Qisqacha xulosa

Xavfsiz autentifikatsiya tizimi — parollarni hech qachon ochiq saqlamaslikdan (`pwdlib`, Argon2 orqali xeshlab) va foydalanuvchi holatini, har bir so'rovda qayta login talab qilmasdan, raqamli imzolangan **JWT token** (`PyJWT` orqali yaratilgan, `.env`da saqlangan maxfiy kalit bilan) orqali boshqarishdan iborat. FastAPI'ning `OAuth2PasswordBearer` va `OAuth2PasswordRequestForm` — bu jarayonni, standart OAuth2 oqimiga mos, `/docs` sahifasida ham qulay sinov imkoniyati bilan soddalashtiradi; 3.2-darsda ko'rilgan dependency zanjirlash naqshi esa, "token → dekodlash → joriy foydalanuvchi" bosqichlarini, istalgan himoyalangan endpoint'da qayta ishlatiladigan, yagona `Depends(joriy_foydalanuvchini_olish)` orqali ifodalash imkonini beradi. Keyingi darsda, foydalanuvchi rollariga (admin, oddiy foydalanuvchi) asoslangan ruxsatlarni qanday boshqarishni o'rganamiz.
