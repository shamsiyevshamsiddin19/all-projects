# Git'ni Ubuntu'ga o'rnatish va sozlash

## Bu darsda nimalarni o'rganasiz

- Git'ni Ubuntu'ga `apt` orqali o'rnata olasiz
- `git config` orqali ism, email va standart sozlamalarni belgilay olasiz
- Standart matn muharriri va standart branch nomini sozlay olasiz
- Sozlamalarning uch darajasini (`--system`, `--global`, `--local`) tushunasiz

## Nazariy qism

### Git'ni Ubuntu'ga o'rnatish

Ubuntu'da Git'ni o'rnatish — standart `apt` paket menejeri orqali juda oddiy:

```bash
sudo apt update
sudo apt install git -y
```

O'rnatishni tekshirish:

```bash
git --version
# git version 2.4x.x
```

> 📌 **Eng so'nggi versiyani xohlasangiz:** Ubuntu'ning standart repozitoriyasidagi Git versiyasi ba'zan biroz eskiroq bo'lishi mumkin (Docker darsligining 0.2-darsida ko'rgan xuddi shu muammo). Agar eng so'nggi Git funksiyalari kerak bo'lsa, rasmiy Git PPA'sini qo'shish mumkin:
```bash
sudo add-apt-repository ppa:git-core/ppa -y
sudo apt update
sudo apt install git -y
```
Ko'pchilik amaliy holatlar uchun esa standart `apt install git` yetarli.

### Birinchi sozlash — `git config` orqali shaxsiy ma'lumot

Git o'rnatilgach, u sizning **kim ekaningizni** bilishi kerak — chunki har bir commit "muallif" ma'lumotini o'z ichiga oladi:

```bash
git config --global user.name "Shamsiddin Shamsiyev"
git config --global user.email "shamsiyevshamsiddin19@gmail.com"
```

> ⚠️ **Muhim: `user.email` GitHub'dagi email bilan mos bo'lishi tavsiya etiladi.** Agar GitHub'ga ulanadigan bo'lsangiz (3-bobda ko'ramiz), bu email GitHub akkauntingizdagi email bilan bir xil bo'lsa, GitHub commit'laringizni avtomatik profilingizga bog'laydi (profil rasmingiz commit tarixida ko'rinadi).

### `--global` bayrog'i — nima uchun kerak

`--global` — bu sozlama **kompyuteringizdagi barcha** Git loyihalari uchun amal qilishini bildiradi (bir marta sozlanadi, hamma joyda ishlaydi). Agar `--global`siz sozlansa, sozlama faqat **joriy loyihaga** tegishli bo'ladi.

### Sozlamalarning uch darajasi

| Daraja | Bayroq | Qamrov |
|---|---|---|
| System | `--system` | Kompyuterdagi **barcha** foydalanuvchilar uchun (kamdan-kam ishlatiladi) |
| Global | `--global` | Joriy foydalanuvchining **barcha** loyihalari uchun |
| Local | (bayrogsiz, standart) | Faqat **joriy** loyiha (papka) uchun |

```bash
# Global — barcha loyihalar uchun standart email
git config --global user.email "shaxsiy@gmail.com"

# Local — faqat SHU loyiha uchun (masalan, ish loyihasi uchun boshqa email)
cd ish-loyihasi/
git config user.email "ish@kompaniya.com"
```

Local sozlama — global sozlamani **shu loyiha doirasida** ustidan bosib o'tadi (override qiladi). Bu — masalan, shaxsiy va ishga oid loyihalarda turli email manzillarini ishlatish kerak bo'lganda foydalanadi.

### Standart matn muharrirni sozlash

Git ba'zan (masalan, commit izohini yozishda, agar `-m` bayrog'i ishlatilmasa) sizni **matn muharrirga** yo'naltiradi. Standart holda bu ko'pincha `vim` (boshlovchilar uchun noqulay) bo'ladi:

```bash
git config --global core.editor "nano"
```

`nano` — Ubuntu'da o'rnatilgan, sodda va boshlovchilar uchun tushunarli matn muharrir. Agar VS Code ishlatsangiz (Python kursining 0.1-darsida o'rnatgan edingiz):

```bash
git config --global core.editor "code --wait"
```

`--wait` — VS Code'da faylni yopmaguningizcha, Git keyingi qadamga o'tmasligini bildiradi.

### Standart branch nomini sozlash — `main` vs `master`

Tarixiy jihatdan Git'ning standart birinchi branch nomi `master` edi. 2020-yildan boshlab GitHub va Git jamoasi **`main`**ni standart va tavsiya etiladigan nom sifatida qabul qildi (bu — 2-bobda batafsil o'rganiladigan "branch" tushunchasiga bog'liq):

```bash
git config --global init.defaultBranch main
```

Bu sozlamasiz, ba'zi eski Git versiyalarida yangi loyiha `master` nomli branch bilan boshlanishi mumkin — bu funksional jihatdan farq qilmaydi, lekin `main` — zamonaviy, GitHub bilan mos konvensiya hisoblanadi.

### Barcha sozlamalarni ko'rish

```bash
git config --list                  # barcha faol sozlamalar
git config --list --show-origin      # + qaysi fayldan kelganini ko'rsatadi (system/global/local)
git config user.name                  # faqat bitta sozlamani ko'rish
```

Global sozlamalar — `~/.gitconfig` (uy papkangizdagi yashirin fayl) ichida saqlanadi, uni to'g'ridan-to'g'ri matn muharririda ham ko'rish/tahrirlash mumkin:

```bash
cat ~/.gitconfig
```

### Foydali qo'shimcha sozlamalar

```bash
# Rangli chiqishni yoqish (odatda standart holda allaqachon yoqilgan)
git config --global color.ui auto

# git pull qilganda standart xatti-harakatni belgilash (5-bobda "rebase" tushunchasiga bog'liq)
git config --global pull.rebase false

# Qisqartma (alias) yaratish — tez-tez ishlatiladigan buyruqlar uchun
git config --global alias.st status
git config --global alias.co checkout
git config --global alias.br branch
git config --global alias.cm "commit -m"
```

Alias'lar — uzun buyruqlarni qisqartirish uchun juda foydali: `git status` o'rniga endi shunchaki `git st` yozish yetarli.

## Amaliy misol

To'liq, birinchi sozlash ketma-ketligi — noldan boshlab:

```bash
# 1. O'rnatish
sudo apt update
sudo apt install git -y

# 2. Versiyani tekshirish
git --version

# 3. Shaxsiy ma'lumotlarni sozlash
git config --global user.name "Shamsiddin Shamsiyev"
git config --global user.email "shamsiyevshamsiddin19@gmail.com"

# 4. Standart matn muharrirni sozlash
git config --global core.editor "nano"

# 5. Standart branch nomini "main" qilib belgilash
git config --global init.defaultBranch main

# 6. Foydali alias'larni qo'shish
git config --global alias.st status
git config --global alias.cm "commit -m"

# 7. Barcha sozlamalarni tekshirish
git config --list
```

Natija (`git config --list` orqali) taxminan:

```
user.name=Shamsiddin Shamsiyev
user.email=shamsiyevshamsiddin19@gmail.com
core.editor=nano
init.defaultbranch=main
alias.st=status
alias.cm=commit -m
```

Bu sozlashdan so'ng, Git kompyuteringizda ishlashga to'liq tayyor — keyingi darsda birinchi repozitoriyani yaratamiz.

## Keng tarqalgan xatolar

**Xato 1:** `user.name`/`user.email`ni sozlamasdan commit qilishga urinish.
❌ Agar bu sozlanmagan bo'lsa, birinchi `git commit` chaqirilganda Git xato beradi (yoki tizim standart, ma'nosiz qiymatlar — masalan, kompyuter nomi — bilan commit yaratadi).
✅ To'g'ri: Git o'rnatilgandan so'ng, **birinchi ish** sifatida har doim `user.name` va `user.email`ni sozlang — bu keyinchalik butun commit tarixining to'g'ri "muallif" ma'lumotiga ega bo'lishini kafolatlaydi.

**Xato 2:** `--global`ni unutib, sozlamani faqat local darajada qoldirish, keyin boshqa loyihada "sozlamalar yo'q" deb hayron bo'lish.
❌ `git config user.email "..."`  (bayrogsiz) — bu faqat **joriy** loyihaga tegishli, boshqa yangi loyihada bu sozlama **mavjud emas**.
✅ To'g'ri: agar barcha loyihalar uchun bir xil ma'lumot ishlatmoqchi bo'lsangiz, har doim `--global` bayrog'ini qo'shing.

**Xato 3:** standart `vim` muharririga tasodifan tushib qolib, undan qanday chiqishni bilmasdan "qotib qolish".
❌ Commit izohi yozish uchun Git avtomatik `vim`ni ochsa-yu, foydalanuvchi undan qanday chiqishni bilmasa, terminal "muzlab qolgandek" tuyulishi mumkin (aslida `vim` ishlayapti, lekin uning boshqaruvi boshqacha).
✅ To'g'ri: agar `vim`ga "tushib qolsangiz" — `Esc` tugmasini bosing, so'ng `:wq` yozib Enter bosing (saqlab chiqish) yoki `:q!` (saqlamasdan chiqish); ammo eng yaxshisi — yuqorida ko'rsatilganidek, boshidanoq `core.editor`ni `nano` yoki VS Code'ga sozlab qo'yish.

## Mashq/topshiriq

**(Oson)** Git'ni o'rnating (agar hali o'rnatilmagan bo'lsa) va `git --version` orqali versiyasini tekshiring, so'ng `user.name` va `user.email`ni o'z ma'lumotlaringiz bilan sozlang.

**(O'rtacha)** `git config --list --show-origin` buyrug'ini ishga tushiring va natijadan qaysi sozlamalar `~/.gitconfig` (global) faylidan kelayotganini toping.

**(Qiyin)** Ikkita test papka yarating (`shaxsiy-loyiha` va `ish-loyihasi`), global email'ni bittasiga (`shaxsiy@gmail.com`) sozlang, so'ng `ish-loyihasi` papkasi ichida **local** darajada boshqa email (`ish@kompaniya.com`) sozlang; ikkala papkada ham `git config user.email` buyrug'ini ishga tushirib, ular turlicha natija berishini tasdiqlang va sababini tushuntirib bering.

## Qisqacha xulosa

Git Ubuntu'ga `sudo apt install git` orqali oson o'rnatiladi, o'rnatilgandan so'ng birinchi va eng muhim qadam — `git config --global user.name`/`user.email` orqali shaxsiy ma'lumotni sozlash (bu har bir commit'ning "muallifi" sifatida saqlanadi); sozlamalar uch darajaga ega (system, global, local), local sozlama global sozlamani o'z loyihasi doirasida ustidan bosib o'tadi; standart matn muharrir (`core.editor`) va standart branch nomi (`init.defaultBranch main`) kabi qo'shimcha sozlamalar — Git bilan ishlashni zamonaviy va qulay qiladi, bu esa keyingi darsdagi birinchi repozitoriya yaratish uchun to'liq tayyorgarlikni ta'minlaydi.
