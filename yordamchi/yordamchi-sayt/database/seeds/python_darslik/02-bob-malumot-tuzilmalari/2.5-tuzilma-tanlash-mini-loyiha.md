# Qaysi tuzilmani qachon tanlash + mini-loyiha

## Bu darsda nimalarni o'rganasiz

- `list`, `tuple`, `dict`, `set` orasidan to'g'ri tanlov qila olasiz
- Har bir tuzilmaning vaqt murakkabligi (tezligi) haqida asosiy tushunchaga ega bo'lasiz
- O'rganilgan barcha ma'lumot tuzilmalarini birlashtirgan mini-loyihani mustaqil yoza olasiz

## Nazariy qism

### Tanlov jadvali

| Savol | Javob | Tuzilma |
|---|---|---|
| Tartib muhimmi, takroriy qiymatlar bo'lishi kerakmi? | Ha | `list` |
| Ma'lumot o'zgarmasligi kerakmi (himoyalangan)? | Ha | `tuple` |
| Kalit orqali tez topish kerakmi (masalan, ID -> ma'lumot)? | Ha | `dict` |
| Faqat noyob qiymatlar, tartib muhim emasmi? | Ha | `set` |
| Ikkita to'plam orasidagi kesishma/farq kerakmi? | Ha | `set` |
| Funksiyadan bir nechta qiymat qaytarish kerakmi? | Ha | `tuple` |

### Tezlik (vaqt murakkabligi) haqida intuitiv tushuncha

Bu bosqichda "Big O" nazariyasini chuqur o'rganish shart emas, lekin quyidagi amaliy qoidani bilish muhim:

| Amal | `list` | `dict` / `set` |
|---|---|---|
| Element mavjudligini tekshirish (`x in ...`) | Sekin (har birini tekshiradi) | Tez (hash orqali to'g'ridan-to'g'ri topadi) |
| Indeks/kalit orqali olish | Tez | Tez |
| Oxiriga qo'shish | Tez | — |
| O'rtadan qo'shish/o'chirish | Sekin (qolganlarini suriydi) | Tez |

Amaliy xulosa: agar kodingizda ko'p marta `if x in katta_royxat:` ko'rinishidagi tekshiruv bo'lsa va `katta_royxat` o'nlab minglab elementdan iborat bo'lsa — uni `set`ga aylantirish dasturni sezilarli tezlashtirishi mumkin.

```python
import time

katta_royxat = list(range(1000000))
katta_set = set(range(1000000))

boshlanish = time.time()
999999 in katta_royxat     # list — har birini birma-bir tekshiradi
print(f"list: {time.time() - boshlanish:.4f} soniya")

boshlanish = time.time()
999999 in katta_set        # set — hash orqali darhol topadi
print(f"set: {time.time() - boshlanish:.4f} soniya")
```

Bu kodni ishga tushirib ko'rsangiz, `set`dagi tekshiruv `list`dagidan minglab marta tezroq bo'lishini o'z ko'zingiz bilan ko'rasiz.

### Ma'lumot tuzilmalarini birlashtirish — real hayotiy misol

Ko'pincha real loyihalarda tuzilmalar **birlashtirilgan** holda ishlatiladi:

```python
# Do'kon: mahsulotlar ro'yxati, har biri lug'at, ichida narx va teglar (set)
dokon = [
    {"nom": "Noutbuk", "narx": 8500000, "teglar": {"elektronika", "kompyuter"}},
    {"nom": "Sichqoncha", "narx": 150000, "teglar": {"elektronika", "aksessuar"}},
    {"nom": "Kitob", "narx": 45000, "teglar": {"ta'lim"}},
]

# "elektronika" tegiga ega mahsulotlarni topish
elektronika = [m["nom"] for m in dokon if "elektronika" in m["teglar"]]
print(elektronika)    # ['Noutbuk', 'Sichqoncha']
```

Bu — `list` (mahsulotlar tartibi), `dict` (har bir mahsulotning maydonlari) va `set` (teglar, tez tekshirish) birgalikda ishlatilgan misol — real loyihalarda deyarli har doim shunday.

## Amaliy misol — Mini-loyiha: "Kutubxona katalogi"

Ushbu mini-loyiha butun bobda o'rgangan barcha tuzilmalarni (satr, list, tuple, dict, set, comprehension) birlashtiradi:

```python
# kutubxona.py

kitoblar = [
    {"nom": "O'tkan kunlar", "muallif": "Abdulla Qodiriy", "yil": 1925, "janrlar": {"roman", "tarixiy"}},
    {"nom": "Sariq devni minib", "muallif": "Xudoyberdi To'xtaboyev", "yil": 1982, "janrlar": {"bolalar", "sarguzasht"}},
    {"nom": "Mehrobdan chayon", "muallif": "Abdulla Qodiriy", "yil": 1929, "janrlar": {"roman", "tarixiy"}},
    {"nom": "Kecha va kunduz", "muallif": "Cho'lpon", "yil": 1936, "janrlar": {"roman"}},
]


def mualliflar_royxati(kitoblar):
    """Barcha noyob mualliflar to'plamini qaytaradi."""
    return {kitob["muallif"] for kitob in kitoblar}


def janr_boyicha_qidirish(kitoblar, janr):
    """Berilgan janrga mos kitoblar nomlari ro'yxatini qaytaradi."""
    return [kitob["nom"] for kitob in kitoblar if janr in kitob["janrlar"]]


def eng_eski_va_yangi(kitoblar):
    """(eng eski kitob, eng yangi kitob) tuple'ini qaytaradi."""
    eng_eski = min(kitoblar, key=lambda k: k["yil"])
    eng_yangi = max(kitoblar, key=lambda k: k["yil"])
    return eng_eski["nom"], eng_yangi["nom"]


def muallif_boyicha_guruhlash(kitoblar):
    """Muallif -> shu muallifning kitoblari ro'yxati lug'atini qaytaradi."""
    natija = {}
    for kitob in kitoblar:
        muallif = kitob["muallif"]
        natija.setdefault(muallif, []).append(kitob["nom"])
    return natija


print("Mualliflar:", mualliflar_royxati(kitoblar))
print("Roman janridagi kitoblar:", janr_boyicha_qidirish(kitoblar, "roman"))

eski, yangi = eng_eski_va_yangi(kitoblar)
print(f"Eng eski: {eski}, Eng yangi: {yangi}")

for muallif, nomlar in muallif_boyicha_guruhlash(kitoblar).items():
    print(f"{muallif}: {', '.join(nomlar)}")
```

`.setdefault(kalit, standart)` — agar kalit lug'atda mavjud bo'lmasa, uni `standart` qiymat bilan yaratadi va qaytaradi; mavjud bo'lsa, mavjud qiymatni qaytaradi. Bu — "guruhlash" (grouping) mantig'ida juda foydali, chunki `if kalit not in natija: natija[kalit] = []` yozishning qisqartirilgan shakli.

## Keng tarqalgan xatolar

**Xato 1:** har doim `list` ishlatishga o'rganib qolib, boshqa tuzilmalarni ko'rib chiqmaslik.
❌ Tez qidirish kerak bo'lgan joyda ham `list` ishlatib, `if x in katta_royxat:` yozish — dastur kattalashgach sekinlashadi.
✅ To'g'ri: har safar ma'lumot tuzilmasini tanlashdan oldin yuqoridagi jadvaldagi savollarni o'zingizga bering.

**Xato 2:** `dict.setdefault()` o'rniga `dict[kalit] = dict[kalit] + [...]` yozib, `KeyError` olish.
❌ `natija[muallif].append(nom)` — agar `muallif` hali lug'atda bo'lmasa, `KeyError` beradi.
✅ To'g'ri: `.setdefault(muallif, []).append(nom)` yoki `collections.defaultdict(list)` (standart kutubxona, 3-bobda ko'riladi) ishlating.

**Xato 3:** `set` ichidagi elementlarni tartib bo'yicha kutish.
❌ `print(mualliflar_royxati(kitoblar))` — natija har safar bir xil **tartibda** chiqadi deb o'ylash noto'g'ri (garchi amalda CPython ko'pincha barqaror tartib ko'rsatsa ham, bu rasmiy kafolat emas).
✅ To'g'ri: agar tartib muhim bo'lsa, `set`ni `sorted()` bilan o'rab, ro'yxatga aylantiring: `sorted(mualliflar_royxati(kitoblar))`.

## Mashq/topshiriq

**(Oson)** `kutubxona.py`ga yangi funksiya qo'shing: `yil_boyicha_saralangan(kitoblar)` — barcha kitoblarni nashr yiliga ko'ra o'sish tartibida saralab, nomlar ro'yxatini qaytarsin.

**(O'rtacha)** `eng_kop_janr(kitoblar)` funksiyasini yozing — barcha kitoblarning barcha janrlarini yig'ib, eng ko'p uchraydigan janrni (va necha marta uchraganini) qaytarsin (lug'at + `max(..., key=...)` kombinatsiyasi bilan).

**(Qiyin)** `mualliflar_ozaro_janrlari(kitoblar, muallif1, muallif2)` funksiyasini yozing — ikkita muallifning barcha kitoblaridagi janrlarni to'plam (`set`) sifatida yig'ib, ularning **umumiy** janrlarini (kesishmasini) qaytarsin.

def mualliflar_ozaro_janrlari(kitoblar, muallif1, muallif2):
    janrlar1 = set()
    janrlar2 = set()
    for kitob in kitoblar:
        if kitob["muallif"] == muallif1:
            janrlar1 |= kitob["janrlar"]
        elif kitob["muallif"] == muallif2:
            janrlar2 |= kitob["janrlar"]
    return janrlar1 & janrlar2

## Qisqacha xulosa

To'g'ri ma'lumot tuzilmasini tanlash — kodning nafaqat to'g'ri, balki **tez va o'qilishi oson** bo'lishini ta'minlaydi: tartib va takroriy qiymatlar uchun `list`, o'zgarmaslik va bir nechta qiymat qaytarish uchun `tuple`, kalit orqali tez topish uchun `dict`, noyoblik va to'plam amallari uchun `set`; ushbu bobda ko'rilgan "Kutubxona katalogi" mini-loyihasi kabi real vazifalarda bu to'rtta tuzilma deyarli har doim **birgalikda**, bir-birini to'ldirib ishlatiladi.
