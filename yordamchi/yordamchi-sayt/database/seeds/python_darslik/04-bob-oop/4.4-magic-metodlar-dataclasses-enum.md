# Magic metodlar, dataclasses va Enum

## Bu darsda nimalarni o'rganasiz

- Eng ko'p ishlatiladigan magic (dunder) metodlarni qo'llay olasiz
- `@dataclass` dekoratori bilan klasslarni qisqa yoza olasiz
- `Enum` yordamida cheklangan, aniq qiymatlar to'plamini ifodalay olasiz
- Bu uchta vosita nega zamonaviy Python kodini qisqartirishini tushunasiz

## Nazariy qism

### Magic metodlar (dunder metodlar) — nima uchun kerak

**Magic metodlar** (yoki "dunder" — *double underscore*dan) — `__init__`, `__str__` kabi ikki pastki chiziq bilan o'ralgan maxsus metodlar bo'lib, ular Python'ning **o'rnatilgan operatorlari va funksiyalarini** (`+`, `==`, `len()`, `print()`) o'z klassingiz uchun moslashtirish imkonini beradi:

```python
class Vektor:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __str__(self):          # print(v) yoki str(v) chaqirilganda
        return f"Vektor({self.x}, {self.y})"

    def __repr__(self):          # konsolda/debugda ko'rsatiladigan "texnik" ko'rinish
        return f"Vektor(x={self.x}, y={self.y})"

    def __add__(self, boshqa):    # v1 + v2 chaqirilganda
        return Vektor(self.x + boshqa.x, self.y + boshqa.y)

    def __eq__(self, boshqa):     # v1 == v2 chaqirilganda
        return self.x == boshqa.x and self.y == boshqa.y

    def __len__(self):             # len(v) chaqirilganda
        return int((self.x ** 2 + self.y ** 2) ** 0.5)


v1 = Vektor(2, 3)
v2 = Vektor(1, 4)

print(v1)              # Vektor(2, 3) — __str__
v3 = v1 + v2             # __add__ — natija: Vektor(3, 7)
print(v3)
print(v1 == Vektor(2, 3))   # True — __eq__ (aks holda, __eq__siz, bu doim False bo'lardi!)
print(len(v1))           # 3 — __len__ (kvadrat ildiz ~3.6, int() kesib tashlaydi)
```

### Eng ko'p ishlatiladigan magic metodlar

| Metod | Qachon chaqiriladi |
|---|---|
| `__init__` | Obyekt yaratilganda |
| `__str__` | `print(obj)`, `str(obj)` |
| `__repr__` | Konsolda/debugda, `repr(obj)` |
| `__eq__` | `obj1 == obj2` |
| `__lt__` | `obj1 < obj2` (saralash uchun kerak) |
| `__len__` | `len(obj)` |
| `__add__` | `obj1 + obj2` |
| `__getitem__` | `obj[indeks]` |
| `__contains__` | `x in obj` |
| `__call__` | `obj()` — obyektni funksiya kabi chaqirish |

> ⚠️ **`__eq__`siz taqqoslash ishlamaydi.** Standart holda Python ikkita obyektni faqat **xotiradagi manzili** bo'yicha solishtiradi (`is` bilan bir xil). Agar klassingiz "mazmuni bir xil bo'lsa teng" degan mantiqqa muhtoj bo'lsa (masalan, ikkita `Vektor(2,3)` obyekti), `__eq__`ni albatta yozish kerak.

### `@dataclass` — ma'lumot saqlovchi klasslarni qisqartirish

Ko'p klasslar shunchaki ma'lumot saqlash uchun yaratiladi (`__init__`, `__repr__`, `__eq__` — barchasi deyarli bir xil naqshda takrorlanadi). `@dataclass` dekoratori (standart kutubxonaning `dataclasses` moduli) buni avtomatlashtiradi:

```python
from dataclasses import dataclass

@dataclass
class Nuqta:
    x: int
    y: int

n1 = Nuqta(2, 3)
n2 = Nuqta(2, 3)

print(n1)              # Nuqta(x=2, y=3) — __repr__ AVTOMATIK yaratilgan
print(n1 == n2)          # True — __eq__ HAM avtomatik yaratilgan
```

Oddiy klass bilan solishtirganda — qancha kod tejaladi:

```python
# @dataclass'siz, qo'lda yozilgan bir xil funksionallik:
class Nuqta:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __repr__(self):
        return f"Nuqta(x={self.x}, y={self.y})"

    def __eq__(self, boshqa):
        return self.x == boshqa.x and self.y == boshqa.y
```

### Standart qiymatlar va metodlar bilan `@dataclass`

```python
from dataclasses import dataclass, field

@dataclass
class Mahsulot:
    nom: str
    narx: float
    miqdor: int = 1                    # standart qiymat
    teglar: list = field(default_factory=list)   # mutable standart — field() orqali xavfsiz

    def jami_narx(self):                # oddiy metod ham qo'shish mumkin
        return self.narx * self.miqdor


mahsulot1 = Mahsulot("Noutbuk", 8500000)
mahsulot2 = Mahsulot("Sichqoncha", 150000, miqdor=2, teglar=["aksessuar"])

print(mahsulot1)                # Mahsulot(nom='Noutbuk', narx=8500000, miqdor=1, teglar=[])
print(mahsulot2.jami_narx())    # 300000
```

`field(default_factory=list)` — 3.1-darsda ko'rgan "mutable standart qiymat" muammosining `@dataclass` uchun to'g'ri yechimi (`teglar: list = []` yozish xato bo'lardi, xuddi oddiy funksiyalardagidek).

### `Enum` — cheklangan, aniq qiymatlar to'plami

Ko'pincha o'zgaruvchi faqat **oldindan belgilangan** qiymatlardan birini olishi kerak (masalan, buyurtma holati: "yangi", "jarayonda", "yetkazilgan"). Buni oddiy satr sifatida saqlash xatoga moyil (`"jaryonda"` — imlo xatosi bilan yozilishi mumkin va Python buni sezmaydi):

```python
from enum import Enum

class BuyurtmaHolati(Enum):
    YANGI = "yangi"
    JARAYONDA = "jarayonda"
    YETKAZILGAN = "yetkazilgan"
    BEKOR_QILINGAN = "bekor_qilingan"


class Buyurtma:
    def __init__(self, mahsulot, holat=BuyurtmaHolati.YANGI):
        self.mahsulot = mahsulot
        self.holat = holat


buyurtma1 = Buyurtma("Noutbuk")
print(buyurtma1.holat)              # BuyurtmaHolati.YANGI
print(buyurtma1.holat.value)         # "yangi" — haqiqiy qiymat
print(buyurtma1.holat == BuyurtmaHolati.YANGI)   # True

buyurtma1.holat = BuyurtmaHolati.JARAYONDA   # faqat aniq belgilangan qiymatlar ishlatilishi mumkin

# buyurtma1.holat = "notogri_qiymat"   # bu ishlaydi, lekin Enum maqsadiga zid — tekshiruv yo'qoladi
```

`Enum` ishlatishning afzalligi — IDE (VS Code, PyCharm) barcha mumkin bo'lgan qiymatlarni **avtomatik to'ldirish** orqali ko'rsatadi, va imlo xatolarini yozish paytida sezib qoladi (`BuyurtmaHolati.YANGGI` — IDE darhol xato deb belgilaydi, oddiy `"yanggi"` satrni esa hech kim payqamasligi mumkin).

### Enum bo'ylab aylanish va taqqoslash

```python
for holat in BuyurtmaHolati:
    print(holat.name, "->", holat.value)
# YANGI -> yangi
# JARAYONDA -> jarayonda
# ...

print(list(BuyurtmaHolati))    # [<BuyurtmaHolati.YANGI: 'yangi'>, ...]
```

## Amaliy misol

To'liq misol — `@dataclass` va `Enum`ni birlashtirish:

```python
# buyurtma_tizimi.py

from dataclasses import dataclass, field
from enum import Enum


class Holat(Enum):
    YANGI = "yangi"
    TASDIQLANGAN = "tasdiqlangan"
    BEKOR_QILINGAN = "bekor_qilingan"


@dataclass
class Buyurtma:
    mijoz: str
    mahsulotlar: list = field(default_factory=list)
    holat: Holat = Holat.YANGI

    def jami_narx(self):
        return sum(narx for _, narx in self.mahsulotlar)

    def mahsulot_qosh(self, nom, narx):
        self.mahsulotlar.append((nom, narx))


buyurtma1 = Buyurtma(mijoz="Ali")
buyurtma1.mahsulot_qosh("Noutbuk", 8500000)
buyurtma1.mahsulot_qosh("Sichqoncha", 150000)
buyurtma1.holat = Holat.TASDIQLANGAN

print(buyurtma1)
print(f"Jami: {buyurtma1.jami_narx():,.0f} so'm")
print(f"Holat: {buyurtma1.holat.value}")
```

## Keng tarqalgan xatolar

**Xato 1:** `__str__` va `__repr__`ni chalkashtirish.
❌ Faqat `__repr__`ni yozib, `__str__` ham xuddi shunday ishlaydi deb o'ylash — aslida `__str__` yo'q bo'lsa, Python `print()` uchun `__repr__`ga "qaytadi" (fallback), lekin bu har doim ham eng chiroyli natija bermaydi.
✅ To'g'ri: foydalanuvchi uchun chiroyli chiqish kerak bo'lsa `__str__`ni, dasturchi/debug uchun texnik ko'rinish kerak bo'lsa `__repr__`ni alohida yozing.

**Xato 2:** `@dataclass`da mutable standart qiymatni to'g'ridan-to'g'ri yozish.
❌ `teglar: list = []` — `@dataclass` bu holatda avtomatik `ValueError: mutable default <class 'list'> for field teglar is not allowed` xatosini beradi (bu, aslida, oddiy funksiyalardagi "yashirin" xatoning oldini oladigan yaxshi xususiyat).
✅ To'g'ri: `teglar: list = field(default_factory=list)` ishlating.

**Xato 3:** `Enum` qiymatini uning `.value`siz to'g'ridan-to'g'ri satr bilan solishtirish.
❌ `if buyurtma.holat == "yangi":` — bu **doim `False`** bo'ladi, chunki `buyurtma.holat` — `Holat.YANGI` (Enum obyekti), `"yangi"` (oddiy satr) emas.
✅ To'g'ri: `if buyurtma.holat == Holat.YANGI:` (Enum bilan solishtirish) yoki `if buyurtma.holat.value == "yangi":` (qiymat bilan solishtirish).

## Mashq/topshiriq

**(Oson)** `@dataclass` yordamida `Kitob` klassini yarating (`nom: str`, `muallif: str`, `yil: int`), so'ng ikkita bir xil ma'lumotli `Kitob` obyektini solishtirib, `__eq__` avtomatik ishlashini tekshiring.

**(O'rtacha)** `Rang` nomli `Enum` yarating (`QIZIL`, `YASHIL`, `KOK` — har biriga mos HEX kod qiymati bilan, masalan `"#FF0000"`), so'ng foydalanuvchidan rang nomini so'rab, mos HEX kodni chiqaring.

**(Qiyin)** `Pul` klassini yozing — `summa` va `valyuta` atributlari bilan; `__add__` metodini shunday yozingki, ikkita `Pul` obyekti qo'shilganda, agar valyutalari bir xil bo'lsa yangi `Pul` qaytarsin, agar har xil bo'lsa `ValueError` chiqarsin. `__str__`ni ham qo'shing (masalan, `"100 UZS"`).

## Qisqacha xulosa

Magic metodlar (`__str__`, `__eq__`, `__add__` va h.k.) — o'z klassingizni Python'ning o'rnatilgan operatorlari bilan "tabiiy" ishlatish imkonini beradi; `@dataclass` — ma'lumot saqlovchi klasslar uchun `__init__`, `__repr__`, `__eq__`ni avtomatik yaratib, kodni sezilarli qisqartiradi; `Enum` esa — cheklangan, aniq belgilangan qiymatlar to'plamini xavfsiz va IDE-qulay tarzda ifodalaydi — bu uchta vosita zamonaviy Python kodida (ayniqsa Django modellari va DRF serializerlarida, keyingi kurslarda ko'rilganidek) juda keng qo'llaniladi.
