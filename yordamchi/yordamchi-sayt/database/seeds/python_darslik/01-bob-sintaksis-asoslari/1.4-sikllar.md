# Sikllar (for/while/range/break/continue/else)

## Bu darsda nimalarni o'rganasiz

- `for` va `while` sikllari orasidagi farqni tushuntira olasiz
- `range()` funksiyasidan turli ko'rinishlarda foydalana olasiz
- `break` va `continue` bilan sikl oqimini boshqara olasiz
- Sikllarning kamdan-kam ishlatiladigan, lekin foydali `else` blokini tushuntira olasiz

## Nazariy qism

### `for` sikli — ketma-ketlik bo'yicha aylanish

`for` — ro'yxat, satr yoki boshqa "iterable" (aylanish mumkin bo'lgan) obyekt elementlari bo'yicha birma-bir yurish uchun ishlatiladi:

```python
mevalar = ["olma", "banan", "uzum"]

for meva in mevalar:
    print(meva)
```

```python
for harf in "Python":
    print(harf)     # P, y, t, h, o, n — har biri alohida qatorda
```

### `range()` — sonlar ketma-ketligi yaratish

```python
for i in range(5):          # 0, 1, 2, 3, 4 (5 KIRMAYDI!)
    print(i)

for i in range(2, 8):        # 2, 3, 4, 5, 6, 7 (boshlanish, tugash)
    print(i)

for i in range(0, 10, 2):    # 0, 2, 4, 6, 8 (boshlanish, tugash, qadam)
    print(i)

for i in range(10, 0, -1):   # 10, 9, 8, ..., 1 (teskari sanoq)
    print(i)
```

> ⚠️ **Muhim:** `range(n)` — `0` dan boshlab, `n` gacha (lekin `n`ning **o'zini kiritmasdan**) sanaydi. Bu — Python'da eng ko'p uchraydigan chalkashliklardan biri, chunki ko'p dasturchi `range(5)` — `1, 2, 3, 4, 5` beradi deb o'ylaydi, aslida `0, 1, 2, 3, 4` beradi.

### `enumerate()` — indeks bilan birga aylanish

```python
mevalar = ["olma", "banan", "uzum"]

for indeks, meva in enumerate(mevalar):
    print(f"{indeks}: {meva}")
# 0: olma
# 1: banan
# 2: uzum
```

`enumerate()` — har bir elementni **indeksi bilan birga** juftlik (`tuple`) ko'rinishida qaytaradi, bu `for i in range(len(mevalar))` yozishdan ancha qulayroq va Pythonic (Python uslubiga mos) hisoblanadi.

### `while` sikli — shart to'g'ri bo'lguncha takrorlash

```python
son = 5

while son > 0:
    print(son)
    son -= 1     # son = son - 1 bilan bir xil
print("Uchirildi!")
```

`while` — takrorlanish soni **oldindan noma'lum** bo'lgan holatlarda ishlatiladi (masalan, foydalanuvchi to'g'ri javob berguncha so'rash):

```python
parol = ""
while parol != "python123":
    parol = input("Parolni kiriting: ")
print("Kirish muvaffaqiyatli!")
```

> ⚠️ **Diqqat: cheksiz sikl (infinite loop).** Agar `while` shartidagi o'zgaruvchi sikl ichida hech qachon o'zgarmasa, sikl **abadiy** davom etadi. Terminalda cheksiz siklni to'xtatish uchun `Ctrl+C` bosiladi.

### `break` — siklni to'liq to'xtatish

```python
for son in range(1, 100):
    if son == 5:
        break        # sikl darhol to'xtaydi, 5-dan keyingi sonlar ko'rilmaydi
    print(son)
# 1, 2, 3, 4
```

### `continue` — joriy iteratsiyani o'tkazib yuborish

```python
for son in range(1, 10):
    if son % 2 == 0:
        continue      # juft sonlarni o'tkazib yuboradi
    print(son)
# 1, 3, 5, 7, 9
```

### Sikldagi `else` bloki — kamdan-kam ishlatiladigan, lekin foydali

Python'da `for`/`while` sikllari ham `else` blokiga ega bo'lishi mumkin — bu blok faqat sikl `break` orqali **to'xtatilmasdan**, to'liq tugaganda ishga tushadi:

```python
sonlar = [4, 6, 8, 10]

for son in sonlar:
    if son % 2 != 0:
        print("Toq son topildi!")
        break
else:
    print("Barcha sonlar juft ekan")   # break ishlamagani uchun bu chiqadi
```

Bu konstruksiya ko'pincha "qidiruv" mantig'ida ishlatiladi: agar biror narsa topilib `break` bo'lsa, `else` **ishlamaydi**; agar hech narsa topilmay sikl to'liq tugasa, `else` ishga tushadi.

### Ichma-ich (nested) sikllar

```python
for qator in range(3):
    for ustun in range(3):
        print(f"({qator},{ustun})", end=" ")
    print()    # har bir tashqi qator tugagach, yangi qatorga o'tish
```

## Amaliy misol

Tub sonlarni (prime numbers) topish dasturi:

```python
# tub_sonlar.py

chegara = int(input("Qaysi songacha tub sonlarni topamiz? "))

print(f"2 dan {chegara} gacha bo'lgan tub sonlar:")

for son in range(2, chegara + 1):
    tub = True
    for boluvchi in range(2, int(son ** 0.5) + 1):
        if son % boluvchi == 0:
            tub = False
            break
    if tub:
        print(son, end=" ")

print()   # oxirida yangi qator
```

Bu dastur har bir son uchun uni faqat `2` dan uning kvadrat ildizigacha bo'lgan sonlarga bo'linishini tekshiradi (chunki agar `son`ning bo'luvchisi bo'lsa, ulardan biri albatta `√son`dan kichik yoki teng bo'ladi) — bu barcha sonlarni `2` dan `son-1`gacha tekshirishdan ancha samaraliroq.

## Keng tarqalgan xatolar

**Xato 1:** `while` siklida hisoblagichni yangilashni unutish — cheksiz sikl.
❌ 
```python
son = 5
while son > 0:
    print(son)
    # son -= 1 yozishni unutgan!
```
Bu dastur hech qachon to'xtamaydi, chunki `son` doim `5` bo'lib qoladi.
✅ To'g'ri: `while` ichida shartga ta'sir qiluvchi o'zgaruvchini har doim yangilab boring (`son -= 1`).

**Xato 2:** `range(len(royxat))` ishlatib, keyin elementga alohida murojaat qilish (Pythonic emas).
❌ 
```python
mevalar = ["olma", "banan"]
for i in range(len(mevalar)):
    print(mevalar[i])
```
✅ To'g'ri: agar faqat elementlar kerak bo'lsa — to'g'ridan-to'g'ri `for meva in mevalar:`; agar indeks ham kerak bo'lsa — `for i, meva in enumerate(mevalar):`.

**Xato 3:** `break`ni ichki sikldan chaqirib, faqat tashqi siklni to'xtatish kutish.
❌ Ichma-ich sikllarda `break` faqat **eng yaqin** (ichki) siklni to'xtatadi, tashqi sikl davom etadi — ko'p dasturchi buni tushunmay, kutilmagan natija oladi.
✅ To'g'ri: agar ikkala siklni ham to'xtatish kerak bo'lsa, alohida `bayroq` (flag) o'zgaruvchisi ishlatiladi yoki kod funksiyaga o'rab, `return` bilan chiqiladi (3-bobda funksiyalarni ko'ramiz).

## Mashq/topshiriq

**(Oson)** `for` sikli yordamida `1` dan `20` gacha bo'lgan barcha juft sonlarni chiqaring.

**(O'rtacha)** `while` sikli yordamida foydalanuvchidan sonlar qabul qiling va ular yig'indisini hisoblang; foydalanuvchi `0` kiritganda sikl to'xtasin va yakuniy yig'indi chiqarilsin.

**(Qiyin)** `1` dan `100` gacha bo'lgan sonlar ichidan `3` ga yoki `5` ga bo'linadigan barcha sonlarning yig'indisini toping (`continue` ishlatib), so'ng alohida — ichma-ich sikl va sikl `else`sidan foydalanib, `100` tub son ekanligini yoki emasligini tekshiruvchi kod yozing.

## Qisqacha xulosa

`for` — ma'lum sondagi elementlar (ro'yxat, `range()`, satr) bo'yicha aylanish uchun, `while` — shart to'g'ri bo'lguncha (takrorlanish soni oldindan noma'lum bo'lganda) ishlatiladi; `break` siklni to'liq to'xtatadi, `continue` joriy iteratsiyani o'tkazib yuboradi, `enumerate()` indeks va elementni birga oladi, sikl `else` bloki esa faqat `break` ishlamagan holda ishga tushadi — bu vositalar dasturdagi har qanday takrorlanuvchi jarayonning (ma'lumotlarni qayta ishlash, qidiruv, hisoblash) asosini tashkil qiladi.
