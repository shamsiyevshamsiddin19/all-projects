# Wstore audit — 2026-10-23

Serverdagi amaldagi kod auditning boshlang'ich manbasi sifatida solishtirildi.

## To'lov va sotuv

1. Standart, ommaga ma'lum Click kaliti bilan webhookni tasdiqlash yopildi. Direct va bridge kalitlari alohida tekshiriladi; kalit sozlanmasa checkout ochilmaydi.
2. Complete imzosiga `merchant_prepare_id` qo'shildi, xizmat/action/prepare ID tekshiriladi. Noto'g'ri JSON, summa va xato kodi 500 bermaydi.
3. Takror webhook yoki bitta buyurtmaning ikkinchi tranzaksiyasi balans/sotuvni ikki marta oshirmaydi. Referal bonusi ham shartli yangilanadi.
4. Pul yechishda balans atomik tekshiriladi; mavjud bo'lmagan `card_holder` maydoni sababli yuz beradigan xato tuzatildi. Xabarda karta raqami niqoblanadi.
5. Pul yechishni admin tomonidan rad etish bir marta qaytarim qiladi. Yakunlangan so'rovni qayta to'lash va moliyaviy maydonlarni oddiy tahrirlash cheklangan.
6. Haqiqiy loyiha arxivi bo'lmasa checkout va soxta ZIP qaytarish to'xtatiladi. Oldingi xaridlar uchun asl fayl formati va ruxsat tekshiruvi saqlanadi.
7. Nginx orqali `/media/products/` ochiq yuklab olish yopiladi. Xaridor faylni faqat tekshiriladigan Django endpointidan oladi.
8. Daromad joriy mahsulot narxidan emas, PAID buyurtmalardagi haqiqiy summadan hisoblanadi; arxivlangan mahsulot sotuvlari yo'qolmaydi.

## API, kirish va ma'lumotlar

9. API matn/ro'yxat/URL/narx turlarini va chegaralarini tekshiradi; NaN, Infinity, juda uzun sarlavha va xato JSON nazoratli javob oladi.
10. Begona sotuvchi mahsulotiga kirish, bekor qilingan token, faol bo'lmagan hisob va arxivlangan mahsulotni qayta faollashtirish rad etiladi.
11. Google orqali bloklangan hisobga kirish yopildi; boshqa Google ID bilan mavjud bog'lanishni almashtirish rad etiladi. Chiqish faqat CSRF bilan POST orqali.
12. Sharh bahosi 1–5, narx musbat, rasm/screenshot havolalari HTTP(S), yangi arxiv formati va hajmi tekshiriladi. Forma xatolari sahifada ko'rinadi.
13. Bo'sh bazada migratsiyalarni ishga tushirishdagi yetishmagan `store.0001` bog'liqligi tuzatildi. Testlar standart `manage.py test` bilan topiladi.

## Interfeys

14. Qidiruvda sotuvchi matnidan HTML yig'ish va galereyada URL'ni JavaScript ichiga qo'yish bekor qilindi; xavfsiz DOM matni va data atributlari ishlatiladi.
15. CSS hamda shablonlardagi noto'g'ri rang ifodalari `rgb(var(...))` shakliga keltirildi. Kunduzgi fon, chegara, matn va placeholder ranglari ishlaydi.
16. Texnologiyalar bitta qatorda sig'adi; ortiqchasi `…` bilan ko'rsatiladi. Narxlar o'lchamga mos kichrayadi; kasrli narxlar yo'qolmaydi.
17. Mobil filtr klonidagi valyuta tugmalari ishlaydi. 320px ekrandagi yuqori menyu ixchamlashtirildi.
18. HTML til atributi tanlangan tilni bildiradi; yangi interfeys xabarlari EN/RU ga tarjima qilindi.

## Sinovlar

`python manage.py test` — 40 ta test: API egaligi va validatsiyasi, auth, webhook, yuklab olish, balans, daromad va filtr regressiyalari.

`python manage.py check`, `python manage.py makemigrations --check --dry-run`, `node --check static/js/wstore.js`, `git diff --check`.

Brauzerda 320px, 375px va 1440px: katalog/mahsulot, kunduzgi rejim, so'm valyutasi, til almashtirish va overflow tekshirildi.
