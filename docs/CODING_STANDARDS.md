# Kod Standartlari va Uslubiy Qoidalar (Coding Standards)

- **Nomlash:** Funksiya va o'zgaruvchilar maqsadi aniq ifodalangan nomlarga ega bo'lishi kerak.
- **Hujjatlashtirish:** Murakkab funksiyalar va modullar qisqa docstring bilan ta'minlanadi.
- **Xatolarni ushlash:** Kutilmagan holatlar to'g'ri qayta ishlanishi va aniq xatolik xabarlari berilishi lozim.
