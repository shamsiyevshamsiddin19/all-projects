# Xavfsizlik Tekshiruv Ro'yxati (Security Checklist)

- [ ] Maxfiy kalitlar va tokenlar `.env` yoki xavfsiz muhitda saqlanmoqda
- [ ] Barcha tashqi kiruvchi ma'lumotlar to'liq tekshiruvdan o'tkazilmoqda
- [ ] Paketlar muntazam yangilanib, ma'lum zaifliklar bartaraf etilmoqda
- [ ] Ruxsatlar minimal zaruriyat tamoyili asosida taqsimlangan
