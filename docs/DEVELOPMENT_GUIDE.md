# Dasturchi Qo'llanmasi (Development Guide)

## Ishni boshlash
1. Repozitoriyani klon qiling: `git clone <repo-url>`
2. Kerakli paketlar va bog'liqliklarni o'rnating.
3. Konfiguratsiya fayllarini tekshirib, dasturni ishga tushiring.

## Kodni tekshirish
Har bir o'zgarishdan so'ng mahalliy muhitda testlarni ishga tushiring.
