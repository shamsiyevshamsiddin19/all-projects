# Muhitni sozlash: Ubuntu'da FastAPI loyihasini boshlash

## Bu darsda nimalarni o'rganasiz

- `uv` — zamonaviy Python paket menejerini Ubuntu'ga o'rnatasiz
- `uv` orqali yangi loyiha yaratish va bog'liqliklarni boshqarishni o'rganasiz
- FastAPI'ni to'g'ri paket ("standard" to'plami) bilan o'rnatasiz
- Birinchi loyiha tuzilmasini yaratasiz

## Nazariy qism

### Nima uchun `uv`

Python darsligining 0-bobida virtual muhitlarni an'anaviy `venv` + `pip` orqali sozlash o'rganilgan edi. FastAPI'ning rasmiy hujjatlari esa, hozirda **`uv`** — zamonaviy, juda tezkor Python paket va loyiha menejerini birinchi va asosiy tavsiya sifatida ilgari suradi.

| Xususiyat | An'anaviy (`pip` + `venv`) | `uv` |
|---|---|---|
| Tezlik | O'rtacha | Juda tez (Rust tilida yozilgan, o'nlab marta tezroq) |
| Virtual muhit | Qo'lda yaratiladi (`python -m venv`) | Avtomatik boshqariladi |
| Bog'liqliklarni qulflash (lock) | Qo'shimcha vosita kerak (`pip freeze`) | O'rnatilgan (`uv.lock`) |
| Python versiyalarini boshqarish | Alohida vosita kerak (masalan, `pyenv`) | O'rnatilgan |

> 📌 **Eslatma:** `pip` va `venv` — hali ham to'liq ishlaydi va ko'plab mavjud loyihalarda ishlatiladi (Python darsligida ko'rilgan usul). `uv` — ularning **o'rnini bosuvchi**, tezroq va qulayroq zamonaviy muqobil, FastAPI kabi yangi loyihalar uchun hozirda birinchi tavsiya etilgan yo'l hisoblanadi.

### `uv`ni Ubuntu'ga o'rnatish

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

O'rnatilgandan so'ng, terminalni qayta ishga tushiring (yoki `source ~/.bashrc`) va tekshiring:

```bash
uv --version
```

> ⚠️ **Xavfsizlik eslatmasi:** `curl | sh` uslubidagi o'rnatish — internetdan skriptni to'g'ridan-to'g'ri ishga tushiradi. Bu — `uv` kabi keng tanilgan, rasmiy loyihalar uchun keng qabul qilingan amaliyot, ammo har doim manba URL'ini (`astral.sh` — `uv`ning rasmiy ishlab chiquvchisi) tekshirib ko'rish tavsiya etiladi.

Muqobil (agar `apt` orqali o'rnatishni afzal ko'rsangiz):

```bash
sudo apt update
sudo apt install pipx -y
pipx install uv
```

### Python versiyasini `uv` orqali o'rnatish

`uv` — kerakli Python versiyasini o'zi yuklab olib, boshqarishi mumkin (`pyenv`ga alohida ehtiyoj qoldirmaydi):

```bash
uv python install 3.13
```

### Yangi FastAPI loyihasini yaratish

```bash
mkdir mening-fastapi-loyiham && cd mening-fastapi-loyiham
uv init
```

`uv init` — loyiha uchun quyidagi fayllarni avtomatik yaratadi:

```
mening-fastapi-loyiham/
├── .python-version
├── pyproject.toml
├── README.md
└── main.py
```

| Fayl | Vazifasi |
|---|---|
| `pyproject.toml` | Loyiha va uning bog'liqliklari haqidagi markaziy konfiguratsiya (Python darsligining 6-bobida ko'rilgan `pyproject.toml` bilan bir xil standart) |
| `.python-version` | Loyiha qaysi Python versiyasini ishlatishini belgilaydi |
| `main.py` | Boshlang'ich Python fayli |

### FastAPI'ni o'rnatish

```bash
uv add "fastapi[standard]"
```

`[standard]` qismi — muhim: bu FastAPI bilan birga, quyidagilarni ham o'rnatadi:

| Komponent | Vazifasi |
|---|---|
| `uvicorn` | ASGI server — FastAPI ilovasini ishga tushiradi |
| `fastapi-cli` | `fastapi dev`/`fastapi run` buyruqlari |
| `pydantic` | Ma'lumot validatsiyasi (FastAPI'ning asosiy tayanchi) |
| `python-multipart` | Formalar va fayl yuklashni qo'llab-quvvatlash |

`uv add` buyrug'i, avtomatik ravishda: virtual muhit yaratadi (agar hali yo'q bo'lsa), paketni o'rnatadi, va `pyproject.toml` hamda `uv.lock` fayllarini yangilaydi — bularning barchasi **bitta buyruq** bilan.

### Muqobil: an'anaviy `pip` + `venv` orqali o'rnatish

Agar `uv`dan foydalanmaslikni afzal ko'rsangiz (masalan, mavjud loyihada), Python darsligida ko'rilgan uslub bilan ham to'liq ishlaydi:

```bash
python3 -m venv venv
source venv/bin/activate
pip install "fastapi[standard]"
```

Ushbu darslikning qolgan qismida, biz asosan `uv` buyruqlaridan foydalanamiz, lekin har bir buyruqning `pip`/`venv` muqobili mavjud ekanini yodda tuting.

### Loyiha tuzilmasi — boshlang'ich tavsiya

```
mening-fastapi-loyiham/
├── pyproject.toml
├── .python-version
├── .gitignore
├── uv.lock
└── app/
    ├── __init__.py
    └── main.py
```

3-bobda, loyiha kattalashgani sari, bu tuzilma yanada murakkabroq (routerlar, modellar alohida papkalarda) bo'lishini ko'ramiz.

### `.gitignore` — Git/GitHub darsligiga bog'liqlik

Agar loyihani Git bilan boshqarsangiz (Git va GitHub darsligining 1.2-darsida ko'rilganidek), quyidagi `.gitignore` FastAPI/`uv` loyihalari uchun tavsiya etiladi:

```gitignore
# Python
__pycache__/
*.pyc

# uv
.venv/

# Muhit sozlamalari
.env

# IDE
.vscode/
.idea/
```

> 📌 **Muhim farq:** `uv` bilan ishlaganda, **`uv.lock` faylini `.gitignore`ga qo'SHMANG** — bu fayl, xuddi Node.js'dagi `package-lock.json` kabi, barcha bog'liqliklarning **aniq versiyalarini** qulflab qo'yadi, va uni Git'da saqlash — jamoaning barcha a'zolari va production serveri **bir xil** paket versiyalaridan foydalanishini kafolatlaydi.

## Amaliy misol

To'liq, noldan boshlab loyiha sozlash ketma-ketligi:

```bash
# 1. uv o'rnatish (bir martalik, butun tizim uchun)
curl -LsSf https://astral.sh/uv/install.sh | sh
source ~/.bashrc
uv --version

# 2. Kerakli Python versiyasini o'rnatish
uv python install 3.13

# 3. Yangi loyiha yaratish
mkdir mening-fastapi-loyiham && cd mening-fastapi-loyiham
uv init --python 3.13

# 4. FastAPI'ni standard to'plami bilan o'rnatish
uv add "fastapi[standard]"

# 5. pyproject.toml faylini tekshirish
cat pyproject.toml
```

Natija (`pyproject.toml`) taxminan:

```toml
[project]
name = "mening-fastapi-loyiham"
version = "0.1.0"
requires-python = ">=3.13"
dependencies = [
    "fastapi[standard]>=0.141.0",
]
```

```bash
# 6. .gitignore yaratish
cat > .gitignore << 'EOF'
__pycache__/
*.pyc
.venv/
.env
.vscode/
EOF

# 7. Git repository sifatida boshlash (Git darsligi, 1-bob)
git init
git add .
git commit -m "Boshlang'ich FastAPI loyiha tuzilmasi"

# 8. O'rnatilganini tekshirish - versiyalarni ko'rish
uv run python -c "import fastapi; print(fastapi.__version__)"
```

`uv run` — buyruqni loyihaning virtual muhiti ichida, uni qo'lda faollashtirmasdan (`source venv/bin/activate` shart emas) ishga tushiradi — bu, `uv`ning eng katta amaliy qulayliklaridan biri.

## Keng tarqalgan xatolar

**Xato 1:** `pip install fastapi` (kvadrat qavslarsiz) buyrug'ini ishlatib, keyin `uvicorn` topilmadi degan xatoga duch kelish.
❌ Oddiy `fastapi` paketi — faqat framework'ning o'zini o'rnatadi, server (`uvicorn`) va CLI vositalarini emas.
✅ To'g'ri: har doim `"fastapi[standard]"` (yoki `uv add "fastapi[standard]"`) ishlatilishi kerak — bu, ishlash uchun zarur bo'lgan barcha qo'shimcha paketlarni birga o'rnatadi.

**Xato 2:** `uv.lock` faylini `.gitignore`ga qo'shib, uni Git'dan yashirish.
❌ Bu — jamoa a'zolari yoki production serveri, turli (potentsial mos kelmaydigan) paket versiyalaridan foydalanishiga olib kelishi mumkin, bu esa "mening kompyuterimda ishlaydi" degan klassik muammoni keltirib chiqaradi.
✅ To'g'ri: `uv.lock` faylini har doim Git'da kuzatib boring (commit qiling) — faqat `.venv/` papkasi (haqiqiy o'rnatilgan fayllar, ular `uv.lock` asosida istalgan vaqtda qayta yaratilishi mumkin) e'tiborsiz qoldiriladi.

**Xato 3:** `uv add` bilan paket o'rnatgandan so'ng, virtual muhitni qo'lda faollashtirishga urinish yoki uni umuman unutish.
❌ `uv` — o'zining ichki virtual muhit boshqaruviga ega, va ko'p hollarda uni qo'lda `source .venv/bin/activate` bilan faollashtirish shart emas.
✅ To'g'ri: `uv run <buyruq>` orqali, istalgan Python buyrug'ini (masalan, `uv run python`, `uv run fastapi dev`) to'g'ri virtual muhitda, avtomatik ishga tushiring — bu, `uv`ning tavsiya etilgan ishlash uslubi.

## Mashq/topshiriq

**(Oson)** `uv`ni Ubuntu'ga o'rnating va `uv --version` orqali muvaffaqiyatli o'rnatilganini tasdiqlang.

**(O'rtacha)** `uv init` orqali yangi loyiha yarating, `uv add "fastapi[standard]"` bilan FastAPI'ni qo'shing, va `pyproject.toml` faylini ochib, qanday bog'liqliklar avtomatik qo'shilganini ko'ring.

**(Qiyin)** Yaratilgan loyihada, `.gitignore` faylini to'g'ri sozlab (`uv.lock`ni **saqlab**, `.venv/`ni **e'tiborsiz qoldirib**), Git repository sifatida boshlang va birinchi commit'ni qiling. Keyin, `uv.lock` faylining mazmunini oching va u nima uchun `requirements.txt`dan (an'anaviy `pip` usulida) ko'proq ma'lumot saqlashini tushuntiring.

<details>

1. `curl -LsSf https://astral.sh/uv/install.sh | sh && source ~/.bashrc && uv --version`.
2. `uv init mening-loyiham && cd mening-loyiham && uv add "fastapi[standard]"`, `cat pyproject.toml` — `dependencies` ro'yxatida `fastapi[standard]` va uning versiyasi ko'rinadi.
3. `.gitignore`ga `.venv/`, `__pycache__/`, `.env` qo'shiladi (`uv.lock` qo'shilmaydi), `git init && git add . && git commit -m "..."`. `uv.lock` — nafaqat to'g'ridan-to'g'ri bog'liqliklarni, balki ularning **barcha bilvosita (transitive) bog'liqliklarini**, aniq versiya va hatto kripto-хэш (hash) bilan saqlaydi — bu, oddiy `requirements.txt`ga qaraganda, to'liq **takrorlanuvchi (reproducible)** o'rnatishni kafolatlaydi: boshqa kompyuterda xuddi shu buyruq bilan o'rnatilganda, aynan bir xil paket versiyalari olinishi ta'minlanadi.

## Qisqacha xulosa

`uv` — FastAPI loyihalari uchun hozirda birinchi tavsiya etiladigan, tezkor Python paket va loyiha menejeri bo'lib, u virtual muhit yaratish, Python versiyasini boshqarish va bog'liqliklarni qulflashni (`uv.lock`) bitta vosita ichida birlashtiradi; `curl -LsSf https://astral.sh/uv/install.sh | sh` orqali o'rnatiladi, `uv init` bilan yangi loyiha, `uv add "fastapi[standard]"` bilan esa FastAPI va uning barcha zarur qo'shimchalari (uvicorn, CLI) o'rnatiladi. An'anaviy `pip`/`venv` usuli (Python darsligida ko'rilgan) hali ham to'liq ishlaydi va muqobil sifatida qoladi, ammo `uv` — tezligi va qulayligi tufayli, yangi loyihalar uchun tavsiya etilgan yo'l hisoblanadi; keyingi darsda shu sozlangan muhitda birinchi FastAPI ilovasini yozamiz.
