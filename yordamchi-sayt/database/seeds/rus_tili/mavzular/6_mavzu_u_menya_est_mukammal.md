# 6-MAVZU: "У меня есть" + Vinitelьnый padej (Винительный падеж)

*"Россия – моя любовь" (1-qism, 6-dars) asosida, qoʻshimcha manbalar bilan kengaytirilgan mukammal qoʻllanma.*

---

## Kirish: Darsning uch asosiy mavzusi

1. **"У меня есть..."** — "Menda bor..." konstruksiyasi
2. **любить, давать, брать** feʼllarining tuslanishi
3. **Винительный падеж (4-kelishik)** — jonsiz otlar uchun

---

## 1. "У МЕНЯ ЕСТЬ" — "Menda bor" konstruksiyasi

Oʻzbekchadagi "menda bor" ga toʻliq mos keladi.

**Formula: У + [kim?] + есть + [nima?]**

Bu yerda "kim?" qismida olmosh oʻzgaradi:

| Oddiy | У ... есть |
|---|---|
| я | **у меня** есть |
| ты | **у тебя** есть |
| он | **у него** есть |
| она | **у неё** есть |
| мы | **у нас** есть |
| вы | **у вас** есть |
| они | **у них** есть |

**Nima uchun bunday?** "у" predlogi Родительный (2-kelishik) talab qiladi. Shuning uchun shaxs olmoshlari Родительный shaklini oladi.

**Diqqat:** я→меня, он→него, она→неё, они→них — yodlash shart.

### Misollar:
- У меня есть друг. — Menda doʻst bor.
- У неё есть брат и сестра. — Unda aka va singil bor.
- — У тебя есть виза? — Да, у меня есть виза.

---

## 2. ЛЮБИТЬ — sevmoq (II tuslanish, maxsus)

II tuslanish, lekin "я" shaklida "л" qoʻshiladi:

| Shaxs | Shakl | Izoh |
|---|---|---|
| я | люб**лю** | **л** qoʻshiladi! |
| ты | люб**ишь** | oddiy |
| он/она | люб**ит** | oddiy |
| мы | люб**им** | oddiy |
| вы | люб**ите** | oddiy |
| они | люб**ят** | oddiy |

**"Л" qoidasi:** Б,В,П,Ф,М undoshlariga tugagan ildizlarda "я" shaklida "л" qoʻshiladi (любить → люблю, готовить → готовлю).

### Ishlatilishi:
- Я люблю **музыку** (Винительный)
- Я люблю **гулять** (infinitiv, oʻzgarmaydi)

---

## 3. ДАВАТЬ — bermoq (I tuslanish, maxsus)

Ildiz oʻzgaradi — "ва" tushib qoladi:

| Shaxs | Shakl |
|---|---|
| я | да**ю** |
| ты | да**ёшь** |
| он/она | да**ёт** |
| мы | да**ём** |
| вы | да**ёте** |
| они | да**ют** |

**Qoida:** -авать feʼllarida hozirgi zamonda "ва" yoʻqoladi (давать → даю, вставать → встаю). Buyruq shaklida esa "ва" saqlanadi (давай!).

---

## 4. БРАТЬ — olmoq (I tuslanish, maxsus)

Ildiz "бра" → "бер" ga oʻzgaradi:

| Shaxs | Shakl |
|---|---|
| я | бер**у** |
| ты | бер**ёшь** |
| он/она | бер**ёт** |
| мы | бер**ём** |
| вы | бер**ёте** |
| они | бер**ут** |

**Diqqat:** брать → беру (ildiz butunlay oʻzgaradi, yodlash kerak).

---

## 5. ВИНИТЕЛЬНЫЙ ПАДЕЖ — 4-kelishik (jonsiz otlar)

"Nima?" va "kimni?" savoliga javob beradi.

**Asosiy qoida — faqat ayol jins oʻzgaradi:**

| Jins | Именительный (1) | Винительный (4) | Oʻzgarish |
|---|---|---|---|
| Erkak | торт | торт | **Oʻzgarmaydi!** |
| Oʻrta | молоко | молоко | **Oʻzgarmaydi!** |
| Ayol -а | вода | вод**у** | **-а → -у** |
| Ayol -я | семья | семь**ю** | **-я → -ю** |
| Ayol -ь | вещь | вещь | **Oʻzgarmaydi!** |
| Koʻplik | бананы | бананы | **Oʻzgarmaydi!** |

**Eng muhim qoida:** Faqat **ayol jins** soʻzlar oʻzgaradi (-а→-у, -я→-ю). Qolgan hamma jins oʻzgarmaydi (jonsiz otlarda).

### Misollar:
- Я покупаю **воду**. (вода → воду)
- Мой брат любит слушать **музыку**. (музыка → музыку)
- Отец любит читать **детективы**. (koʻplik, oʻzgarmaydi)
- Дети любят **шоколад**. (erkak, oʻzgarmaydi)

---

## 6. Hammasini birga koʻrish

**"У меня есть музыка. Я люблю музыку. Я беру наушники."**
- У меня есть **музыка** (Именительный)
- Я люблю **музыку** (Винительный: -а → -у)
- Я беру **наушники** (koʻplik, oʻzgarmaydi)

## 8. Eng koʻp qilinadigan xatolar

**Xato 1:** "я любю" deyish.
Toʻgʻri: я люб**лю** (л qoʻshiladi).

**Xato 2:** "я даваю" deyish.
Toʻgʻri: я да**ю** ("ва" tushadi).

**Xato 3:** "я браю" deyish.
Toʻgʻri: я бер**у** (ildiz oʻzgaradi).

**Xato 4:** Erkak/oʻrta otni Винительный da oʻzgartirish.
Toʻgʻri: faqat ayol oʻzgaradi (воду), erkak/oʻrta oʻzgarmaydi (торт, молоко).

---

## 9. Mustahkamlash uchun mashq

Toʻgʻri shaklga oʻtkazing:

1. У ___ (я) есть кот.
2. У ___ (она) есть братья.
3. Я люблю ___ (музыка).
4. Фирма даёт ___ (работа).
5. Ты берёшь ___ (зонт)?
6. Я покупаю ___ (вода).
7. Я (любить) ___ гулять.

**Javoblar:** 1-меня, 2-неё, 3-музыку, 4-работу, 5-зонт, 6-воду, 7-люблю

---

## Xulosa — eslab qolish uchun 3 ta ustun

**1. У меня есть:** я→меня, он→него, она→неё, они→них
**2. Maxsus feʼllar:** любить→люблю, давать→даю, брать→беру
**3. Винительный (jonsiz):** faqat ayol oʻzgaradi (-а→-у, -я→-ю), qolganlari oʻzgarmaydi

Bu dars rus tilida "menda bor" deyish va obyektni toʻgʻri ifodalashning asosidir.
