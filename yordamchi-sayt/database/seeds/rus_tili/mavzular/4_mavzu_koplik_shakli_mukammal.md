# 4-MAVZU: Otlarning koʻplik shakli (Множественное число существительных)

*"Россия – моя любовь" (1-qism, 4-dars) asosida, qoʻshimcha manbalar bilan kengaytirilgan mukammal qoʻllanma.*

---

## Kirish: Darsning asosiy mavzulari

1. **Множественное число (Koʻplik shakli)** — asosiy yangi mavzu
2. **7 undosh qoidasi** (Правило 7 согласных)
3. **Koʻplikdagi istisnolar** (друзья, дети, люди)
4. **Doim koʻplikda boʻladigan otlar** (родители, очки, деньги)
5. **I va II tuslanishni takrorlash**

---

## 1. Koʻplik yasashning asosiy qoidasi — jinsga qarab

Otning koʻplik shakli **jinsiga qarab** yasaladi:

| Jins | Birlik oxiri | Koʻplik qoʻshimchasi | Misol |
|---|---|---|---|
| Erkak | undosh | **-ы / -и** | стол → стол**ы**, телефон → телефон**ы** |
| Ayol | -а / -я | **-ы / -и** | газета → газет**ы** |
| Oʻrta | -о / -е | **-а / -я** | окно → окн**а**, море → мор**я** |

**Muhim kuzatuv:** Erkak va ayol jins koʻplikda **bir xil** qoʻshimcha oladi (-ы/-и). Faqat oʻrta jins boshqacha (-а/-я). Yaʼni koʻplikda aslida ikki guruh bor: (erkak+ayol) va (oʻrta).

---

## 2. -Ы yoki -И? — qachon qaysi biri?

Erkak va ayol otlarda **-ы yoki -и** tanlash uchun uchta holat bor:

### A) "7 undosh qoidasi" (Правило 7 согласных)
**Г, К, Х, Ч, Ш, Щ, Ж** harflaridan keyin hech qachon -ы yozilmaydi, faqat **-и**:
- чашка → чашк**и** (К)
- книга → книг**и** (Г)
- нож → нож**и** (Ж)
- врач → врач**и** (Ч)
- коллега → коллег**и** (Г)

### B) -ь bilan tugasa → -И
- словарь → словар**и**
- ночь → ноч**и**
- день → дн**и** (е tushib qoladi!)

### C) -й bilan tugasa → -И
- музей → муз**еи**
- трамвай → трамва**и**

### D) -ия bilan tugasa → -ИИ (ikki "и")
- академия → академ**ии**
- фантазия → фантаз**ии**
- симфония → симфон**ии**

### Qolgan barcha holatlar → -Ы
- стол → стол**ы**
- газета → газет**ы**
- машина → машин**ы**

---

## 3. Oʻrta jins koʻpligi (-А / -Я)

Oʻrta jins otlar boshqa qoidaga boʻysunadi:
- -о bilan tugasa → **-а**: окно → окн**а**, письмо → письм**а**, вино → вин**а**
- -е bilan tugasa → **-я**: море → мор**я**, поле → пол**я**, задание → задани**я**

**Qoida:** "qattiq" -о qattiq -а ga, "yumshoq" -е yumshoq -я ga oʻtadi.

---

## 4. Istisnolar (ЗАПОМНИТЕ! — yodlash shart)

Baʼzi otlar standart qoidaga boʻysunmaydi:

### -ЬЯ guruhi (maxsus qoʻshimcha):
| Birlik | Koʻplik |
|---|---|
| друг | друзь**я** |
| брат | брать**я** |
| сын | сынов**ья** |
| стул | стул**ья** |
| дерево | дерев**ья** |

### Urgʻu bilan -А oluvchi erkak otlar:
| Birlik | Koʻplik |
|---|---|
| город | город**а** |
| дом | дом**а** |
| лес | лес**а** |
| остров | остров**а** |
| поезд | поезд**а** |

### Butunlay maxsus shakllar:
| Birlik | Koʻplik |
|---|---|
| мать | матер**и** |
| дочь | дочер**и** |
| сестра | сёстр**ы** |
| ребёнок | **дети** (boshqa soʻz!) |
| человек | **люди** (boshqa soʻz!) |

**Eng muhim ikkitasi:** ребёнок → дети, человек → люди — bular butunlay boshqa oʻzakdan yasaladi.

## 5. Doim koʻplikda boʻladigan otlar (ВСЕГДА МНОЖЕСТВЕННОЕ)

Baʼzi otlarning **birlik shakli yoʻq** — ular doim koʻplikda:

| Ot | Tarjima |
|---|---|
| родители | ota-onalar |
| очки | koʻzoynak |
| брюки | shim |
| шорты | shortik |
| деньги | pul |
| часы | soat |
| джинсы | jinsi |

Bunday otlar bilan doim koʻplik feʼl va sifat ishlatiladi: Мои родители работают. (Ota-onam ishlaydi.)

## 7. "А yoki О?" mashqi (9-mashq)

Darslik koʻplikda urgʻusiz unlilarni toʻgʻri yozishni mashq qiladi. Urgʻusiz holatda "о" va "а" bir xil eshitiladi, lekin yozilishi farq qiladi:
- ст**о**лы (stol → столы)
- к**о**ты (kot → коты)
- вр**а**чи (vrach → врачи)

---

## 8. I va II tuslanishni takrorlash (4-dars boshida)

Darslik 4-dars boshida ikkala tuslanishни birga takrorlaydi:

| I guruh | II guruh |
|---|---|
| думать → думаем | строить → строим |
| завтракать → завтракаете | помнить → помним |
| знать → знают | смотреть → смотрю |
| гулять → гуляет | говорить → говорит |

---

## 9. Eng koʻp qilinadigan xatolar

**Xato 1:** 7 undoshdan keyin -ы yozish.
Toʻgʻri: книг**и** (книгы emas), нож**и** (ножы emas).

**Xato 2:** Oʻrta jinsni -ы bilan koʻplik qilish.
Toʻgʻri: окн**а** (окны emas), мор**я** (моры emas).

**Xato 3:** Istisnolarni standart qoida bilan yasash.
Toʻgʻri: друзь**я** (други emas), дет**и** (ребёнки emas).

**Xato 4:** -ия otlarni bitta -и bilan yasash.
Toʻgʻri: академ**ии** (академи emas — ikki "и").

## Xulosa — eslab qolish uchun 5 ta asosiy narsa

1. **Erkak+ayol → -ы/-и**, **oʻrta → -а/-я**
2. **7 undosh (Г,К,Х,Ч,Ш,Щ,Ж) + -ь + -й → -и**, qolganlari **-ы**
3. **-ия → -ии** (academия → академии)
4. **Istisnolar:** друзья, братья, дети, люди, города, дома
5. **Doim koʻplik:** родители, очки, деньги, часы, брюки

Koʻplik — rus tilida koʻp narsalar haqida gapirishning asosidir. Istisnolarni alohida yodlash kerak, lekin asosiy qoida sodda: jinsni bil, keyin qoʻshimchani qoʻsh.
