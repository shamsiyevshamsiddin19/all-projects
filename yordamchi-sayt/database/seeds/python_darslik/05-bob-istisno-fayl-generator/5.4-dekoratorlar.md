# Dekoratorlar

## Bu darsda nimalarni o'rganasiz

- Dekorator nima ekanini va u qanday ishlashini tushuntira olasiz
- O'zingizning dekoratoringizni `@` sintaksisi bilan yoza olasiz
- Argumentli dekoratorlarni va `functools.wraps`ni to'g'ri qo'llay olasiz
- Python'ning eng ko'p ishlatiladigan tayyor dekoratorlarini bilasiz

## Nazariy qism

### Dekorator nima — asosiy g'oya

**Dekorator** — boshqa funksiyani "o'rab olib", uning xatti-harakatini o'zgartiradigan yoki kengaytiradigan funksiya. Bu — 3.2-darsda ko'rgan **closure** tushunchasining amaliy qo'llanilishi:

```python
def mening_dekoratorim(funksiya):
    def orash(*args, **kwargs):
        print("Funksiya chaqirilishidan OLDIN")
        natija = funksiya(*args, **kwargs)
        print("Funksiya chaqirilishidan KEYIN")
        return natija
    return orash


def salomlash():
    print("Salom!")

salomlash = mening_dekoratorim(salomlash)   # qo'lda "dekoratsiya qilish"
salomlash()
# Funksiya chaqirilishidan OLDIN
# Salom!
# Funksiya chaqirilishidan KEYIN
```

### `@` sintaksisi — dekoratorning qulay yozilishi

Yuqoridagi `salomlash = mening_dekoratorim(salomlash)` qatorini Python maxsus, qulayroq sintaksis bilan yozish imkonini beradi:

```python
@mening_dekoratorim
def salomlash():
    print("Salom!")

salomlash()    # @ belgisi orqali AVTOMATIK "o'ralgan"
```

`@dekorator_nomi` — funksiya ta'rifi ustida yozilib, `funksiya = dekorator_nomi(funksiya)` bilan **aynan bir xil** natija beradi, lekin ancha o'qilishi oson.

### Amaliy dekorator — vaqtni o'lchash

```python
import time
from functools import wraps

def vaqtni_olchash(funksiya):
    @wraps(funksiya)     # funksiyaning asl nomi/docstringini saqlaydi (pastda batafsil)
    def orash(*args, **kwargs):
        boshlanish = time.time()
        natija = funksiya(*args, **kwargs)
        tugash = time.time()
        print(f"{funksiya.__name__} {tugash - boshlanish:.4f} soniyada bajarildi")
        return natija
    return orash


@vaqtni_olchash
def sekin_hisoblash(n):
    return sum(i ** 2 for i in range(n))


natija = sekin_hisoblash(1000000)
# sekin_hisoblash 0.0821 soniyada bajarildi
```

`*args, **kwargs` — 3.1-darsda ko'rganimizdek, dekorator **istalgan** funksiyani (istalgan sondagi argument bilan) o'rab olishi uchun ishlatiladi.

### `functools.wraps` — nega kerak

```python
def dekorator(funksiya):
    def orash(*args, **kwargs):
        return funksiya(*args, **kwargs)
    return orash

@dekorator
def mening_funksiyam():
    """Bu funksiya juda muhim ishni bajaradi."""
    pass

print(mening_funksiyam.__name__)    # 'orash' — NOTO'G'RI! Asl nom yo'qolgan
print(mening_funksiyam.__doc__)      # None — docstring ham yo'qolgan
```

`@wraps(funksiya)` — dekorator ichidagi `orash`ga asl funksiyaning `__name__`, `__doc__` va boshqa metama'lumotlarini "nusxalab qo'yadi", shunda dekoratsiya qilingan funksiya tashqi ko'rinishda (masalan, debugda, `help()`da) o'zining haqiqiy nomi va tavsifi bilan ko'rinadi. **Har doim** o'z dekoratorlaringizda `@wraps`ni ishlating.

### Argumentli dekorator — "dekorator yasovchi"

```python
def takrorlash(marta):    # bu — DEKORATOR YASOVCHI funksiya, dekoratorning o'zi emas
    def dekorator(funksiya):
        @wraps(funksiya)
        def orash(*args, **kwargs):
            natija = None
            for _ in range(marta):
                natija = funksiya(*args, **kwargs)
            return natija
        return orash
    return dekorator


@takrorlash(marta=3)
def salomlash(ism):
    print(f"Salom, {ism}!")

salomlash("Ali")
# Salom, Ali!
# Salom, Ali!
# Salom, Ali!
```

Bu — uch qavatli tuzilma: `takrorlash(3)` — `dekorator` funksiyasini qaytaradi, `dekorator(salomlash)` esa — `orash`ni qaytaradi. Argument qabul qiladigan dekoratorlar har doim shu naqshga amal qiladi: **tashqi funksiya (argumentlar bilan) → dekorator (funksiyani qabul qiladi) → orash (chaqiriladigan joyni almashtiradi)**.

### Bir nechta dekoratorni birlashtirish

```python
@vaqtni_olchash
@takrorlash(marta=2)
def hisobla(n):
    return sum(range(n))

hisobla(1000000)
```

Dekoratorlar **pastdan yuqoriga** qo'llaniladi: avval `takrorlash(marta=2)` `hisobla`ni o'raydi, so'ng `vaqtni_olchash` natijaviy funksiyani o'raydi. Bu — kod qatorlarining tartibini yaxshi tushunish muhimligini ko'rsatadi.

### Python'ning eng ko'p ishlatiladigan tayyor dekoratorlari

```python
class Hisoblagich:
    def __init__(self, boshlangich=0):
        self._qiymat = boshlangich

    @property                    # 4.3-darsda ko'rgan — metodni atribut kabi ko'rsatadi
    def qiymat(self):
        return self._qiymat

    @staticmethod                 # self/cls kerak emas — klass bilan bog'liq, lekin obyektga muhtoj emas yordamchi funksiya
    def nol_yaratish():
        return Hisoblagich(0)

    @classmethod                   # birinchi argument sifatida self o'rniga cls (klassning o'zi) oladi
    def yuzdan_yarat(cls):
        return cls(100)


h1 = Hisoblagich.nol_yaratish()     # obyekt yaratmasdan chaqiriladi
h2 = Hisoblagich.yuzdan_yarat()      # cls orqali Hisoblagich(100) yaratadi
print(h1.qiymat, h2.qiymat)           # 0 100
```

| Dekorator | Vazifasi |
|---|---|
| `@property` | Metodni atribut kabi ko'rsatadi (4.3-dars) |
| `@staticmethod` | `self`/`cls` kerak bo'lmagan, lekin klass ichida mantiqiy joylashgan yordamchi metod |
| `@classmethod` | Birinchi argument `cls` (klassning o'zi) — ko'pincha muqobil konstruktor sifatida ishlatiladi |
| `@abstractmethod` | Majburiy override qilinishi kerak bo'lgan metod (4.5-dars) |
| `@functools.lru_cache` | Funksiya natijalarini keshlaydi (pastda ko'ramiz) |

### `functools.lru_cache` — avtomatik keshlash

```python
from functools import lru_cache

@lru_cache(maxsize=None)     # maxsize=None — cheksiz kesh hajmi
def fibonachchi(n):
    if n <= 1:
        return n
    return fibonachchi(n - 1) + fibonachchi(n - 2)

print(fibonachchi(35))    # keshsiz — juda sekin (millionlab qayta hisoblash); kesh bilan — DEYARLI DARHOL
```

3.2-darsda ko'rgan "sodda Fibonachchi rekursiyasi sekin ishlaydi" muammosi — `@lru_cache` bilan bir qatorda hal qilinadi! Dekorator har bir `n` uchun natijani "eslab qoladi" (keshlaydi), va bir xil `n` bilan qayta chaqirilganda hisoblamasdan, to'g'ridan-to'g'ri saqlangan natijani qaytaradi.

## Amaliy misol

Loglash va xatolarni qayta urinish (retry) dekoratorlari — real loyihalarda keng qo'llaniladigan naqsh:

```python
# dekoratorlar_amaliy.py
import time
from functools import wraps


def logla(funksiya):
    @wraps(funksiya)
    def orash(*args, **kwargs):
        print(f"[LOG] {funksiya.__name__} chaqirildi, argumentlar: {args}, {kwargs}")
        natija = funksiya(*args, **kwargs)
        print(f"[LOG] {funksiya.__name__} natija qaytardi: {natija}")
        return natija
    return orash


def qayta_urin(marta_soni=3, kutish=1):
    def dekorator(funksiya):
        @wraps(funksiya)
        def orash(*args, **kwargs):
            for urinish in range(1, marta_soni + 1):
                try:
                    return funksiya(*args, **kwargs)
                except Exception as xato:
                    print(f"Urinish {urinish}/{marta_soni} muvaffaqiyatsiz: {xato}")
                    if urinish == marta_soni:
                        raise    # oxirgi urinishda ham muvaffaqiyatsiz bo'lsa, xatoni chiqarish
                    time.sleep(kutish)
        return orash
    return dekorator


@logla
def qosh(a, b):
    return a + b


@qayta_urin(marta_soni=3, kutish=0.5)
def notogri_tarmoq_sorovi():
    import random
    if random.random() < 0.7:    # 70% ehtimol bilan "xato" simulyatsiya qilinadi
        raise ConnectionError("Server javob bermadi")
    return "Muvaffaqiyatli!"


qosh(3, 5)
# [LOG] qosh chaqirildi, argumentlar: (3, 5), {}
# [LOG] qosh natija qaytardi: 8

try:
    natija = notogri_tarmoq_sorovi()
    print(natija)
except ConnectionError:
    print("Barcha urinishlar muvaffaqiyatsiz tugadi")
```

`qayta_urin` dekoratori — tarmoq bilan bog'liq operatsiyalarda (API so'rovlari, ma'lumotlar bazasiga ulanish) haqiqiy loyihalarda juda tez-tez ishlatiladigan naqsh: vaqtinchalik xatolarda dasturni darhol to'xtatish o'rniga, bir necha marta qayta urinib ko'rish.

## Keng tarqalgan xatolar

**Xato 1:** `@wraps(funksiya)`ni yozishni unutish.
❌ Dekorator to'g'ri ishlaydi, lekin `funksiya.__name__` va `__doc__` yo'qoladi — bu debug qilishda va IDE yordamida qiyinchilik tug'diradi.
✅ To'g'ri: har doim dekorator ichidagi ichki funksiya ustiga `@wraps(funksiya)` qo'ying (`from functools import wraps`).

**Xato 2:** dekorator ichida `return`ni unutish.
❌ 
```python
def dekorator(funksiya):
    def orash(*args, **kwargs):
        funksiya(*args, **kwargs)    # return yo'q!
    return orash
```
Bu holda dekoratsiya qilingan funksiya har doim `None` qaytaradi, garchi asl funksiya biror qiymat qaytarsa ham.
✅ To'g'ri: ichki funksiyada har doim `return funksiya(*args, **kwargs)` yozing.

**Xato 3:** argumentli dekoratorda bitta "qavat"ni unutish.
❌ 
```python
def takrorlash(marta):
    def orash(*args, **kwargs):    # dekorator qavati YO'Q!
        ...
    return orash

@takrorlash(3)
def f(): ...
```
Bu `TypeError` beradi, chunki `takrorlash(3)` to'g'ridan-to'g'ri `orash`ni qaytaradi, lekin `@takrorlash(3)` uni **funksiyaga** (`f`ga) qo'llashga harakat qiladi — qavatlar soni mos kelmaydi.
✅ To'g'ri: argumentli dekorator har doim uch qavatli bo'lishi kerak: tashqi (argumentlar) → o'rta (funksiyani oladi) → ichki (`*args, **kwargs`).

## Mashq/topshiriq

**(Oson)** `katta_harflarga_ozgartir` dekoratorini yozing — o'ralgan funksiya `str` qaytarsa, uni avtomatik `.upper()` qilib qaytarsin.

**(O'rtacha)** `faqat_musbat` dekoratorini yozing — agar o'ralgan funksiyaga berilgan **birinchi** argument manfiy bo'lsa, funksiyani chaqirmasdan `ValueError("Argument manfiy bo'lishi mumkin emas")` chiqarsin.

**(Qiyin)** `chaqiruvlar_soni` dekoratorini yozing — u dekoratsiya qilingan funksiya necha marta chaqirilganini kuzatib borsin (funksiyaning o'zida `.chaqiruvlar` nomli atribut sifatida saqlansin, har chaqiriqda oshib borsin) va har safar `print(f"{funksiya.__name__} {n}-marta chaqirildi")` chiqarsin.

```python
from functools import wraps
```

```python
def faqat_musbat(funksiya):
    @wraps(funksiya)
    def orash(*args, **kwargs):
        if args and args[0] < 0:
            raise ValueError("Argument manfiy bo'lishi mumkin emas")
        return funksiya(*args, **kwargs)
    return orash
```

```python
def chaqiruvlar_soni(funksiya):

    orash.chaqiruvlar = 0
    return orash
```

## Qisqacha xulosa

Dekorator — closure tamoyiliga asoslangan, `@` sintaksisi orqali qo'llaniladigan, boshqa funksiyaning xatti-harakatini o'zgartirmasdan **kengaytiradigan** funksiya bo'lib (loglash, vaqt o'lchash, keshlash, qayta urinish kabi vazifalar uchun ishlatiladi); `functools.wraps` — funksiya metama'lumotlarini saqlaydi, argumentli dekoratorlar esa uch qavatli tuzilmani talab qiladi; `@property`, `@staticmethod`, `@classmethod`, `@lru_cache` — Python standart kutubxonasining eng ko'p ishlatiladigan tayyor dekoratorlari bo'lib, ular butun kurs davomida (ayniqsa Django darsligida `@login_required`, `@admin.action` kabi ko'rinishlarda) doimiy uchraydi.
