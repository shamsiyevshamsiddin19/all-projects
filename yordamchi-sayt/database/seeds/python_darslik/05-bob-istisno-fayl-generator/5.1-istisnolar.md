# Istisnolar (exceptions)

## Bu darsda nimalarni o'rganasiz

- `try`/`except`/`else`/`finally` bloklarini to'g'ri qo'llay olasiz
- Turli xato turlarini (`ValueError`, `TypeError`, `KeyError` va h.k.) alohida ushlay olasiz
- O'zingizning maxsus istisno klassingizni yarata olasiz
- `raise` orqali xatoni ataylab keltirib chiqara olasiz

## Nazariy qism

### Nega istisnolarni boshqarish kerak

```python
son = int(input("Son kiriting: "))    # foydalanuvchi "salom" kiritsa nima bo'ladi?
print(100 / son)                        # foydalanuvchi 0 kiritsa nima bo'ladi?
```

Ushbu ikkala qatorda ham dastur **kutilmagan** ma'lumot kelganda to'xtab qoladi (`ValueError` yoki `ZeroDivisionError`). Real dasturlar bunday holatlarni "chiroyli" boshqarishi, foydalanuvchiga tushunarli xabar berishi va dastur ishini davom ettirishi kerak.

### `try`/`except` — asosiy tuzilma

```python
try:
    son = int(input("Son kiriting: "))
    natija = 100 / son
    print(f"Natija: {natija}")
except ValueError:
    print("Xato: iltimos, haqiqiy son kiriting!")
except ZeroDivisionError:
    print("Xato: nolga bo'lish mumkin emas!")
```

`try` bloki ichida "xavfli" kod (xato chiqarishi mumkin bo'lgan) yoziladi; agar xato yuzaga kelsa, mos `except` bloki ishga tushadi va dastur **to'xtamaydi**.

### Bir nechta xato turini birga ushlash

```python
try:
    fayl = open("mavjud_bolmagan.txt")
except (FileNotFoundError, PermissionError) as xato:
    print(f"Faylga muammo: {xato}")
```

`as xato` — xato obyektini o'zgaruvchiga saqlaydi, unda xatoning matnli tavsifi mavjud (`str(xato)` orqali ko'rish mumkin).

### Eng ko'p uchraydigan xato turlari

| Xato turi | Qachon yuzaga keladi |
|---|---|
| `ValueError` | Noto'g'ri qiymat (masalan, `int("salom")`) |
| `TypeError` | Noto'g'ri tur bilan amal (masalan, `"5" + 5`) |
| `KeyError` | Lug'atda mavjud bo'lmagan kalit (`dict["yoq_kalit"]`) |
| `IndexError` | Ro'yxat chegarasidan tashqari indeks (`royxat[100]`) |
| `ZeroDivisionError` | Nolga bo'lish |
| `FileNotFoundError` | Mavjud bo'lmagan faylni ochish |
| `AttributeError` | Mavjud bo'lmagan metod/atributga murojaat |
| `ImportError`/`ModuleNotFoundError` | Mavjud bo'lmagan modulni import qilish |

### `else` va `finally`

```python
try:
    son = int(input("Musbat son kiriting: "))
except ValueError:
    print("Bu son emas!")
else:
    # FAQAT try bloki XATOSIZ tugasa ishga tushadi
    print(f"Rahmat, siz {son} kiritdingiz")
finally:
    # HAR DOIM ishga tushadi — xato bo'lsa ham, bo'lmasa ham
    print("Dastur bu qismini yakunladi")
```

`else` — try bloki muvaffaqiyatli o'tgandagina bajariladigan kod uchun (bu kodni xato tutish doirasidan "tashqariga" chiqarish, tasodifan boshqa xatoni ham ushlab qolmaslik uchun foydali). `finally` — resurslarni tozalash (fayl yopish, ulanishni uzish) uchun ishlatiladi, natija qanday bo'lishidan qat'iy nazar bajariladi.

### `raise` — o'zingiz xato chiqarish

```python
def yosh_tekshir(yosh):
    if yosh < 0:
        raise ValueError("Yosh manfiy bo'lishi mumkin emas!")
    if yosh > 150:
        raise ValueError("Bu yosh ishonarli emas!")
    return yosh

try:
    yosh_tekshir(-5)
except ValueError as xato:
    print(f"Xato: {xato}")
```

### O'z maxsus istisno klassingizni yaratish

Katta loyihalarda o'ziga xos xatolarni **aniq nomlangan** klasslar bilan ifodalash tavsiya etiladi:

```python
class YetarliMablagYoqXatosi(Exception):
    """Hisobda yetarli mablag' bo'lmaganda ko'tariladi."""
    pass


class BankHisobi:
    def __init__(self, balans):
        self.balans = balans

    def yechish(self, summa):
        if summa > self.balans:
            raise YetarliMablagYoqXatosi(
                f"Balansda {self.balans} so'm bor, {summa} so'm yechib bo'lmaydi"
            )
        self.balans -= summa
        return self.balans


hisob = BankHisobi(50000)
try:
    hisob.yechish(100000)
except YetarliMablagYoqXatosi as xato:
    print(f"Amaliyot bekor qilindi: {xato}")
```

Maxsus istisno klasslari — barcha o'rnatilgan `Exception` klassidan meros oladi (to'g'ridan-to'g'ri yoki bilvosita). Bu — `except Exception:` orqali barcha xatolarni umumiy ushlash imkonini ham saqlab qoladi, lekin aniqroq xatolarni alohida ushlashga ham imkon beradi.

### Xatolar ierarxiyasi — aniqdan umumiyga

```python
try:
    natija = 10 / 0
except ZeroDivisionError:
    print("Aniq: nolga bo'lish")
except ArithmeticError:       # ZeroDivisionError'ning ota klassi
    print("Umumiyroq: matematik xato")
except Exception:              # deyarli barcha xatolarning ota klassi
    print("Eng umumiy: noma'lum xato")
```

> ⚠️ **Muhim: tartib muhim.** `except` bloklari **yuqoridan pastga**, birinchi mos kelgani ishga tushadi. Shuning uchun har doim **aniqroq** xato turlarini birinchi, **umumiyroq**larini keyin yozing — aks holda umumiy blok aniqroqni "to'sib qo'yadi" va u hech qachon ishlamaydi.

> ⚠️ **`except:` (turi ko'rsatilmagan) dan saqlaning.** `except:` — **barcha** xatolarni, hatto `KeyboardInterrupt` (Ctrl+C) kabi dastur to'xtatilishini ham ushlab qoladi, bu kutilmagan xatti-harakatlarga olib kelishi mumkin. Har doim aniq xato turini (yoki kamida `except Exception:`) ko'rsating.

## Amaliy misol

Xavfsiz kalkulyator — foydalanuvchi kiritgan ma'lumot bilan ishlash:

```python
# xavfsiz_kalkulyator.py

def xavfsiz_bolish(a, b):
    try:
        natija = a / b
    except ZeroDivisionError:
        print("Xato: nolga bo'lib bo'lmaydi")
        return None
    else:
        return natija


def foydalanuvchidan_son_ol(xabar):
    while True:
        try:
            return float(input(xabar))
        except ValueError:
            print("Iltimos, to'g'ri son kiriting (masalan: 5 yoki 3.14)")


birinchi_son = foydalanuvchidan_son_ol("Birinchi sonni kiriting: ")
ikkinchi_son = foydalanuvchidan_son_ol("Ikkinchi sonni kiriting: ")

natija = xavfsiz_bolish(birinchi_son, ikkinchi_son)
if natija is not None:
    print(f"Natija: {natija:.2f}")
```

`foydalanuvchidan_son_ol` — `while True` va `try/except`ni birlashtirib, foydalanuvchi **to'g'ri** qiymat kiritmaguncha qayta-qayta so'raydi — bu real dasturlarda juda ko'p ishlatiladigan naqsh.

## Keng tarqalgan xatolar

**Xato 1:** `except`ni juda umumiy (`Exception` yoki hech narsasiz) yozib, aniq xato sababini yashirish.
❌ 
```python
try:
    # 20 qatorlik murakkab kod
except:
    print("Xato yuz berdi")   # QAYSI xato? Qayerda? Bilib bo'lmaydi!
```
✅ To'g'ri: aniq xato turlarini alohida ushlang, va agar umumiy blok kerak bo'lsa, xatoning o'zini ham chiqaring: `except Exception as e: print(f"Xato: {e}")`.

**Xato 2:** xatoni "yutib yuborish" — hech narsa qilmasdan e'tiborsiz qoldirish.
❌ 
```python
try:
    muhim_amal()
except Exception:
    pass    # xato butunlay "yo'qoladi", hech kim bilmaydi nima noto'g'ri ketdi
```
✅ To'g'ri: hech bo'lmaganda xatoni logga yozing yoki foydalanuvchiga xabar bering — sukut saqlash debug qilishni deyarli imkonsiz qiladi.

**Xato 3:** `try` blokini haddan tashqari katta qilib, qaysi qator xato berganini bilmaslik.
❌ 
```python
try:
    a = int(input("A: "))
    b = int(input("B: "))
    natija = a / b
    fayl = open("natija.txt", "w")
    # ... yana 10 qator
except Exception as e:
    print("Xatolik")   # qaysi qatorda? int() da? open() da? / da?
```
✅ To'g'ri: `try` blokini imkon qadar **kichik va aniq** qismlarga bo'ling, har biri o'z mos xatosi bilan — bu xatoni tezroq aniqlash va tuzatishga yordam beradi.

## Mashq/topshiriq

**(Oson)** Foydalanuvchidan ikkita son so'rang va ularni bo'ling; `ValueError` va `ZeroDivisionError`ni alohida `except` bloklarida ushlab, mos xabar chiqaring.

**(O'rtacha)** `royxatdan_element_ol(royxat, indeks)` funksiyasini yozing — agar `indeks` chegaradan tashqari bo'lsa, `IndexError`ni ushlab, `"Bunday indeks mavjud emas"` deb qaytaring (funksiya `None` qaytarsin, dastur to'xtamasin).

**(Qiyin)** `YoshChegarasiXatosi(Exception)` maxsus istisno klassini yarating. `kirish_ruxsati(yosh)` funksiyasini yozing — agar `yosh < 18` bo'lsa, ushbu maxsus xatoni (`"Voyaga yetmagan, kirish taqiqlanadi"` xabari bilan) ko'tarsin; funksiyani `try/except` bilan chaqirib, xato ushlanganda mos xabar chiqaring.

## Qisqacha xulosa

`try`/`except` — dasturni kutilmagan xatolardan (noto'g'ri kiritilgan ma'lumot, mavjud bo'lmagan fayl, nolga bo'lish) himoya qilib, uni to'xtatmasdan boshqarish imkonini beradi; `else` faqat xatosiz holatda, `finally` esa har doim ishga tushadi; `raise` orqali o'zingiz xato chiqarish va o'z maxsus istisno klasslaringizni (`class MeningXatoim(Exception):`) yaratish — katta loyihalarda xatolarni aniq va tushunarli tarzda boshqarishning standart usuli.
