# Type hints (tur maslahatlari)

## Bu darsda nimalarni o'rganasiz

- Type hints nima ekanini va ular runtime'da qanday ishlashini (yoki ishlamasligini) tushunasiz
- Funksiya va o'zgaruvchilar uchun tur maslahatlarini yoza olasiz
- `list[int]`, `dict[str, int]`, `Optional`, `Union` kabi murakkab turlarni qo'llay olasiz
- `mypy` kabi statik tekshiruvchi vositalar nima uchun kerakligini bilasiz

## Nazariy qism

### Type hints — nima va nega kerak

Python — **dinamik tipланган** til, ya'ni o'zgaruvchi turi kodni ishga tushirish vaqtida (runtime) aniqlanadi, oldindan e'lon qilinmaydi. Bu moslashuvchanlik beradi, lekin katta loyihalarda funksiya qanday argument kutishini "taxmin qilish" qiyinlashadi:

```python
def hisobla(a, b):    # a va b qanday tur bo'lishi kerak? int? str? Kod o'qib bilib olish kerak
    return a + b
```

**Type hints** (Python 3.5+, PEP 484) — funksiya argumentlari va qaytarish qiymatlari uchun **maslahat** (hint) sifatida turlarni yozish imkonini beradi:

```python
def hisobla(a: int, b: int) -> int:
    return a + b
```

`a: int` — `a` argumenti `int` turida bo'lishi **kutiladi**; `-> int` — funksiya `int` qaytarishi kutiladi.

> ⚠️ **MUHIM: type hints runtime'da MAJBURLAMAYDI.** 
```python
def hisobla(a: int, b: int) -> int:
    return a + b

natija = hisobla("salom", "dunyo")    # bu ISHLAYDI! Python xato bermaydi!
print(natija)    # "salomdunyo" — string qo'shildi, hech qanday TypeError yo'q
```
Type hints — faqat **hujjatlashtirish** va **IDE/statik tekshiruvchilar** uchun signal, Python interpretatorining o'zi ularni ishga tushirish vaqtida tekshirmaydi va majburlamaydi.

### Nega baribir foydali — IDE va statik tekshiruv

Garchi runtime'da majburlanmasa ham, type hints ikkita katta amaliy foyda beradi:

1. **IDE yordami** — VS Code, PyCharm type hint'lar orqali avtomatik to'ldirish, xato ogohlantirishlarini (kod yozish paytida, ishga tushirmasdan) ko'rsatadi.
2. **Statik tekshiruvchilar** (`mypy`, `pyright`) — butun loyihani ishga tushirmasdan, faqat turlarni tahlil qilib, mos kelmasliklarni oldindan topadi.

```bash
pip install mypy
mypy main.py
```

```python
def hisobla(a: int, b: int) -> int:
    return a + b

hisobla("salom", "dunyo")   # mypy: error: Argument 1 to "hisobla" has incompatible type "str"; expected "int"
```

### Ro'yxat, lug'at va boshqa tuzilmalar (Python 3.9+)

Python 3.9'dan boshlab, `list`, `dict`, `set`, `tuple`ning o'zini to'g'ridan-to'g'ri generic (parametrlangan) tur sifatida ishlatish mumkin (bu kurs 3.12+ni asos qilib olgani uchun bu sintaksis to'liq ishlaydi):

```python
def ismlarni_chiqar(ismlar: list[str]) -> None:
    for ism in ismlar:
        print(ism)

def balllar_lugati(balllar: dict[str, int]) -> float:
    return sum(balllar.values()) / len(balllar)

def koordinata(x: int, y: int) -> tuple[int, int]:
    return (x, y)

def noyob_sonlar(sonlar: list[int]) -> set[int]:
    return set(sonlar)
```

### `Optional` va `Union` — "yo bu, yo u" turlar

```python
from typing import Optional, Union

def foydalanuvchi_top(id: int) -> Optional[str]:
    """Topilsa ism (str) qaytaradi, topilmasa None."""
    foydalanuvchilar = {1: "Ali", 2: "Vali"}
    return foydalanuvchilar.get(id)    # .get() topilmasa None qaytaradi

def id_yoki_nom(qiymat: Union[int, str]) -> str:
    """Qiymat int YOKI str bo'lishi mumkin."""
    return str(qiymat)
```

`Optional[str]` — `Union[str, None]`ning qisqartmasi, ya'ni "bu `str` yoki `None` bo'lishi mumkin" degan ma'noni bildiradi. Python 3.10'dan boshlab `Union[int, str]` o'rniga qisqaroq `int | str` sintaksisi ham ishlatilishi mumkin:

```python
def id_yoki_nom(qiymat: int | str) -> str:      # Python 3.10+ zamonaviy sintaksis
    return str(qiymat)

def foydalanuvchi_top(id: int) -> str | None:    # Optional[str] o'rniga
    ...
```

> 📌 **Bu kursda qaysi sintaksis ishlatiladi:** kurs 3.12+ asosida qurilgani uchun, zamonaviy `int | str` va `str | None` sintaksisi tavsiya etiladi — u qisqaroq va `typing`dan import qilishni talab qilmaydi. `Optional`/`Union` esa eski (3.9 va undan past) kodlarda ko'proq uchraydi, ularni tanish uchun bilish kerak.

### O'z klassларингиз uchun type hints

```python
class Foydalanuvchi:
    def __init__(self, ism: str, yosh: int) -> None:
        self.ism: str = ism
        self.yosh: int = yosh


def eng_katta_yosh(foydalanuvchilar: list[Foydalanuvchi]) -> int:
    return max(f.yosh for f in foydalanuvchilar)
```

### `TypeAlias` — murakkab turlarga nom berish (o'qilishni osonlashtirish)

```python
from typing import TypeAlias

# Murakkab turga qisqa, tushunarli nom berish:
Malumot: TypeAlias = dict[str, int | str | list[str]]

def qayta_ishla(malumot: Malumot) -> None:
    ...
```

## Amaliy misol

Type hints bilan yozilgan to'liq, o'qilishi oson funksiyalar to'plami:

```python
# talabalar_type_hints.py
from dataclasses import dataclass


@dataclass
class Talaba:
    ism: str
    ball: int
    fakultet: str


def eng_yaxshi_talaba(talabalar: list[Talaba]) -> Talaba | None:
    """Ro'yxat bo'sh bo'lsa None, aks holda eng yuqori ballli talabani qaytaradi."""
    if not talabalar:
        return None
    return max(talabalar, key=lambda t: t.ball)


def fakultet_boyicha_guruhlash(talabalar: list[Talaba]) -> dict[str, list[Talaba]]:
    """Fakultet nomi -> shu fakultetdagi talabalar ro'yxati."""
    natija: dict[str, list[Talaba]] = {}
    for talaba in talabalar:
        natija.setdefault(talaba.fakultet, []).append(talaba)
    return natija


def orta_ball(talabalar: list[Talaba]) -> float:
    """Talabalar bo'sh bo'lsa 0.0, aks holda o'rtacha ballni qaytaradi."""
    if not talabalar:
        return 0.0
    return sum(t.ball for t in talabalar) / len(talabalar)


talabalar: list[Talaba] = [
    Talaba("Ali", 85, "IT"),
    Talaba("Vali", 92, "IT"),
    Talaba("Guli", 78, "Iqtisodiyot"),
]

eng_yaxshi = eng_yaxshi_talaba(talabalar)
if eng_yaxshi is not None:
    print(f"Eng yaxshi talaba: {eng_yaxshi.ism} ({eng_yaxshi.ball} ball)")

print(f"O'rtacha ball: {orta_ball(talabalar):.1f}")

for fakultet, royxat in fakultet_boyicha_guruhlash(talabalar).items():
    ismlar = ", ".join(t.ism for t in royxat)
    print(f"{fakultet}: {ismlar}")
```

Diqqat qiling: `eng_yaxshi_talaba` funksiyasi `Talaba | None` qaytarishi mumkinligi type hint orqali **aniq ko'rsatilgan** — bu kodni o'qigan har qanday dasturchiga (yoki 6 oydan keyin sizning o'zingizga) "bu funksiya natijasini ishlatishdan oldin `None` ekanini tekshirish kerak" degan signalni beradi, hatto `mypy` ishlatilmasa ham.

## Keng tarqalgan xatolar

**Xato 1:** type hints runtime'da xatolarni ushlaydi deb noto'g'ri o'ylash.
❌ `def f(x: int) -> int: return x * 2` funksiyasiga `f("salom")` chaqirilsa, Python **xato bermaydi** — natija `"salomsalom"` bo'ladi, chunki `str * int` ishlaydi.
✅ To'g'ri: agar haqiqiy runtime tekshiruvi kerak bo'lsa, `isinstance()` bilan qo'lda tekshiring yoki `mypy`ni CI/CD jarayoniga (kod har safar joylashtirilishdan oldin) qo'shing — type hints o'zi bu xatoni ishga tushirish vaqtida ushlamaydi.

**Xato 2:** eski (`typing.List`, `typing.Dict`) va yangi (`list`, `dict`) sintaksisni aralashtirib, keraksiz importlar qilish.
❌ 
```python
from typing import List, Dict
def f(x: List[int]) -> Dict[str, int]:   # Python 3.9+ da keraksiz uzunlik
    ...
```
✅ To'g'ri: Python 3.9+ (bu kurs 3.12+ asos qilingan) da to'g'ridan-to'g'ri kichik harf bilan ishlating: `def f(x: list[int]) -> dict[str, int]:` — `typing`dan import qilish shart emas.

**Xato 3:** `None` qaytarishi mumkin bo'lgan funksiyada `Optional`/`| None`ni ko'rsatmaslik.
❌ `def foydalanuvchi_top(id: int) -> str:` — lekin funksiya aslida ba'zan `None` qaytarishi mumkin (masalan, `.get()` orqali). Bu — `mypy`ni chalg'itadi va funksiyani chaqiruvchi kod `None`ni kutmasdan xatoga duch kelishi mumkin.
✅ To'g'ri: agar funksiya `None` qaytarishi mumkin bo'lsa, buni har doim aniq ko'rsating: `-> str | None`.

## Mashq/topshiriq

**(Oson)** `kupaytir(a: int, b: int) -> int` funksiyasini to'liq type hints bilan yozing va uni chaqiring.

**(O'rtacha)** `eng_uzun_soz(sozlar: list[str]) -> str | None` funksiyasini yozing — bo'sh ro'yxat uchun `None`, aks holda eng uzun so'zni qaytarsin.

**(Qiyin)** `Buyurtma` nomli `@dataclass` klassini type hints bilan yozing (`mahsulot: str`, `narx: float`, `miqdor: int = 1`). So'ng `jami_narx_hisobla(buyurtmalar: list[Buyurtma]) -> float` funksiyasini yozing — barcha buyurtmalarning (`narx * miqdor`) yig'indisini qaytarsin. Agar `mypy` o'rnatilgan bo'lsa, faylni `mypy fayl_nomi.py` orqali tekshirib ko'ring.

## Qisqacha xulosa

Type hints (`x: int`, `-> str | None`) — Python'ning dinamik tabiatiga qo'shimcha, ixtiyoriy "hujjatlashtirish qatlami" bo'lib, runtime'da hech narsani majburlamaydi, lekin IDE'lar va `mypy` kabi statik tekshiruvchilar orqali xatolarni **ishga tushirishdan oldin** aniqlash imkonini beradi; `list[int]`, `dict[str, int]`, `X | None` (zamonaviy sintaksis) — eng ko'p ishlatiladigan ko'rinishlar bo'lib, katta loyihalarda (ayniqsa Django/DRF kabi freymvorklar bilan ishlaganda) kod sifatini va jamoaviy tushunishni sezilarli oshiradi — bu 5-bobning yakuniy, "professional kod yozish" ko'nikmalaridan biridir.
