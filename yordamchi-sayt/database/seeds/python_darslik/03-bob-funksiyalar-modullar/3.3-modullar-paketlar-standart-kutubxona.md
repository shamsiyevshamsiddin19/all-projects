# Modullar, paketlar va standart kutubxona

## Bu darsda nimalarni o'rganasiz

- `import`ning turli ko'rinishlarini (`import`, `from...import`, `as`) qo'llay olasiz
- O'z modulingizni yaratib, boshqa fayldan import qila olasiz
- Paket (package) va `__init__.py`ning vazifasini tushuntira olasiz
- Python standart kutubxonasining eng foydali modullarini bilasiz

## Nazariy qism

### Modul — bu shunchaki `.py` fayl

Har qanday `.py` fayl — Python uchun **modul** hisoblanadi. Boshqa fayldan uni import qilish mumkin:

```python
# matematika_yordamchi.py
def kvadrat(x):
    return x ** 2

def kub(x):
    return x ** 3

PI = 3.14159
```

```python
# main.py
import matematika_yordamchi

print(matematika_yordamchi.kvadrat(5))    # 25
print(matematika_yordamchi.PI)              # 3.14159
```

### `import`ning turli shakllari

```python
import math                          # butun modulni import qilish
print(math.sqrt(16))                  # math.sqrt(...) orqali murojaat

from math import sqrt, pi              # faqat kerakli qismlarni import qilish
print(sqrt(16))                        # to'g'ridan-to'g'ri, prefikssiz

from math import sqrt as ildiz          # nomni o'zgartirib import qilish (alias)
print(ildiz(16))

import numpy as np                      # keng tarqalgan konvensiya (uzun nomlarni qisqartirish)

from math import *                       # ❌ HAMMA narsani import qilish — tavsiya etilmaydi!
```

> ⚠️ **`from module import *` ishlatmang.** Bu barcha nomlarni joriy fayl qamroviga olib kiradi va qaysi funksiya qayerdan kelganini bilish qiyinlashadi, bundan tashqari mavjud o'zgaruvchilaringizni "yashirinib" almashtirib qo'yishi mumkin. Har doim aniq nima kerakligini `from module import nom1, nom2` ko'rinishida yozing.

### `if __name__ == "__main__":` — modul va skript farqi

```python
# hisoblagich.py

def qosh(a, b):
    return a + b

if __name__ == "__main__":
    # Bu blok FAQAT fayl to'g'ridan-to'g'ri ishga tushirilganda bajariladi:
    # `python3 hisoblagich.py`
    # Boshqa fayldan `import hisoblagich` qilinganda BAJARILMAYDI.
    print(qosh(2, 3))
```

Har bir Python fayli o'zining maxsus `__name__` o'zgaruvchisiga ega: agar fayl to'g'ridan-to'g'ri ishga tushirilsa, `__name__` qiymati `"__main__"` bo'ladi; agar boshqa fayldan import qilinsa — `__name__` shu modulning nomi (`"hisoblagich"`) bo'ladi. Bu — kodni **test qilish** (fayl alohida ishga tushirilganda) va **qayta ishlatish** (boshqa faylga import qilinganda, ortiqcha kod ishga tushmasdan) imkonini beruvchi standart Python konvensiyasi.

### Paket (package) — modullar to'plami

Paket — ichida `__init__.py` fayli bo'lgan papka:

```
loyiha/
├── main.py
└── yordamchilar/
    ├── __init__.py       # bu papkani "paket" qiladi (bo'sh bo'lishi ham mumkin)
    ├── matematik.py
    └── matnlar.py
```

```python
# main.py
from yordamchilar import matematik
from yordamchilar.matnlar import katta_harf_qil

print(matematik.kvadrat(4))
print(katta_harf_qil("salom"))
```

> 📌 **Python 3.3+ da:** `__init__.py` fayli texnik jihatdan majburiy emas (Python "namespace package"larni qo'llab-quvvatlaydi), lekin uni **aniq va tushunarli** qilish uchun barcha real loyihalarda hali ham qo'shish tavsiya etiladi — bu papkaning "bu shunchaki papka emas, bu Python paketi" ekanini bildiradi.

### Standart kutubxona — eng foydali modullar

Python "batteries included" (o'rnatilgan holda tayyor) falsafasiga ega — juda ko'p foydali modullar hech narsa o'rnatmasdan mavjud:

```python
import math
print(math.sqrt(25), math.pi, math.ceil(4.3), math.floor(4.7))

import random
print(random.randint(1, 10))          # 1 dan 10 gacha tasodifiy butun son
print(random.choice(["A", "B", "C"]))  # ro'yxatdan tasodifiy tanlash
royxat = [1, 2, 3, 4, 5]
random.shuffle(royxat)                  # ro'yxatni joyida aralashtirish
print(royxat)

from datetime import datetime, timedelta
hozir = datetime.now()
print(hozir.strftime("%Y-%m-%d %H:%M"))     # sana/vaqtni formatlash
ertaga = hozir + timedelta(days=1)            # sanaga qo'shish

import os
print(os.getcwd())                # joriy papka yo'li
print(os.listdir("."))             # papkadagi fayllar ro'yxati

import json
malumot = {"ism": "Ali", "yosh": 25}
matn = json.dumps(malumot)          # dict -> JSON matn
qayta = json.loads(matn)             # JSON matn -> dict

from collections import Counter, defaultdict
hisoblagich = Counter(["olma", "banan", "olma", "olma"])
print(hisoblagich)                    # Counter({'olma': 3, 'banan': 1})
print(hisoblagich.most_common(1))     # [('olma', 3)] — eng ko'p uchraganlar
```

| Modul | Vazifasi |
|---|---|
| `math` | Matematik funksiyalar (`sqrt`, `pi`, `ceil`, `floor`) |
| `random` | Tasodifiy sonlar va tanlovlar |
| `datetime` | Sana va vaqt bilan ishlash |
| `os` | Fayl tizimi va operatsion tizim bilan ishlash |
| `json` | JSON formatida ma'lumot almashish |
| `collections` | `Counter`, `defaultdict`, `namedtuple` kabi qo'shimcha tuzilmalar |
| `re` | Regulyar ifodalar (matn qidirish/almashtirish) |
| `sys` | Python interpretatori bilan bog'liq amallar |

`collections.defaultdict` — 2.5-darsda ko'rgan `.setdefault()` muammosini yanada qulayroq hal qiladi:

```python
from collections import defaultdict

guruhlar = defaultdict(list)     # agar kalit yo'q bo'lsa, avtomatik bo'sh list yaratadi
guruhlar["A"].append("Ali")
guruhlar["A"].append("Vali")
guruhlar["B"].append("Guli")
print(dict(guruhlar))    # {'A': ['Ali', 'Vali'], 'B': ['Guli']}
```

## Amaliy misol

Oddiy loyiha strukturasi — vaqt va tasodifiy ma'lumot generatori:

```python
# fayl: yordamchilar/vaqt_utils.py
from datetime import datetime

def joriy_sana():
    return datetime.now().strftime("%d.%m.%Y")

def joriy_vaqt():
    return datetime.now().strftime("%H:%M:%S")
```

```python
# fayl: yordamchilar/generator_utils.py
import random
import string

def tasodifiy_parol(uzunlik=10):
    belgilar = string.ascii_letters + string.digits
    return "".join(random.choice(belgilar) for _ in range(uzunlik))
```

```python
# fayl: main.py
from yordamchilar.vaqt_utils import joriy_sana, joriy_vaqt
from yordamchilar.generator_utils import tasodifiy_parol

print(f"Bugungi sana: {joriy_sana()}, vaqt: {joriy_vaqt()}")
print(f"Tasodifiy parol: {tasodifiy_parol(12)}")
```

`string.ascii_letters` — standart kutubxonaning `string` modulidagi barcha lotin harflarini (katta+kichik) o'z ichiga olgan tayyor satr; `string.digits` — `"0123456789"`.

## Keng tarqalgan xatolar

**Xato 1:** o'z faylini standart modul nomi bilan chalkashtirish (3-darsda ham eslatilgan, lekin bu yerda yana muhim).
❌ `random.py` nomli faylni loyihaga qo'shib, o'sha faylda `import random` yozish — Python o'z faylni import qiladi, standart `random` modulini emas.
✅ To'g'ri: fayllaringizga standart kutubxona modullari bilan bir xil nom bermang.

**Xato 2:** paket ichidagi `__init__.py`ni yaratishni unutish.
❌ `yordamchilar/` papkasida `__init__.py` bo'lmasa, ba'zi eski Python muhitlarida yoki ayrim vositalarda (masalan, ba'zi test yig'uvchilar) paket to'g'ri tanilmasligi mumkin.
✅ To'g'ri: har bir paket papkasida (hatto bo'sh bo'lsa ham) `__init__.py` faylini yarating — bu aniqlik va moslikni ta'minlaydi.

**Xato 3:** aylanma import (circular import).
❌ `a.py` faylida `from b import narsa`, `b.py` faylida esa `from a import boshqa_narsa` — bu `ImportError` yoki `AttributeError` ga olib keladi, chunki ikkala fayl bir-birini "kutib" qoladi.
✅ To'g'ri: modullarni loyihalashda funksional bog'liqliklarni bir yo'nalishli qiling (masalan, umumiy funksiyalarni alohida, uchinchi `utils.py` fayliga chiqaring), yoki importni funksiya ichiga ko'chiring (import faqat kerak bo'lganda bajariladi).

## Mashq/topshiriq

**(Oson)** `mening_modulim.py` nomli fayl yarating, unda `salomlash(ism)` funksiyasini yozing, so'ng boshqa `main.py` faylidan uni import qilib chaqiring.

**(O'rtacha)** `random` va `string` modullaridan foydalanib, 20 ta tasodifiy 4 xonali "kod" (masalan, tasdiqlash kodi) generatsiya qiluvchi ro'yxat yarating, so'ng `collections.Counter` yordamida ular orasida takroriy kod bor-yo'qligini tekshiring.

**(Qiyin)** Kichik paket yarating: `fayl_utils/` papkasi ichida `__init__.py`, `oquvchi.py` (JSON faylni o'qiydigan funksiya, `json` modulidan foydalanib) va `yozuvchi.py` (dict'ni JSON faylga yozadigan funksiya) fayllarini yozing, so'ng `main.py`dan ikkalasini ham import qilib, biror ma'lumotni faylga yozib, qayta o'qib ko'ring.

## Qisqacha xulosa

Har qanday `.py` fayl — modul, `__init__.py` bilan papka esa — paket bo'lib, `import`, `from...import` va `as` orqali kodni qismlarga bo'lib, qayta ishlatish mumkin; `if __name__ == "__main__":` — faylning skript sifatida ishga tushirilishi va modul sifatida import qilinishini ajratadi; Python'ning boy standart kutubxonasi (`math`, `random`, `datetime`, `os`, `json`, `collections`) esa ko'p keng tarqalgan vazifalar uchun tashqi kutubxona o'rnatmasdan tayyor yechim beradi — bu "batteries included" falsafasining amaliy ko'rinishi.
