# Shart operatorlari (if/elif/else, walrus, match-case)

## Bu darsda nimalarni o'rganasiz

- `if`/`elif`/`else` orqali dasturda tarmoqlanish yarata olasiz
- Python'da indentatsiya (chekinish) nega blokni belgilashda muhim ekanini tushuntira olasiz
- "Walrus operator" (`:=`) nima ekanini va qachon foydali bo'lishini bilasiz
- Python 3.10'dan kiritilgan `match`/`case` konstruksiyasini qo'llay olasiz

## Nazariy qism

### `if`/`elif`/`else` — asosiy tuzilma

```python
yosh = 20

if yosh < 18:
    print("Voyaga yetmagan")
elif yosh < 65:
    print("Kattalar")
else:
    print("Pensionerlar")
```

Python'da bloklarni belgilash uchun `{}` **ishlatilmaydi** — buning o'rniga **indentatsiya** (chekinish, odatda 4 bo'sh joy) ishlatiladi. Bu — tilning eng o'ziga xos xususiyatlaridan biri: chekinish noto'g'ri bo'lsa, kod ishlamaydi yoki xato beradi.

```python
# ❌ Indentatsiya yo'q
if yosh < 18:
print("Voyaga yetmagan")   # IndentationError: expected an indented block

# ✅ To'g'ri
if yosh < 18:
    print("Voyaga yetmagan")   # 4 bo'sh joy chekinish
```

### Ichma-ich (nested) shartlar

```python
balans = 500000
parol_togri = True

if parol_togri:
    if balans > 0:
        print("Pul yechish mumkin")
    else:
        print("Balansda mablag' yo'q")
else:
    print("Parol noto'g'ri")
```

### Bir qatorlik shart (ternary/conditional expression)

```python
yosh = 20
holat = "kattalar" if yosh >= 18 else "voyaga yetmagan"
print(holat)     # kattalar
```

Bu — `if/else`ning **ifoda** (expression) ko'rinishi, ko'p qatorlik blok yozish o'rniga bitta qatorda qiymat tanlashda ishlatiladi.

### Murakkab shartlar — `and`, `or`, `not`

```python
yosh = 25
haydovchilik_guvohnomasi = True

if yosh >= 18 and haydovchilik_guvohnomasi:
    print("Mashina haydashi mumkin")

kun = "shanba"
if kun == "shanba" or kun == "yakshanba":
    print("Dam olish kuni")
```

### Walrus operator (`:=`) — Python 3.8+

**Walrus operator** (`:=`, "morj operatori" — belgisi morjning tishlariga o'xshagani uchun shunday nomlangan) — qiymatni **bir vaqtning o'zida** o'zgaruvchiga yozish **va** shartda ishlatish imkonini beradi:

```python
# Walrus'siz — ikki qadam:
narx = float(input("Narx: "))
if narx > 100000:
    print(f"Qimmat mahsulot: {narx}")

# Walrus bilan — bitta qatorda:
if (narx := float(input("Narx: "))) > 100000:
    print(f"Qimmat mahsulot: {narx}")
```

Bu ayniqsa sikllarda (masalan, fayl qatorlarini o'qishda) kodni qisqartiradi:

```python
# Ro'yxatning uzunligi bilan ishlash misoli
mahsulotlar = ["olma", "banan", "uzum"]
if (soni := len(mahsulotlar)) > 2:
    print(f"{soni} ta mahsulot bor, bu 2 tadan ko'p")
```

### `match`/`case` — Python 3.10'dan kiritilgan struktura mosligi

`match`/`case` — boshqa tillardagi `switch`ga o'xshaydi, lekin ancha kuchliroq (struktura va tur bo'yicha ham mos kelishi mumkin):

```python
buyruq = "salom"

match buyruq:
    case "salom":
        print("Salom, qandaysiz?")
    case "xayr":
        print("Ko'rishguncha!")
    case _:
        print("Tushunmadim")   # _ — "boshqa hamma narsa" (default holat)
```

Bir nechta qiymatni bitta `case`da tekshirish:

```python
kun_raqami = 6

match kun_raqami:
    case 1 | 2 | 3 | 4 | 5:
        print("Ish kuni")
    case 6 | 7:
        print("Dam olish kuni")
    case _:
        print("Noto'g'ri kun raqami")
```

Struktura bo'yicha moslikni tekshirish (masalan, `tuple` yoki `dict` bilan):

```python
buyurtma = ("pizza", 2)

match buyurtma:
    case (mahsulot, soni) if soni > 1:
        print(f"{soni} ta {mahsulot} buyurtma qilindi (ko'p sonli)")
    case (mahsulot, 1):
        print(f"1 ta {mahsulot} buyurtma qilindi")
```

`match`/`case` — har doim `if/elif`ni almashtirishi shart emas, lekin ko'p variantli, ayniqsa struktura bo'yicha tekshiruv kerak bo'lgan holatlarda kodni ancha o'qilishi osonroq qiladi.

## Amaliy misol

Oddiy baho tizimi:

```python
# baho_tizimi.py

ball = int(input("Ballingizni kiriting (0-100): "))

if not (0 <= ball <= 100):
    print("Xato: ball 0 dan 100 gacha bo'lishi kerak")
elif ball >= 90:
    baho = "A'lo"
elif ball >= 70:
    baho = "Yaxshi"
elif ball >= 60:
    baho = "Qoniqarli"
else:
    baho = "Qoniqarsiz"

if 0 <= ball <= 100:
    print(f"Sizning bahoyingiz: {baho}")
```

`0 <= ball <= 100` — Python'ning **zanjirli taqqoslash** (chained comparison) imkoniyati — bu `0 <= ball and ball <= 100` bilan bir xil, lekin qisqaroq va matematik yozuvga yaqinroq.

## Keng tarqalgan xatolar

**Xato 1:** `elif`ni unutib, bir nechta alohida `if` yozish.
❌ 
```python
if ball >= 90:
    baho = "A'lo"
if ball >= 70:      # bu ham tekshiriladi, hatto birinchisi True bo'lsa ham!
    baho = "Yaxshi"
```
Bu holda `ball = 95` bo'lsa, avval `baho = "A'lo"`, keyin darhol `baho = "Yaxshi"`ga qayta yoziladi — natija noto'g'ri.
✅ To'g'ri: bir-birini istisno qiluvchi shartlar uchun har doim `elif` ishlating — faqat birinchi mos kelgan shart bajariladi, qolganlari **tekshirilmaydi** ham.

**Xato 2:** indentatsiyada bo'sh joy va tab'ni aralashtirib ishlatish.
❌ Ba'zi qatorlarda bo'sh joy, ba'zilarida tab ishlatilsa — `TabError: inconsistent use of tabs and spaces` xatosi chiqishi mumkin.
✅ To'g'ri: matn muharritingizni (VS Code) har doim Tab bosilganda 4 ta bo'sh joy qo'yadigan qilib sozlang — bu standart va PEP 8 tavsiyasi.

**Xato 3:** `match`da `case _`ni (default holatni) unutish.
❌ Agar hech qanday `case` mos kelmasa va `case _` bo'lmasa, `match` **hech narsa qilmay**, jimgina o'tib ketadi — bu kutilmagan xatolarni "yashirishi" mumkin.
✅ To'g'ri: odatda oxirida `case _:` qo'shib, kutilmagan holatlarni aniq boshqaring (masalan, xato xabari chiqarish).

## Mashq/topshiriq

**(Oson)** Foydalanuvchidan sonni so'rang va u musbat, manfiy yoki nolga tengligini `if/elif/else` bilan aniqlang.

**(O'rtacha)** Foydalanuvchidan oyning raqamini (1-12) so'rang va `match/case` yordamida qaysi fasl (qish, bahor, yoz, kuz) ekanini chiqaring (`case 12 | 1 | 2:` kabi guruhlash bilan).

**(Qiyin)** Walrus operatordan foydalanib, foydalanuvchidan parol so'rang va agar parol uzunligi (`len()`) 8 dan kam bo'lsa, "Parol juda qisqa (uzunligi: N)" deb, uzunlikni ham ko'rsatib xabar bering — buni bitta `if` qatorida, `len()`ni ikki marta chaqirmasdan yozing.
