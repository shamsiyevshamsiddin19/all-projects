# O'zgaruvchilar, ma'lumot turlari va operatorlar

## Bu darsda nimalarni o'rganasiz

- O'zgaruvchi yaratish va unga qiymat berish qoidalarini bilasiz
- Python'ning asosiy ma'lumot turlarini (`int`, `float`, `str`, `bool`) ajrata olasiz
- Arifmetik, taqqoslash va mantiqiy operatorlardan foydalana olasiz
- `type()` va tur o'zgartirish (`int()`, `str()`, `float()`) funksiyalarini qo'llay olasiz

## Nazariy qism

### O'zgaruvchi nima

**O'zgaruvchi** (variable) — xotiradagi qiymatga berilgan nom. Python'da o'zgaruvchi e'lon qilish uchun tur ko'rsatish shart emas (masalan, C++ yoki Java'dagidek `int x = 5;` emas) — Python turlarni **avtomatik aniqlaydi**:

```python
yosh = 25
ism = "Ali"
narx = 15.5
faol = True
```

### Nomlash qoidalari

- Faqat harflar, raqamlar va pastki chiziq (`_`) ishlatiladi, **raqam bilan boshlanmaydi**
- Katta-kichik harf farqlanadi (`yosh` va `Yosh` — ikki xil o'zgaruvchi)
- Python'ning zaxira so'zlari (`if`, `for`, `class`, `import` va h.k.) o'zgaruvchi nomi bo'la olmaydi
- Konvensiya (PEP 8): `snake_case` — `foydalanuvchi_ismi`, `mahsulot_narxi`

```python
# ❌ noto'g'ri
1ta_son = 5          # raqamdan boshlangan
class = "matematika" # zaxira so'z

# ✅ to'g'ri
birinchi_son = 5
fan_nomi = "matematika"
```

### Asosiy ma'lumot turlari

| Tur | Tavsif | Misol |
|---|---|---|
| `int` | Butun son | `42`, `-7`, `0` |
| `float` | Kasr son | `3.14`, `-0.5`, `2.0` |
| `str` | Matn (satr) | `"salom"`, `'Python'` |
| `bool` | Mantiqiy (rost/yolg'on) | `True`, `False` |
| `NoneType` | "Qiymat yo'q"ni bildiradi | `None` |

Turni tekshirish uchun `type()` funksiyasi ishlatiladi:

```python
narx = 15000
print(type(narx))        # <class 'int'>
print(type(15.0))         # <class 'float'>
print(type("salom"))      # <class 'str'>
print(type(True))         # <class 'bool'>
print(type(None))         # <class 'NoneType'>
```

### Arifmetik operatorlar

| Operator | Ma'nosi | Misol | Natija |
|---|---|---|---|
| `+` | Qo'shish | `5 + 3` | `8` |
| `-` | Ayirish | `5 - 3` | `2` |
| `*` | Ko'paytirish | `5 * 3` | `15` |
| `/` | Bo'lish (har doim `float` qaytaradi) | `5 / 2` | `2.5` |
| `//` | Butun bo'lish | `5 // 2` | `2` |
| `%` | Qoldiq (modulo) | `5 % 2` | `1` |
| `**` | Daraja | `5 ** 2` | `25` |

### Taqqoslash va mantiqiy operatorlar

```python
print(5 > 3)        # True
print(5 == 5)        # True — teng (== ikkita teng belgi!)
print(5 != 3)        # True — teng emas
print(5 >= 5)        # True

print(True and False)   # False — ikkalasi ham True bo'lishi kerak
print(True or False)    # True — kamida bittasi True bo'lsa yetadi
print(not True)          # False — teskarisiga aylantiradi
```

> ⚠️ **Muhim: `=` va `==` chalkashtirmang.** `=` — qiymat berish (assignment), `==` — taqqoslash. `if yosh = 18:` — `SyntaxError` beradi, to'g'risi `if yosh == 18:`.

### Tur o'zgartirish (type casting)

```python
son_matn = "25"
son = int(son_matn)      # "25" -> 25 (str dan int ga)
narx = float("15.5")      # "15.5" -> 15.5
matn = str(100)            # 100 -> "100" (int dan str ga)

print(son + 5)             # 30 — endi haqiqiy son sifatida qo'shish mumkin
```

> ⚠️ **Diqqat:** `int("salom")` — `ValueError: invalid literal for int()` xatosini beradi, chunki `"salom"` sonli matn emas. Foydalanuvchidan olingan matnni songa o'girishdan oldin uning to'g'ri formatda ekanini tekshirish kerak (5-bobda `try/except` bilan bunday xatolarni qanday ushlashni ko'ramiz).

## Amaliy misol

Oddiy narx hisoblovchi:

```python
# narx_hisoblash.py

mahsulot_nomi = "Noutbuk"
narx = 8500000          # so'mda
chegirma_foizi = 15
soliq_foizi = 12

chegirma_summasi = narx * chegirma_foizi / 100
narx_chegirmadan_keyin = narx - chegirma_summasi
soliq_summasi = narx_chegirmadan_keyin * soliq_foizi / 100
yakuniy_narx = narx_chegirmadan_keyin + soliq_summasi

print("Mahsulot:", mahsulot_nomi)
print("Asl narx:", narx, "so'm")
print("Chegirma:", chegirma_summasi, "so'm")
print("Yakuniy narx:", round(yakuniy_narx), "so'm")
```

`round()` — built-in funksiya, kasr sonni eng yaqin butun songa (yoki ko'rsatilgan raqamgacha, masalan `round(x, 2)`) yaxlitlaydi.

## Keng tarqalgan xatolar

**Xato 1:** `int` va `str`ni to'g'ridan-to'g'ri qo'shishga urinish.
❌ `yosh = 25; print("Yoshim: " + yosh)` — `TypeError: can only concatenate str (not "int") to str` xatosini beradi.
✅ To'g'ri: `print("Yoshim: " + str(yosh))` yoki (tavsiya etiladigan usul) `print(f"Yoshim: {yosh}")` (f-string — keyingi darsda batafsil).

**Xato 2:** `/` va `//`ni farqlamaslik.
❌ Butun son kutilganda `/` ishlatib, kutilmagan `float` natija olish: `10 / 2` → `5.0` (nazariyada `5` kutilgan bo'lishi mumkin).
✅ To'g'ri: agar aniq butun bo'lish natijasi kerak bo'lsa, `//` ishlating: `10 // 2` → `5` (`int`).

**Xato 3:** qat'iy teng belgi (`==`) o'rniga qiymat berish belgisini (`=`) shartda ishlatish.
❌ `if narx = 0:` — bu `SyntaxError` beradi (Python bunga umuman yo'l qo'ymaydi, C tilidan farqli).
✅ To'g'ri: taqqoslash uchun har doim `==` ishlating: `if narx == 0:`.

## Mashq/topshiriq

**(Oson)** `uzunlik_sm = 180` o'zgaruvchisini yarating va uni metrga (`uzunlik_m`) o'girib chiqaring (`180 / 100`).

**(O'rtacha)** Foydalanuvchi yoshini ifodalovchi `yosh = "23"` (matn ko'rinishida) o'zgaruvchisi berilgan. Uni `int`ga o'girib, 5 yildan keyingi yoshni hisoblab chiqaring.

**(Qiyin)** Ikkita butun son (`a = 17`, `b = 5`) berilgan. `//` va `%` operatorlaridan foydalanib, "17 ni 5 ga bo'lganda 3 marta to'liq sig'adi va 2 qoladi" ma'nosidagi jumlani f-string ishlatmasdan, `+` va `str()` orqali yasab chiqaring.

<summary>Javoblarni ko'rish</summary>

1. `uzunlik_m = uzunlik_sm / 100` → `1.8`.
2. `yosh = int("23")`, so'ng `yangi_yosh = yosh + 5` → `28`.
3. `natija = str(a) + " ni " + str(b) + " ga bo'lganda " + str(a // b) + " marta to'liq sig'adi va " + str(a % b) + " qoladi"` — natija: "17 ni 5 ga bo'lganda 3 marta to'liq sig'adi va 2 qoladi".

## Qisqacha xulosa

Python'da o'zgaruvchilar tur ko'rsatmasdan yaratiladi va turlari avtomatik aniqlanadi (`int`, `float`, `str`, `bool`, `None`), `type()` orqali tur tekshiriladi, `int()`/`str()`/`float()` orqali turlar orasida o'girish (casting) amalga oshiriladi; arifmetik (`+ - * / // % **`), taqqoslash (`== != > < >= <=`) va mantiqiy (`and or not`) operatorlar — keyingi barcha darslarda (shartlar, sikllar) doimiy ishlatiladigan asosiy quruvchi bloklardir.
