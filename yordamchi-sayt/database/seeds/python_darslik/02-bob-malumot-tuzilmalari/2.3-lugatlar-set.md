# Lug'atlar (dict) va Set

## Bu darsda nimalarni o'rganasiz

- Lug'at (`dict`) yaratish, o'qish, yangilash va o'chirishni bajara olasiz
- Lug'at bo'ylab aylanishning turli usullarini (`.keys()`, `.values()`, `.items()`) bilasiz
- `set` (to'plam) nima ekanini va uni qachon ishlatishni tushuntira olasiz
- `dict` va `set`ning ichki ishlash prinsipi (hash) nega ularni tez qilishini tushunasiz

## Nazariy qism

### Lug'at (dict) — kalit-qiymat juftliklari

```python
odam = {
    "ism": "Aziz",
    "yosh": 28,
    "shahar": "Samarqand"
}

print(odam["ism"])          # Aziz — kalit orqali qiymatga murojaat
odam["yosh"] = 29             # qiymatni yangilash
odam["kasb"] = "dasturchi"    # yangi kalit-qiymat qo'shish
del odam["shahar"]             # kalitni o'chirish

print(odam)   # {'ism': 'Aziz', 'yosh': 29, 'kasb': 'dasturchi'}
```

Python 3.7'dan boshlab lug'atlar elementlarni **qo'shilgan tartibida** saqlaydi (bu rasmiy kafolat).

### Mavjud bo'lmagan kalitga xavfsiz murojaat — `.get()`

```python
print(odam["email"])          # KeyError: 'email' — dastur to'xtaydi!

print(odam.get("email"))                       # None — xato bermaydi
print(odam.get("email", "kiritilmagan"))       # "kiritilmagan" — standart qiymat bilan
```

`.get(kalit, standart_qiymat)` — kalit mavjud bo'lmasa xato bermasdan, standart qiymatni qaytaradi. Bu — foydalanuvchi kiritgan yoki tashqi manbadan kelgan ma'lumot bilan ishlashda **eng xavfsiz** usul.

### Lug'at bo'ylab aylanish

```python
odam = {"ism": "Aziz", "yosh": 28, "kasb": "dasturchi"}

for kalit in odam:                  # standart holda kalitlar bo'ylab aylanadi
    print(kalit)

for kalit, qiymat in odam.items():   # kalit va qiymat birga
    print(f"{kalit}: {qiymat}")

for qiymat in odam.values():         # faqat qiymatlar
    print(qiymat)

print(list(odam.keys()))              # ['ism', 'yosh', 'kasb']
```

### Kalit mavjudligini tekshirish

```python
if "ism" in odam:            # `in` — dict'da KALITLAR ichidan qidiradi (tez, O(1))
    print("Ism mavjud")

if "email" not in odam:
    print("Email kiritilmagan")
```

### Ichma-ich (nested) lug'atlar — real hayotda eng ko'p uchraydigan holat

```python
foydalanuvchilar = {
    "user1": {"ism": "Ali", "yosh": 25, "faol": True},
    "user2": {"ism": "Vali", "yosh": 30, "faol": False},
}

print(foydalanuvchilar["user1"]["ism"])    # Ali

for user_id, malumot in foydalanuvchilar.items():
    holat = "faol" if malumot["faol"] else "faol emas"
    print(f"{user_id}: {malumot['ism']} ({holat})")
```

### Set (to'plam) — takrorlanmaydigan, tartibsiz elementlar

```python
ranglar = {"qizil", "yashil", "ko'k", "qizil"}   # takroriy "qizil" avtomatik olib tashlanadi
print(ranglar)     # {'qizil', 'yashil', 'ko'k'} — faqat 3 ta noyob element

ranglar.add("sariq")
ranglar.remove("yashil")
print("qizil" in ranglar)    # True — juda tez tekshirish (O(1))
```

`set` — asosan ikkita maqsadda ishlatiladi: (1) ro'yxatdan **takroriy elementlarni olib tashlash**, (2) ikkita to'plam orasidagi **matematik amallar** (kesishma, birlashma, farq):

```python
ro_a = {1, 2, 3, 4}
ro_b = {3, 4, 5, 6}

print(ro_a | ro_b)     # {1, 2, 3, 4, 5, 6} — birlashma (union)
print(ro_a & ro_b)     # {3, 4} — kesishma (intersection)
print(ro_a - ro_b)     # {1, 2} — farq (faqat ro_a'da bor)
print(ro_a ^ ro_b)     # {1, 2, 5, 6} — simmetrik farq (ikkalasida ham bo'lmagan)
```

Ro'yxatdan takroriy elementlarni olib tashlash uchun tezkor usul:

```python
royxat = [1, 2, 2, 3, 3, 3, 4]
noyob = list(set(royxat))     # ro'yxat -> set (takroriylar yo'qoladi) -> qayta ro'yxat
print(sorted(noyob))            # [1, 2, 3, 4]
```

### Nega `dict` va `set` bunchalik tez — hash tushunchasi

`dict` va `set` — ichki tuzilmasi bo'yicha **hash-jadval** asosida ishlaydi: har bir kalit (yoki `set` elementi) uchun maxsus "hash" (raqamli kod) hisoblanadi, va shu hash orqali element to'g'ridan-to'g'ri joyidan topiladi — `list`dagi kabi boshidan oxirigacha qidirish shart emas. Shuning uchun `kalit in dict` yoki `element in set` — ro'yxatdagi `element in list`ga qaraganda katta hajmdagi ma'lumotlarda ancha tezroq ishlaydi. Aynan shu sababdan **faqat immutable (o'zgarmas) obyektlar** (`str`, `int`, `tuple`) `dict` kaliti yoki `set` elementi bo'la oladi — `list` esa bo'la olmaydi, chunki u o'zgaruvchan.

## Amaliy misol

Oddiy telefon kitobi (kontaktlar boshqaruvi):

```python
# kontaktlar.py

kontaktlar = {
    "Ali": "+998901234567",
    "Vali": "+998907654321",
}

while True:
    buyruq = input("\nBuyruq (qo'sh/ko'r/och/chiq): ").strip().lower()

    if buyruq == "qo'sh":
        ism = input("Ism: ")
        raqam = input("Raqam: ")
        kontaktlar[ism] = raqam
        print(f"{ism} qo'shildi.")
    elif buyruq == "ko'r":
        for ism, raqam in kontaktlar.items():
            print(f"{ism}: {raqam}")
    elif buyruq == "och":
        ism = input("Qaysi ismni izlaymiz? ")
        raqam = kontaktlar.get(ism, "Topilmadi")
        print(f"{ism}: {raqam}")
    elif buyruq == "chiq":
        break
    else:
        print("Noma'lum buyruq")
```

## Keng tarqalgan xatolar

**Xato 1:** mavjud bo'lmagan kalitga to'g'ridan-to'g'ri `[]` orqali murojaat qilish.
❌ `print(odam["email"])` — kalit mavjud bo'lmasa, `KeyError` beradi va dastur to'xtaydi.
✅ To'g'ri: agar kalit mavjudligiga ishonch bo'lmasa, `.get(kalit, standart)` ishlating yoki oldindan `if kalit in odam:` bilan tekshiring.

**Xato 2:** bo'sh `set` yaratish uchun `{}` ishlatish.
❌ `boshsh_set = {}` — bu aslida **bo'sh dict** yaratadi, `set` emas! `type({})` → `<class 'dict'>`.
✅ To'g'ri: bo'sh `set` yaratish uchun `set()` funksiyasi ishlatiladi: `boshsh_set = set()`.

**Xato 3:** lug'at bo'ylab aylanayotganda uni o'zgartirish (kalit qo'shish/o'chirish).
❌ 
```python
for kalit in odam:
    if odam[kalit] is None:
        del odam[kalit]     # RuntimeError: dictionary changed size during iteration
```
✅ To'g'ri: aylanish paytida lug'atni o'zgartirish kerak bo'lsa, avval kalitlar ro'yxatining **nusxasi** bo'yicha aylaning: `for kalit in list(odam.keys()):`.

## Mashq/topshiriq

**(Oson)** Mahsulot nomlari va narxlarini o'z ichiga olgan lug'at yarating (kamida 4 ta mahsulot), so'ng barcha mahsulotlar va narxlarini chiroyli formatda chiqaring.

**(O'rtacha)** Berilgan matndagi (`matn = "salom dunyo salom python dunyo salom"`) har bir so'z necha marta uchraganini hisoblab, lug'at ko'rinishida chiqaring (`.split()` va lug'atdan foydalaning, `.get()` bilan hisoblagichni oshiring).

**(Qiyin)** Ikkita guruh talabalarining ismlari ro'yxat ko'rinishida berilgan: `guruh_a = ["Ali", "Vali", "Guli"]`, `guruh_b = ["Vali", "Sardor", "Guli"]`. `set` amallaridan foydalanib: (1) ikkala guruhda ham bo'lgan talabalarni, (2) faqat A guruhida bo'lganlarni, (3) ikkala guruhdagi barcha noyob talabalarni toping.

## Qisqacha xulosa

`dict` — kalit-qiymat juftliklarini saqlaydi va `.get()`, `.items()`, `.keys()`, `.values()` orqali xavfsiz ishlashni ta'minlaydi; `set` — takrorlanmaydigan elementlar to'plami bo'lib, tezkor mavjudlik tekshiruvi va matematik to'plam amallari (`|`, `&`, `-`, `^`) uchun ishlatiladi; ikkalasi ham hash-jadval asosida ishlagani uchun `list`ga qaraganda katta ma'lumotlarda ancha tezroq — bu ularni real loyihalarda (ma'lumotlar bazasi natijalari, konfiguratsiya, keshlash) eng ko'p ishlatiladigan tuzilmalarga aylantiradi.
