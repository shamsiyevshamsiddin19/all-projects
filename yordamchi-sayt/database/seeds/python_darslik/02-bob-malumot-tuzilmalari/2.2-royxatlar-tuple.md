# Ro'yxatlar (list) va Tuple

## Bu darsda nimalarni o'rganasiz

- Ro'yxat (`list`) yarata, o'zgartira va uning metodlaridan foydalana olasiz
- `list` va `tuple` orasidagi asosiy farqni (mutable/immutable) tushuntira olasiz
- Ro'yxatlarni saralash, teskari aylantirish va nusxalash usullarini bilasiz
- Qachon `list`, qachon `tuple` ishlatish kerakligini tanlay olasiz

## Nazariy qism

### Ro'yxat (list) — o'zgaruvchan (mutable) ketma-ketlik

```python
mevalar = ["olma", "banan", "uzum"]

print(mevalar[0])        # olma
mevalar[1] = "shaftoli"   # elementni o'zgartirish — list mutable!
print(mevalar)             # ['olma', 'shaftoli', 'uzum']

mevalar.append("nok")      # oxiriga qo'shish
mevalar.insert(0, "anor")  # ma'lum joyga qo'shish
mevalar.remove("uzum")     # qiymat bo'yicha o'chirish
oxirgisi = mevalar.pop()   # oxirgisini o'chirib, qaytaradi
print(mevalar)
```

`str`dan farqli o'laroq, `list` — **mutable** (o'zgaruvchan): elementlarni to'g'ridan-to'g'ri o'zgartirish, qo'shish, o'chirish mumkin, yangi obyekt yaratish shart emas.

### Eng ko'p ishlatiladigan list metodlari

| Metod | Vazifasi |
|---|---|
| `.append(x)` | Oxiriga bitta element qo'shadi |
| `.extend([...])` | Boshqa ro'yxat elementlarini qo'shadi |
| `.insert(i, x)` | `i`-indeksga element qo'shadi |
| `.remove(x)` | Birinchi topilgan `x` qiymatini o'chiradi |
| `.pop(i)` | `i`-indeksdagi elementni o'chirib, qaytaradi (standart: oxirgisi) |
| `.sort()` | Ro'yxatni **joyida** saralaydi |
| `.reverse()` | Ro'yxatni **joyida** teskari aylantiradi |
| `.count(x)` | `x` necha marta uchraganini sanaydi |
| `.index(x)` | `x`ning birinchi indeksini qaytaradi |

```python
sonlar = [5, 2, 8, 1, 9]

sonlar.sort()               # joyida saralaydi (asl ro'yxatni o'zgartiradi)
print(sonlar)                 # [1, 2, 5, 8, 9]

sonlar.sort(reverse=True)     # kamayish tartibida
print(sonlar)                 # [9, 8, 5, 2, 1]

# sort() o'rniga sorted() — YANGI ro'yxat qaytaradi, aslini o'zgartirmaydi
asl_royxat = [3, 1, 2]
yangi_royxat = sorted(asl_royxat)
print(asl_royxat)     # [3, 1, 2] — o'zgarmagan
print(yangi_royxat)    # [1, 2, 3]
```

### Ro'yxatlarni nusxalash — muhim nozik jihat

```python
royxat_a = [1, 2, 3]
royxat_b = royxat_a          # ❌ Bu nusxa EMAS — ikkalasi bitta obyektga ishora qiladi!
royxat_b.append(4)
print(royxat_a)                # [1, 2, 3, 4] — royxat_a HAM o'zgardi!

royxat_c = royxat_a.copy()    # ✅ Haqiqiy nusxa (copy())
# yoki: royxat_c = royxat_a[:]  # slicing orqali ham nusxa olinadi
royxat_c.append(5)
print(royxat_a)                # o'zgarmaydi, faqat royxat_c o'zgaradi
```

Bu — Python'dagi eng ko'p uchraydigan chalkashliklardan biri: `=` orqali ro'yxatni "nusxalash" aslida faqat **bitta xotira manzilига ikkinchi nom berish**, haqiqiy nusxa emas.

### Tuple — o'zgarmas (immutable) ketma-ketlik

```python
koordinata = (10, 20)
rang = "qizil", "yashil", "ko'k"   # qavssiz ham tuple bo'ladi

print(koordinata[0])    # 10
koordinata[0] = 15       # TypeError: 'tuple' object does not support item assignment
```

`tuple` — `list`ga juda o'xshaydi (indekslash, slicing ishlaydi), lekin **immutable**: yaratilgandan keyin o'zgartirib bo'lmaydi.

### Qachon `list`, qachon `tuple` ishlatiladi

| Holat | Tavsiya |
|---|---|
| Ma'lumot o'zgarishi kerak (qo'shish/o'chirish) | `list` |
| Ma'lumot o'zgarmasligi kafolatlanishi kerak (masalan, koordinata, sozlama) | `tuple` |
| Funksiyadan bir nechta qiymat qaytarish | `tuple` (odatiy amaliyot) |
| `dict` kaliti sifatida ishlatish | `tuple` (chunki `list` mutable — kalit bo'la olmaydi) |

```python
def minmax_topish(sonlar):
    return min(sonlar), max(sonlar)    # tuple qaytariladi

kichik, katta = minmax_topish([5, 2, 8, 1])   # "unpacking" — tuple'ni ikkiga ajratish
print(kichik, katta)    # 1 8
```

### Tuple unpacking (ajratib olish)

```python
odam = ("Vali", 25, "Toshkent")
ism, yosh, shahar = odam    # bitta qatorda uchtaga ajratish

a, b = 1, 2
a, b = b, a       # o'zgaruvchilarni almashtirish — Python'ning qulay xususiyati!
print(a, b)        # 2 1
```

## Amaliy misol

Talabalar ro'yxatini boshqarish:

```python
# talabalar.py

talabalar = ["Ali", "Vali", "Guli", "Dilnoza"]

print("Boshlang'ich ro'yxat:", talabalar)

talabalar.append("Sardor")
talabalar.remove("Vali")
talabalar.sort()

print("Yangilangan ro'yxat:", talabalar)
print("Jami talabalar:", len(talabalar))

# eng past va eng yuqori ballarni tuple orqali qaytaruvchi funksiya
ballar = [78, 92, 65, 88, 71]

def statistika(royxat):
    return min(royxat), max(royxat), sum(royxat) / len(royxat)

eng_past, eng_yuqori, orta = statistika(ballar)
print(f"Eng past: {eng_past}, Eng yuqori: {eng_yuqori}, O'rtacha: {orta:.1f}")
```

## Keng tarqalgan xatolar

**Xato 1:** `=` orqali ro'yxatni "nusxalash" deb o'ylash.
❌ `royxat_b = royxat_a` — bu nusxa emas, ikkalasi bitta ro'yxatga ishora qiladi, birini o'zgartirsangiz ikkalasi ham o'zgaradi.
✅ To'g'ri: haqiqiy nusxa uchun `.copy()` yoki `[:]` ishlating.

**Xato 2:** bitta elementli tuple yaratishda vergulni unutish.
❌ `tuple_emas = (5)` — bu aslida oddiy `int` (`5`), tuple emas! Chunki qavs bu yerda faqat guruhlash uchun.
✅ To'g'ri: bitta elementli tuple uchun vergul **shart**: `haqiqiy_tuple = (5,)`.

**Xato 3:** `.sort()` va `sorted()`ni bir-biriga chalkashtirish.
❌ `yangi = royxat.sort()` — `yangi` doim `None` bo'ladi! Chunki `.sort()` ro'yxatni **joyida** o'zgartiradi va hech narsa qaytarmaydi.
✅ To'g'ri: agar yangi, saralangan ro'yxat kerak bo'lsa (aslini o'zgartirmasdan) — `yangi = sorted(royxat)` ishlating; agar mavjud ro'yxatni o'zini saralash kerak bo'lsa — `royxat.sort()` (natijani o'zgaruvchiga yozmasdan) yetarli.

## Mashq/topshiriq

**(Oson)** `[10, 25, 3, 47, 8]` ro'yxatini yarating, uni o'sish tartibida saralang va eng katta hamda eng kichik elementlarni alohida chiqaring.

**(O'rtacha)** Ikkita ro'yxat berilgan: `xarajatlar = [15000, 32000, 8000]` va `sanalar = ["dushanba", "seshanba", "chorshanba"]`. `zip()` funksiyasidan foydalanib (yoki indeks orqali), har bir sana va unga mos xarajatni birga chiqaring.

**(Qiyin)** `koordinatalar = [(0, 0), (3, 4), (1, 1)]` — tuple'lardan iborat ro'yxat berilgan. Har bir koordinataning boshlang'ich nuqtadan (0,0) uzoqligini (`(x**2 + y**2) ** 0.5`) hisoblab, eng uzoq koordinatani (`max()` va `key` parametri bilan) toping.

<details>
<summary>Javoblarni ko'rish</summary>

1. `sonlar = [10, 25, 3, 47, 8]; sonlar.sort(); print(min(sonlar), max(sonlar))` → `3 47`.
2. `for sana, xarajat in zip(sanalar, xarajatlar): print(f"{sana}: {xarajat} so'm")`.
3. `import math` shart emas, `**0.5` yetarli: `eng_uzoq = max(koordinatalar, key=lambda k: (k[0]**2 + k[1]**2) ** 0.5)` → `(3, 4)` (masofasi `5.0`, eng katta).

</details>

## Qisqacha xulosa

`list` — o'zgaruvchan (mutable), tartiblangan ma'lumot to'plami bo'lib, `.append()`, `.remove()`, `.sort()` kabi metodlar orqali boshqariladi; `tuple` — o'xshash, lekin **immutable** ketma-ketlik, ko'pincha funksiyadan bir nechta qiymat qaytarishda yoki o'zgarmasligi kerak bo'lgan ma'lumotlar uchun ishlatiladi; ro'yxatni nusxalashda `=` emas, `.copy()` yoki `[:]` ishlatish kerakligini yodda tutish — Python'da eng ko'p uchraydigan xatolarning oldini oladi.
