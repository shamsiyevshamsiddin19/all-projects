# Satrlar (strings) bilan ishlash

## Bu darsda nimalarni o'rganasiz

- Satrlarni indekslash va "slicing" (kesib olish) orqali qismlarga bo'la olasiz
- Eng ko'p ishlatiladigan satr metodlarini (`.upper()`, `.split()`, `.join()` va h.k.) qo'llay olasiz
- Satrlarning **immutable** (o'zgarmas) ekanini tushuntira olasiz
- Ko'p qatorli satrlar va escape-belgilardan foydalana olasiz

## Nazariy qism

### Indekslash — bitta belgiga murojaat

```python
soz = "Python"

print(soz[0])     # P — birinchi belgi (indeks 0 dan boshlanadi)
print(soz[5])     # n — oltinchi belgi
print(soz[-1])    # n — oxirgi belgi (manfiy indeks — oxiridan sanaydi)
print(soz[-2])    # o — oxiridan ikkinchi
```

### Slicing — qism olish

`satr[boshlanish:tugash:qadam]` — `boshlanish` kiradi, `tugash` **kirmaydi**:

```python
soz = "Dasturlash"

print(soz[0:4])     # Dast
print(soz[4:])       # urlash — 4-indeksdan oxirigacha
print(soz[:4])       # Dast — boshidan 4-indeksgacha
print(soz[::2])      # Dsual — har ikkinchi belgi
print(soz[::-1])     # hsalrutsaD — teskari tartibda (butun satrni)
```

### Satrlar — immutable (o'zgarmas)

```python
soz = "salom"
soz[0] = "S"    # TypeError: 'str' object does not support item assignment
```

Python'da satrlar **o'zgartirib bo'lmaydi** — istalgan "o'zgartirish" aslida **yangi satr yaratadi**:

```python
soz = "salom"
yangi_soz = "S" + soz[1:]    # yangi satr yaratildi
print(yangi_soz)              # Salom
print(soz)                    # salom — asl satr o'zgarmagan
```

### Eng ko'p ishlatiladigan satr metodlari

```python
matn = "  Salom, Python dunyosi!  "

print(matn.strip())             # "Salom, Python dunyosi!" — boshi/oxiridagi bo'sh joylarni olib tashlaydi
print(matn.upper())              # katta harflarga
print(matn.lower())              # kichik harflarga
print(matn.strip().replace("Python", "dasturlash"))   # almashtirish
print(matn.strip().split(", "))  # ['Salom', 'Python dunyosi!'] — ro'yxatga bo'lish

soz_royxati = ["Salom", "Python", "dunyosi"]
print(" ".join(soz_royxati))     # "Salom Python dunyosi" — ro'yxatni satrga birlashtirish

print("Python" in matn)           # True — qatnashishni tekshirish
print(matn.strip().startswith("Salom"))   # True
print(matn.strip().endswith("!"))          # True
print(len(matn))                   # 27 — uzunlik (bo'sh joylar bilan)
print(matn.strip().find("Python")) # 7 — "Python" boshlangan indeks
```

| Metod | Vazifasi |
|---|---|
| `.strip()` | Boshi/oxiridagi bo'sh joylarni olib tashlaydi |
| `.upper()` / `.lower()` | Katta/kichik harfga o'giradi |
| `.split(ajratkich)` | Satrni ro'yxatga bo'ladi |
| `.join(royxat)` | Ro'yxatni satrga birlashtiradi |
| `.replace(eski, yangi)` | Qism satrni almashtiradi |
| `.find(qism)` | Qism satr indeksini topadi (topilmasa `-1`) |
| `in` | Qatnashishni tekshiradi (`True`/`False`) |

### Escape-belgilar va ko'p qatorli satrlar

```python
print("Ism:\tYosh")          # \t — tab (gorizontal joy)
print("Birinchi qator\nIkkinchi qator")   # \n — yangi qator
print("U \"Salom\" dedi")     # \" — qo'shtirnoqni satr ichida ishlatish

kop_qatorli = """Bu birinchi qator.
Bu ikkinchi qator.
Bu uchinchi qator."""
print(kop_qatorli)
```

Uch qo'shtirnoq (`"""..."""`) — ko'p qatorli satrlar yozish uchun, ko'pincha funksiya/fayl tavsifi (docstring) sifatida ham ishlatiladi.

### Raw string — escape-belgilarni o'chirish

```python
yol = "C:\Users\name"      # \U va \n escape sifatida talqin qilinishi mumkin, xato
yol_togri = r"C:\Users\name"   # r"..." — "raw string", escape-belgilar ishlamaydi
```

`r"..."` prefiksi ayniqsa fayl yo'llari va regulyar ifodalarda (RegEx) qo'llaniladi.

## Amaliy misol

Oddiy matn tahlilchisi:

```python
# matn_tahlil.py

matn = input("Matn kiriting: ").strip()

sozlar = matn.split()

print(f"Umumiy belgilar soni (bo'sh joysiz): {len(matn.replace(' ', ''))}")
print(f"So'zlar soni: {len(sozlar)}")
print(f"Katta harflar bilan: {matn.upper()}")
print(f"Teskari tartibda: {matn[::-1]}")

eng_uzun_soz = max(sozlar, key=len)
print(f"Eng uzun so'z: {eng_uzun_soz}")

if matn.lower() == matn.lower()[::-1]:
    print("Bu palindrom!")
else:
    print("Bu palindrom emas")
```

`max(sozlar, key=len)` — `sozlar` ro'yxatidagi eng uzun elementni, uzunligi (`len`) bo'yicha solishtirib topadi (`key` parametri — funksiyalar haqidagi keyingi bobda batafsil ko'riladi).

## Keng tarqalgan xatolar

**Xato 1:** satrni to'g'ridan-to'g'ri o'zgartirishga urinish.
❌ `ism = "ali"; ism[0] = "A"` — `TypeError: 'str' object does not support item assignment`.
✅ To'g'ri: `ism = "A" + ism[1:]` yoki `ism = ism.capitalize()` (birinchi harfni katta qiladigan tayyor metod) orqali **yangi** satr yarating.

**Xato 2:** slicing chegarasidan tashqariga chiqishdan qo'rqish (aslida xato bermaydi).
❌ Ko'p dasturchi `soz[0:100]` (satr uzunligi 6 bo'lsa ham) `IndexError` beradi deb o'ylaydi.
✅ To'g'ri: slicing hech qachon `IndexError` bermaydi — agar chegara oshib ketsa, Python shunchaki mavjud qismini qaytaradi (`soz[0:100]` — butun satrni qaytaradi, xato bermaydi). Lekin oddiy indekslash (`soz[100]`) chegaradan chiqsa, `IndexError` beradi.

**Xato 3:** `.split()`ni ajratkichsiz va bo'sh joylar ko'p bo'lganda noto'g'ri kutish.
❌ `"salom   dunyo".split(" ")` — `['salom', '', '', 'dunyo']` beradi (bo'sh satrlar bilan), chunki ajratkich aniq bitta bo'sh joy deb belgilangan.
✅ To'g'ri: agar bir nechta ketma-ket bo'sh joylarni bitta ajratkich sifatida ko'rish kerak bo'lsa, `.split()`ni **argumentsiz** chaqiring: `"salom   dunyo".split()` → `['salom', 'dunyo']`.

## Qisqacha xulosa

Satrlar Python'da **immutable** (o'zgarmas) bo'lib, indekslash (`soz[0]`) va slicing (`soz[1:4]`, `soz[::-1]`) orqali qismlarga bo'linadi; `.strip()`, `.split()`, `.join()`, `.replace()`, `.upper()`/`.lower()` — eng ko'p ishlatiladigan metodlar bo'lib, matn bilan ishlashning katta qismini (foydalanuvchi kiritgan ma'lumotni tozalash, tahlil qilish, formatlash) tashkil qiladi — bu metodlar deyarli har bir Python dasturida uchraydi.
