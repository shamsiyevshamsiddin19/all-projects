# Python nima, tarixi va o'rnatish

## Bu darsda nimalarni o'rganasiz

- Python nima ekanini va uni qayerda ishlatilishini tushuntira olasiz
- Joriy Python versiyalarini va ular orasidagi farqni bilasiz
- Python'ni kompyuteringizga to'g'ri o'rnata olasiz
- Virtual muhit (`venv`) yaratish nima uchun kerakligini tushuntira olasiz

## Nazariy qism

### Python nima va nega mashhur

**Python** — Guido van Rossum tomonidan 1991-yilda yaratilgan, oddiy va o'qilishi oson sintaksisga ega, umumiy maqsadli dasturlash tili. Python'ning asosiy falsafasi — kod **inson uchun o'qilishi oson** bo'lishi kerak, hatto bu ba'zan bir oz ko'proq belgi yozishni talab qilsa ham (masalan, boshqa tillardagi `{}` o'rniga Python'da qatorlar chekinishi — indentatsiya — orqali bloklarni belgilaydi).

Python bugungi kunda quyidagi sohalarda keng qo'llaniladi: veb-dasturlash (Django, FastAPI, Flask), ma'lumotlar tahlili va sun'iy intellekt (Pandas, NumPy, PyTorch, TensorFlow), avtomatlashtirish va skriptlar, Telegram botlar (Aiogram), va ilmiy hisob-kitoblar. Aynan shu ko'p qirralilik — Python'ning dunyoda eng ko'p o'rganiladigan tillardan biriga aylanishining asosiy sababi.

### Versiyalar haqida — nima tanlash kerak

Hozirgi kunda ikkita asosiy versiya keng qo'llaniladi: **Python 3.14** (2025-yil oktabrda chiqqan, eng so'nggi) va **Python 3.13** (hali ham ko'p loyihada barqaror ishlatiladi). Bu kursda **Python 3.12+** sintaksisi asos qilib olinadi — bu yerda o'rgatiladigan deyarli barcha narsa 3.10 va undan yuqori versiyalarda ishlaydi, faqat ba'zi eng yangi imkoniyatlar (masalan, 6-bobda ko'rilgan ba'zi tur maslahatlari sintaksisi) 3.12+ talab qilishi mumkin — bunday joylarda alohida eslatib o'tiladi.

> ⚠️ **Python 2 — butunlay eskirgan.** 2020-yildan beri rasmiy qo'llab-quvvatlash to'xtatilgan. Agar internetdan `print "salom"` (qavssiz `print`) kabi kod ko'rsangiz — bu Python 2, uni hech qachon ishlatmang.

### O'rnatish (Ubuntu)

_Ushbu kursdagi barcha terminal buyruqlari **Ubuntu** (va boshqa Debian-asosidagi distributivlar) uchun moslashtirilgan — chunki ko'pchilik server va development muhitlarida aynan shu tizim ishlatiladi._

Ubuntu'da odatda Python 3 tizim bilan birga allaqachon o'rnatilgan bo'ladi, lekin `pip` va `venv` modullari alohida paket sifatida qo'shilishi kerak bo'lishi mumkin:

```bash
sudo apt update
sudo apt install python3 python3-pip python3-venv -y
```

O'rnatishni tekshirish:

```bash
python3 --version
# Python 3.12.x  (yoki tizimingizdagi versiya)
```

> ⚠️ **Muhim: Ubuntu'da `python` emas, `python3`.** Ko'pchilik Ubuntu versiyasida `python` buyrug'i mavjud emas — faqat `python3` ishlaydi (bu ataylab shunday qilingan, chunki eski Python 2 bilan chalkashmaslik uchun). Xuddi shunday, paket o'rnatish uchun ham `pip3` ishlatiladi. Ushbu kursda barcha misollarda **`python3`** va **`pip3`** ishlatiladi — agar boshqa manbada oddiy `python`/`pip` ko'rsangiz, bilingki bu ko'pincha Windows yoki virtual muhit faollashtirilgan holat uchun yozilgan (virtual muhit ichida `python` va `python3` odatda bir xil narsaga ishora qiladi).

Agar eng so'nggi Python versiyasini (masalan, 3.13 yoki 3.14) rasmiy Ubuntu repozitoriyasida topa olmasangiz, `deadsnakes` PPA orqali qo'shish mumkin:

```bash
sudo add-apt-repository ppa:deadsnakes/ppa
sudo apt update
sudo apt install python3.13 python3.13-venv -y
```

### IDE (kod yozish muhiti) tanlash va o'rnatish

Yangi boshlovchi uchun eng ko'p tavsiya etiladigan ikkita variant: **VS Code** (bepul, yengil, Python kengaytmasi bilan) va **PyCharm** (Python uchun maxsus yaratilgan, ko'proq imkoniyatli, Community nashri bepul). Ikkalasi ham to'liq professional darajada ishlatilishi mumkin — tanlov shaxsiy did masalasi. Ubuntu'da ikkalasini ham `snap` orqali oson o'rnatish mumkin:

```bash
sudo snap install code --classic          # VS Code
sudo snap install pycharm-community --classic   # PyCharm Community
```

VS Code o'rnatilgach, ichida **Python** kengaytmasini (Microsoft tomonidan) o'rnatishni unutmang — bu sintaksis bo'yash, avtomatik to'ldirish va debug qilish imkoniyatlarini beradi.

### Virtual muhit (venv) — nega loyihaning boshidanoq kerak

Agar barcha loyihalaringiz uchun kutubxonalarni kompyuterga "global" o'rnatsangiz, bir loyihangiz `django==4.2` talab qilsa, ikkinchisi `django==5.2` — ular to'qnashadi. **Virtual muhit** har bir loyiha uchun alohida, izolyatsiya qilingan Python muhiti yaratadi:

```bash
python3 -m venv venv         # "venv" nomli virtual muhit yaratish
source venv/bin/activate     # faollashtirish (Ubuntu/Linux)
```

Faollashtirilgandan so'ng, muhit ichida oddiy `python` va `pip` buyruqlari ham ishlaydi (ular avtomatik `python3`/`pip3`ga ishora qiladi) — shuning uchun `venv` faollashtirilgan holatda ko'p qo'llanmalarda oddiy `python`/`pip` ko'rishingiz mumkin, bu xato emas.

Faollashtirilgan muhitda terminalda odatda `(venv)` yozuvi paydo bo'ladi — bu hozir aynan shu izolyatsiya qilingan muhitda ishlayotganingizni bildiradi. Bu tushuncha — butun kurs davomida, ayniqsa 3-bobda kutubxonalar o'rnatishni boshlaganda, doimiy ishlatiladi.

## Amaliy misol

O'rnatishdan tortib, birinchi tekshiruvgacha to'liq ketma-ketlik:

```bash
# 1. Versiyani tekshirish
python3 --version
# Python 3.13.2

# 2. Loyiha papkasi va virtual muhit yaratish
mkdir mening_birinchi_loyiham
cd mening_birinchi_loyiham
python3 -m venv venv
source venv/bin/activate     # (venv) terminalda paydo bo'ladi

# 3. pip (paket o'rnatuvchi) versiyasini tekshirish
pip --version
# pip 24.x from ... (python 3.13)

# 4. Muhitni o'chirish (kerak bo'lganda)
deactivate
```

Bu bosqichdan so'ng, kompyuteringiz Python kodini yozish va ishga tushirishga to'liq tayyor.

## Keng tarqalgan xatolar

**Xato 1:** `python3-venv` paketini o'rnatmasdan turib `venv` yaratishga urinish.
❌ `python3 -m venv venv` buyrug'i `Error: Command '['.../venv/bin/python3', ...]' returned non-zero exit status 1` yoki `ensurepip is not available` kabi xato beradi, chunki Ubuntu'da `venv` moduli asosiy `python3` paketidan **alohida** paket sifatida tarqatiladi.
✅ To'g'ri: `sudo apt install python3-venv -y` orqali kerakli paketni o'rnating, so'ng `python3 -m venv venv`ni qayta ishga tushiring.

**Xato 2:** virtual muhitni faollashtirmasdan kutubxona o'rnatishga urinish.
❌ `pip install django` — bu holda Django kompyuterning **global** Python muhitiga o'rnatiladi, boshqa loyihalar bilan versiya to'qnashuvi ehtimoli oshadi.
✅ To'g'ri: har doim avval `source venv/bin/activate`, terminalda `(venv)` yozuvini ko'rgach, keyingina `pip install` qiling.

**Xato 3:** eski, internetdan topilgan Python 2 kodini (masalan, `print "salom"`) ishlatishga urinish.
❌ Python 3'da bu `SyntaxError` beradi, chunki `print` Python 3'da funksiya (`print("salom")`), Python 2'dagidek buyruq (statement) emas.
✅ To'g'ri: har doim Python 3 sintaksisiga (`print(...)`, qavs bilan) amal qiling — bu butun kurs davomida ishlatiladigan yagona standart.

## Mashq/topshiriq

**(Oson)** Python'ni kompyuteringizga o'rnating (agar hali o'rnatilmagan bo'lsa) va `python3 --version` buyrug'i orqali versiyani tekshiring, natijani yozib qo'ying.

**(O'rtacha)** `mening_kursim` nomli papka yarating, ichida virtual muhit tuzing, uni faollashtiring va `pip --version` orqali tekshiring. So'ng `deactivate` bilan muhitni o'chiring.

**(Qiyin)** Kompyuteringizda ikkita alohida papka yarating, har birida alohida virtual muhit tuzing. Birinchisida `pip install requests` (mashhur kutubxona), ikkinchisida hech narsa o'rnatmang. `pip list` buyrug'i orqali ikkalasining farqini ko'ring va nega ular bir-biriga ta'sir qilmasligini tushuntirib bering.

## Qisqacha xulosa

Python — o'qilishi oson sintaksisga ega, veb-dasturlash, ma'lumotlar tahlili va avtomatlashtirishda keng qo'llaniladigan umumiy maqsadli til bo'lib, bu kursda Python 3.12+ versiyasi asos qilib olinadi (Python 2 butunlay eskirgan, ishlatilmasligi kerak); har bir loyiha uchun alohida virtual muhit (`python3 -m venv venv` va uni faollashtirish) yaratish — kutubxonalar versiyasi to'qnashuvining oldini oluvchi, professional dasturchining eng birinchi va o'zgarmas odati.
