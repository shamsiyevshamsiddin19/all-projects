# Kirish/chiqish va f-string

## Bu darsda nimalarni o'rganasiz

- `input()` orqali foydalanuvchidan ma'lumot qabul qila olasiz
- `print()` funksiyasining qo'shimcha parametrlarini (`sep`, `end`) qo'llay olasiz
- f-string (formatlangan satr) yordamida o'zgaruvchilarni matn ichiga qo'ya olasiz
- Sonlarni formatlash (kasr xonalar, minglik ajratkich) usullarini bilasiz

## Nazariy qism

### `input()` — foydalanuvchidan ma'lumot olish

```python
ism = input("Ismingizni kiriting: ")
print("Salom, " + ism)
```

`input()` — terminalda yozilgan matnni **har doim `str` (satr) sifatida** qaytaradi, hatto foydalanuvchi son kiritgan taqdirda ham:

```python
yosh_matn = input("Yoshingizni kiriting: ")
print(type(yosh_matn))    # <class 'str'> — hatto "25" kiritilsa ham!

yosh = int(input("Yoshingizni kiriting: "))   # to'g'ridan-to'g'ri int'ga o'girish
```

### `print()`ning qo'shimcha parametrlari

```python
print("Python", "juda", "qiziq", sep="-")
# Python-juda-qiziq

print("Yuklanmoqda", end="")
print("...")
# Yuklanmoqda...   (bir qatorda, chunki end="" — standart "\n" o'rniga)
```

`sep` — qiymatlar orasidagi ajratkich (standart: bo'sh joy), `end` — qator oxiridagi belgi (standart: yangi qator `\n`).

### f-string — matn ichiga o'zgaruvchi qo'yishning eng qulay yo'li

Python 3.6'dan boshlab kiritilgan **f-string** (formatted string literal) — matn ichida o'zgaruvchilarni to'g'ridan-to'g'ri jingalak qavs `{}` ichida yozish imkonini beradi:

```python
ism = "Dilnoza"
yosh = 22

# Eski usullar (bilish kerak, lekin tavsiya etilmaydi):
print("Salom, " + ism + "! Sen " + str(yosh) + " yoshdasan.")     # + orqali
print("Salom, {}! Sen {} yoshdasan.".format(ism, yosh))              # .format()

# ✅ Zamonaviy, tavsiya etiladigan usul — f-string:
print(f"Salom, {ism}! Sen {yosh} yoshdasan.")
```

`f"..."` — satr oldiga `f` harfi qo'yiladi, va `{}` ichiga **istalgan Python ifodasi** (nafaqat o'zgaruvchi) yozilishi mumkin:

```python
narx = 15000
soni = 3

print(f"Jami: {narx * soni} so'm")            # ifoda to'g'ridan-to'g'ri hisoblanadi
print(f"Katta harf bilan: {ism.upper()}")      # metod chaqirish ham mumkin
```

### Sonlarni formatlash f-string ichida

```python
narx = 1234567.891

print(f"{narx:.2f}")          # 1234567.89 — 2 xonali kasr
print(f"{narx:,.2f}")         # 1,234,567.89 — minglik vergul bilan ajratilgan
print(f"{narx:,.0f}")         # 1,234,568 — butun songa yaxlitlangan, minglik bilan

foiz = 0.4567
print(f"{foiz:.1%}")          # 45.7% — foiz formatida
```

`{qiymat:format_spec}` — ikki nuqtadan keyingi qism formatlash qoidasini bildiradi: `.2f` (2 kasr xona, float), `,` (minglik ajratkich), `%` (foizga aylantirish).

### t-string — Python 3.14'ning yangi imkoniyati (qisqacha)

> 📌 **Qo'shimcha ma'lumot:** Python 3.14'da f-string'ning "template string" versiyasi — **t-string** (`t"..."`) qo'shildi. U f-string kabi ishlaydi, lekin natijani darhol matnga aylantirish o'rniga, `Template` obyekti qaytaradi — bu, masalan, foydalanuvchi kiritgan qiymatlarni avtomatik xavfsizlashtirish (SQL/HTML injection'dan himoya) kerak bo'lgan holatlarda foydali. Bu kursda asosan **f-string** ishlatiladi, chunki u barcha keng tarqalgan Python versiyalarida (3.6+) ishlaydi.

## Amaliy misol

Oddiy "shaxsiy karta" generatori:

```python
# shaxsiy_karta.py

ism = input("Ismingiz: ")
familiya = input("Familiyangiz: ")
yosh = int(input("Yoshingiz: "))
maosh = float(input("Oylik maoshingiz (so'm): "))

yillik_maosh = maosh * 12

print("=" * 30)
print(f"ISM FAMILIYA: {ism.upper()} {familiya.upper()}")
print(f"YOSH: {yosh}")
print(f"OYLIK MAOSH: {maosh:,.0f} so'm")
print(f"YILLIK MAOSH: {yillik_maosh:,.0f} so'm")
print("=" * 30)
```

Namuna ishga tushirish (terminalda):

```
Ismingiz: Sardor
Familiyangiz: Karimov
Yoshingiz: 28
Oylik maoshingiz (so'm): 8500000
==============================
ISM FAMILIYA: SARDOR KARIMOV
YOSH: 28
OYLIK MAOSH: 8,500,000 so'm
YILLIK MAOSH: 102,000,000 so'm
==============================
```

`"=" * 30` — satrni 30 marta takrorlash orqali chiziq hosil qiladi (Python'da `str * int` — satrni takrorlash amali).

## Keng tarqalgan xatolar

**Xato 1:** `input()`dan qaytgan qiymatni to'g'ridan-to'g'ri son sifatida ishlatishga urinish.
❌ `yosh = input("Yosh: "); keyingi_yil = yosh + 1` — `TypeError: can only concatenate str (not "int") to str` xatosini beradi.
✅ To'g'ri: `yosh = int(input("Yosh: "))` — darhol `int()` bilan o'rab oling.

**Xato 2:** f-string oldida `f` harfini yozishni unutish.
❌ `print("Salom, {ism}")` — bu holda `{ism}` **so'zma-so'z** chiqadi, o'zgaruvchi qiymati emas (chunki `f` yo'q, bu oddiy satr).
✅ To'g'ri: `print(f"Salom, {ism}")` — `f` harfisiz jingalak qavslar hech narsani "formatlamaydi".

**Xato 3:** f-string ichida qo'shtirnoq turini ichki qatordagi bilan bir xil qilib qo'yish.
❌ `print(f"Ism: {"Ali"}")` — bu ba'zi eski Python versiyalarida `SyntaxError` berishi mumkin edi (Python 3.12'dan oldin ichki va tashqi qo'shtirnoqlar bir xil bo'lmasligi kerak edi).
✅ To'g'ri: tashqi va ichki qo'shtirnoqlarni turlicha ishlating: `f'Ism: {"Ali"}'` yoki Python 3.12+ da bu cheklov olib tashlangan, lekin barqarorlik uchun baribir turlicha ishlatish tavsiya etiladi.

## Mashq/topshiriq

**(Oson)** Foydalanuvchidan ismini so'rang va f-string yordamida `"Xush kelibsiz, <ism>!"` deb chiqaring.

**(O'rtacha)** Foydalanuvchidan uchburchakning ikkita tomonini (`int` sifatida) so'rab oling va Pifagor teoremasi bo'yicha gipotenuzani hisoblab, natijani 2 kasr xona bilan (`:.2f`) chiqaring (`**0.5` — kvadrat ildiz uchun).

**(Qiyin)** Foydalanuvchidan mahsulot narxini so'rang, so'ng shu narxni `f"{narx:,.0f} so'm"` formatida, ham ADPU (12% QQS qo'shilgan holda) formatida, ikkalasini ham chiroyli, tekislangan (masalan, `sep` va bo'sh joylar bilan) ko'rinishda ikkita qatorda chiqaring.

## Qisqacha xulosa

`input()` — foydalanuvchidan har doim `str` ko'rinishida ma'lumot oladi (songa kerak bo'lsa `int()`/`float()` bilan o'girish shart), `print()`ning `sep`/`end` parametrlari chiqish ko'rinishini boshqaradi, f-string (`f"...{ifoda}..."`) esa — matn ichiga o'zgaruvchi va formatlashni (`:.2f`, `:,` , `:.1%`) qo'shishning zamonaviy, tez va o'qilishi oson usuli bo'lib, bu kursning barcha keyingi darslarida doimiy ishlatiladi.
