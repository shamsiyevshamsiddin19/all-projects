# Fayllar (matn/JSON/CSV) va context managerlar

## Bu darsda nimalarni o'rganasiz

- Fayllarni ochish, o'qish va yozishning xavfsiz usulini (`with`) qo'llay olasiz
- JSON va CSV fayllar bilan standart kutubxona orqali ishlay olasiz
- `with` statement (context manager) qanday ishlashini tushunasiz
- O'zingizning context manager'ingizni (`__enter__`/`__exit__`) yoza olasiz

## Nazariy qism

### Fayl bilan ishlashning xavfli usuli

```python
fayl = open("malumot.txt", "w")
fayl.write("Salom, dunyo!")
fayl.close()    # buni UNUTISH OSON, ayniqsa xato yuz bersa
```

Agar `fayl.write()` bilan `fayl.close()` orasida biror xato yuz bersa (masalan, `except` bilan ushlanmagan istisno), `fayl.close()` **hech qachon** ishlamay qoladi — fayl "ochiq" holda qolib ketishi mumkin, bu resurs sizib chiqishi (resource leak) deb ataladi.

### `with` statement — xavfsiz va tavsiya etiladigan usul

```python
with open("malumot.txt", "w") as fayl:
    fayl.write("Salom, dunyo!")
# bu yerga kelganda fayl AVTOMATIK yopiladi — hatto xato yuz bersa ham!
```

`with` — **context manager** protokoli orqali ishlaydi: blok tugagach (yoki xato yuz bersa ham), fayl avtomatik yopiladi. Bu — fayllar, tarmoq ulanishlari va ma'lumotlar bazasi bilan ishlashning **standart, tavsiya etiladigan** usuli.

### Fayl rejimlari

| Rejim | Ma'nosi |
|---|---|
| `"r"` | O'qish (read) — standart, agar fayl topilmasa xato beradi |
| `"w"` | Yozish (write) — mavjud tarkibni **butunlay o'chirib**, yangidan yozadi |
| `"a"` | Qo'shish (append) — mavjud tarkib oxiriga qo'shadi |
| `"x"` | Yaratish — agar fayl allaqachon mavjud bo'lsa, xato beradi |

```python
# O'qish
with open("malumot.txt", "r") as fayl:
    tarkib = fayl.read()          # butun faylni bitta satr sifatida o'qiydi
    print(tarkib)

with open("malumot.txt", "r") as fayl:
    for qator in fayl:              # fayl bo'ylab qator-qator aylanish (xotira tejamkor)
        print(qator.strip())         # .strip() — qator oxiridagi \n ni olib tashlaydi

with open("malumot.txt", "r") as fayl:
    qatorlar = fayl.readlines()    # barcha qatorlarni RO'YXAT sifatida qaytaradi

# Yozish
with open("yangi.txt", "w") as fayl:
    fayl.write("Birinchi qator\n")
    fayl.write("Ikkinchi qator\n")

# Qo'shish
with open("yangi.txt", "a") as fayl:
    fayl.write("Uchinchi qator (qo'shildi)\n")
```

### Kodировка (encoding) — o'zbek/kirill harflar bilan ishlash

```python
with open("malumot.txt", "r", encoding="utf-8") as fayl:
    tarkib = fayl.read()
```

> ⚠️ **`encoding="utf-8"`ni har doim aniq ko'rsating.** Ba'zi tizimlarda (ayniqsa Windows'da) standart kodировка `utf-8` bo'lmasligi mumkin, bu o'zbek lotin/kirill yoki boshqa maxsus belgilar bilan `UnicodeDecodeError` xatosiga olib kelishi mumkin. Ubuntu'da odatda standart kodировка allaqachon `utf-8`, lekin aniq ko'rsatish — har qanday muhitda ishlashni kafolatlaydi, shuning uchun professional kodda bu doim yozib qo'yiladi.

### JSON fayllar bilan ishlash

```python
import json

malumot = {
    "ism": "Ali",
    "yosh": 25,
    "sevimli_tillar": ["Python", "JavaScript"]
}

# Python obyektini JSON faylga yozish
with open("malumot.json", "w", encoding="utf-8") as fayl:
    json.dump(malumot, fayl, ensure_ascii=False, indent=2)

# JSON fayldan Python obyektiga o'qish
with open("malumot.json", "r", encoding="utf-8") as fayl:
    qayta_yuklangan = json.load(fayl)
    print(qayta_yuklangan["ism"])    # Ali
```

`ensure_ascii=False` — o'zbek/kirill harflar `б` kabi escape-kodlar o'rniga **to'g'ridan-to'g'ri** o'qilishi mumkin bo'lgan holda saqlanishini ta'minlaydi; `indent=2` — faylni odam o'qishi qulay bo'lgan, chekinishlar bilan formatlaydi.

### CSV fayllar bilan ishlash

```python
import csv

# CSV faylga yozish
talabalar = [
    {"ism": "Ali", "ball": 85},
    {"ism": "Vali", "ball": 92},
]

with open("talabalar.csv", "w", newline="", encoding="utf-8") as fayl:
    yozuvchi = csv.DictWriter(fayl, fieldnames=["ism", "ball"])
    yozuvchi.writeheader()
    yozuvchi.writerows(talabalar)

# CSV fayldan o'qish
with open("talabalar.csv", "r", encoding="utf-8") as fayl:
    oquvchi = csv.DictReader(fayl)
    for qator in oquvchi:
        print(qator["ism"], qator["ball"])
```

`newline=""` — CSV modulida Windows/Unix qator tugash belgilari to'g'ri ishlashi uchun rasmiy tavsiya (Python hujjatlarida shunday yozish kerakligi ko'rsatilgan).

### Fayl mavjudligini oldindan tekshirish

```python
import os

if os.path.exists("malumot.txt"):
    print("Fayl mavjud")
else:
    print("Fayl topilmadi")

# yoki, tavsiya etiladigan zamonaviy usul — pathlib
from pathlib import Path

fayl_yoli = Path("malumot.txt")
if fayl_yoli.exists():
    tarkib = fayl_yoli.read_text(encoding="utf-8")
```

`pathlib.Path` — Python 3'da fayl yo'llari bilan ishlashning zamonaviy, obyektga yo'naltirilgan usuli bo'lib, `os.path`ning ko'p funksiyalarini qulayroq metodlar ko'rinishida taqdim etadi.

### O'z context manager'ingizni yaratish

```python
class VaqtOlchagich:
    def __enter__(self):
        import time
        self.boshlanish = time.time()
        return self

    def __exit__(self, exc_turi, exc_qiymat, traceback):
        import time
        print(f"Bajarildi: {time.time() - self.boshlanish:.4f} soniya")
        return False    # False — agar xato yuz bergan bo'lsa, uni "yutib yubormaslik", tashqariga chiqarish


with VaqtOlchagich():
    natija = sum(range(1000000))
    print(natija)
```

`__enter__` — `with` blokiga kirishda chaqiriladi (natija `as` bilan olinadi), `__exit__` — blokdan chiqishda (xato bo'lsa ham) chaqiriladi. Bu — `open()`ning o'zi ham xuddi shu protokol asosida ishlashini ko'rsatadi.

## Amaliy misol

Oddiy "kunlik xarajatlar" jurnalini JSON orqali saqlash:

```python
# xarajatlar_jurnali.py
import json
from pathlib import Path

FAYL_NOMI = "xarajatlar.json"


def xarajatlarni_yukla():
    fayl = Path(FAYL_NOMI)
    if not fayl.exists():
        return []
    with open(fayl, "r", encoding="utf-8") as f:
        return json.load(f)


def xarajatlarni_saqlash(xarajatlar):
    with open(FAYL_NOMI, "w", encoding="utf-8") as f:
        json.dump(xarajatlar, f, ensure_ascii=False, indent=2)


def xarajat_qosh(nom, summa):
    xarajatlar = xarajatlarni_yukla()
    xarajatlar.append({"nom": nom, "summa": summa})
    xarajatlarni_saqlash(xarajatlar)
    print(f"'{nom}' — {summa} so'm qo'shildi.")


def jami_xarajat():
    xarajatlar = xarajatlarni_yukla()
    return sum(x["summa"] for x in xarajatlar)


xarajat_qosh("Non", 4000)
xarajat_qosh("Taksi", 25000)
print(f"Jami xarajat: {jami_xarajat():,.0f} so'm")
```

Har safar dastur ishga tushirilganda, `xarajatlarni_yukla()` avvalgi ma'lumotlarni fayldan o'qiydi — bu dasturga "xotira" (persistensiya) beradi, dastur yopilib-ochilsa ham ma'lumot saqlanib qoladi.

## Keng tarqalgan xatolar

**Xato 1:** `with`siz `open()` ishlatib, `close()`ni unutish.
❌ `fayl = open("m.txt", "w"); fayl.write("...")` — `close()` chaqirilmasa, ba'zi hollarda yozilgan ma'lumot **diskka to'liq yozilmasligi** ham mumkin (buferlash sababli).
✅ To'g'ri: har doim `with open(...) as fayl:` ishlating — bu avtomatik va xavfsiz.

**Xato 2:** `"w"` rejimini `"a"` o'rniga ishlatib, mavjud ma'lumotni yo'qotib qo'yish.
❌ Mavjud faylga qo'shimcha yozish niyatida `open("jurnal.txt", "w")` ishlatish — bu faylning **butun avvalgi tarkibini o'chirib tashlaydi**!
✅ To'g'ri: mavjud tarkibga qo'shish kerak bo'lsa har doim `"a"` (append) rejimini ishlating, faqat yangidan yozish/tozalash kerak bo'lgandagina `"w"`.

**Xato 3:** mavjud bo'lmagan faylni `"r"` rejimida ochishga urinib, `FileNotFoundError`ni boshqarmaslik.
❌ `with open("mavjud_emas.txt") as f: ...` — agar fayl mavjud bo'lmasa, dastur to'xtaydi.
✅ To'g'ri: `try/except FileNotFoundError:` bilan o'rab oling, yoki oldindan `Path(...).exists()` orqali tekshiring (yuqoridagi misolda ko'rganimizdek).

## Qisqacha xulosa

`with open(...) as fayl:` — fayllar bilan ishlashning xavfsiz, tavsiya etiladigan usuli bo'lib, blok tugagach faylni avtomatik yopadi (xato yuz bersa ham); `json` moduli Python obyektlari va JSON fayllar orasida, `csv` moduli esa jadval ko'rinishidagi ma'lumotlar bilan ishlaydi; `with` statement — **context manager** protokoli (`__enter__`/`__exit__`) asosida ishlaydi, va o'z resurslaringiz (masalan, ulanishlar) uchun ham xuddi shunday o'zingizning context manager'ingizni yozishingiz mumkin.
