# Comprehensions (list, dict, set)

## Bu darsda nimalarni o'rganasiz

- List comprehension yordamida ro'yxatlarni qisqa va o'qilishi oson yarata olasiz
- Dict va set comprehension'larni qo'llay olasiz
- Comprehension ichida shart (`if`) va ichma-ich sikl ishlata olasiz
- Qachon comprehension, qachon oddiy `for` sikli ishlatish kerakligini ajrata olasiz

## Nazariy qism

### List comprehension — nima uchun kerak

Oddiy `for` sikli bilan har bir sonning kvadratidan iborat ro'yxat yaratish:

```python
kvadratlar = []
for son in range(1, 6):
    kvadratlar.append(son ** 2)
print(kvadratlar)     # [1, 4, 9, 16, 25]
```

Xuddi shu natija, **list comprehension** bilan bitta qatorda:

```python
kvadratlar = [son ** 2 for son in range(1, 6)]
print(kvadratlar)     # [1, 4, 9, 16, 25]
```

Umumiy sintaksis: `[ifoda for element in ketma_ketlik]`.

### Shart bilan comprehension

```python
# Faqat juft sonlarning kvadratlari
juft_kvadratlar = [son ** 2 for son in range(1, 11) if son % 2 == 0]
print(juft_kvadratlar)    # [4, 16, 36, 64, 100]
```

Umumiy sintaksis: `[ifoda for element in ketma_ketlik if shart]` — `if` shu yerda **filtr** vazifasini bajaradi (faqat shartga mos elementlar qatnashadi).

### if/else comprehension ichida (ifoda sifatida)

```python
sonlar = [1, 2, 3, 4, 5, 6]
natija = ["juft" if son % 2 == 0 else "toq" for son in sonlar]
print(natija)    # ['toq', 'juft', 'toq', 'juft', 'toq', 'juft']
```

> ⚠️ **Diqqat: ikki xil `if`ni chalkashtirmang.** `for ... if shart` (oxirida) — **filtrlaydi** (ba'zi elementlarni tashlab yuboradi). `ifoda1 if shart else ifoda2 for ...` (boshida) — **har bir element uchun qaysi qiymat ishlatilishini tanlaydi** (hech narsani tashlamaydi, natija hajmi o'zgarmaydi).

### Dict comprehension

```python
sonlar = [1, 2, 3, 4, 5]
kvadratlar_lugati = {son: son ** 2 for son in sonlar}
print(kvadratlar_lugati)    # {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

# Ikkita ro'yxatdan dict yaratish
ismlar = ["Ali", "Vali", "Guli"]
yoshlar = [25, 30, 22]
odamlar = {ism: yosh for ism, yosh in zip(ismlar, yoshlar)}
print(odamlar)    # {'Ali': 25, 'Vali': 30, 'Guli': 22}
```

### Set comprehension

```python
sozlar = ["olma", "banan", "olma", "uzum", "banan"]
uzunliklar = {len(soz) for soz in sozlar}    # takroriy uzunliklar avtomatik olib tashlanadi
print(uzunliklar)    # {4, 5} — "olma"=4, "banan"=5, "uzum"=4
```

### Generator expression — comprehension'ning "dangasa" (lazy) versiyasi

```python
kvadratlar_generator = (son ** 2 for son in range(1, 1000000))   # darhol hisoblanmaydi!
print(sum(kvadratlar_generator))    # faqat shu yerda, kerak bo'lganda hisoblanadi
```

Kvadrat qavs `[]` o'rniga oddiy qavs `()` ishlatilsa — natija **generator** bo'ladi, u elementlarni **darhol xotiraga yuklamaydi**, faqat kerak bo'lganda birma-bir hisoblaydi. Bu juda katta ma'lumotlar bilan ishlaganda xotirani tejaydi (generatorlar haqida 5-bobda batafsil).

### Ichma-ich (nested) comprehension

```python
# 3x3 "matritsa" (ro'yxatlar ro'yxati)
matritsa = [[qator * 3 + ustun for ustun in range(3)] for qator in range(3)]
print(matritsa)    # [[0, 1, 2], [3, 4, 5], [6, 7, 8]]

# Matritsani "tekislash" (flatten) — ichma-ich for bilan
tekis = [son for qator in matritsa for son in qator]
print(tekis)    # [0, 1, 2, 3, 4, 5, 6, 7, 8]
```

> ⚠️ **Muhim:** ichma-ich comprehension'lar tez o'qilishi qiyinlashadi. Agar 2 tadan ortiq ichma-ich `for` yoki murakkab shart kerak bo'lsa — **oddiy `for` siklini** ishlatish, kodni o'qilishi osonroq qilishi mumkin. "Qisqalik" har doim "tushunarli"dan ustun emas.

## Amaliy misol

Talabalar ma'lumotlarini qayta ishlash:

```python
# talabalar_tahlil.py

talabalar = [
    {"ism": "Ali", "ball": 85},
    {"ism": "Vali", "ball": 45},
    {"ism": "Guli", "ball": 92},
    {"ism": "Dilnoza", "ball": 58},
]

# 1. Faqat o'tgan talabalar ismlari (ball >= 60)
otganlar = [t["ism"] for t in talabalar if t["ball"] >= 60]
print("O'tganlar:", otganlar)     # ['Ali', 'Guli']

# 2. Ism -> ball lug'ati
ball_lugati = {t["ism"]: t["ball"] for t in talabalar}
print(ball_lugati)

# 3. Har bir talaba uchun "o'tdi"/"yiqildi" holati
holatlar = {t["ism"]: ("o'tdi" if t["ball"] >= 60 else "yiqildi") for t in talabalar}
print(holatlar)

# 4. Noyob ball diapazonlari (10 ga bo'lingan)
diapazonlar = {(t["ball"] // 10) * 10 for t in talabalar}
print(sorted(diapazonlar))    # [40, 50, 80, 90]
```

## Keng tarqalgan xatolar

**Xato 1:** comprehension ichida murakkab, ko'p qatorlik mantiqni siqishga urinish.
❌ 
```python
natija = [x**2 if x % 2 == 0 else x**3 if x % 3 == 0 else x for x in range(20) if x > 5 if x < 15]
```
Bu texnik jihatdan ishlaydi, lekin o'qish deyarli imkonsiz.
✅ To'g'ri: agar mantiq murakkablashsa, alohida funksiyaga chiqaring: `natija = [qayta_ishla(x) for x in range(20) if 5 < x < 15]`, `qayta_ishla` esa alohida, tushunarli funksiya bo'lsin.

**Xato 2:** `{}` bilan bo'sh comprehension yasab, `dict` kutib, aslida `set` olish (yoki aksincha).
❌ Dict comprehension yozish niyatida `{x for x in range(5)}` yozish — bu **set comprehension**, chunki `key: value` juftligi yo'q.
✅ To'g'ri: dict comprehension uchun har doim `{kalit: qiymat for ...}` formatini eslab qoling — ikki nuqta (`:`) borligini tekshiring.

**Xato 3:** comprehension natijasini qayta-qayta hisoblash (samarasizlik).
❌ 
```python
[son for son in range(1000000) if son in katta_royxat]   # katta_royxat list bo'lsa, har safar sekin qidiradi
```
✅ To'g'ri: agar `in` orqali tez-tez tekshiruv kerak bo'lsa, `katta_royxat`ni oldindan `set()`ga aylantiring — `set`da `in` ancha tezroq ishlaydi (oldingi darsda ko'rganimizdek).

## Mashq/topshiriq

**(Oson)** `1` dan `20` gacha bo'lgan sonlardan faqat `3`ga bo'linadiganlarini list comprehension bilan hosil qiling.

**(O'rtacha)** Berilgan so'zlar ro'yxati (`sozlar = ["olma", "IT", "dasturlash", "AI", "Python"]`) ichidan, uzunligi 3 dan katta bo'lgan so'zlarni katta harfga o'girib, yangi ro'yxat yarating (bitta comprehension'da).

**(Qiyin)** `1` dan `50` gacha bo'lgan sonlar ichidan tub sonlarni (avvalgi darsda yozgan mantiqdan foydalanib) list comprehension va ichki yordamchi funksiya (yoki ichma-ich comprehension bilan `all()` funksiyasidan foydalanib) toping.

<details>
<summary>Javoblarni ko'rish</summary>

1. `natija = [son for son in range(1, 21) if son % 3 == 0]` → `[3, 6, 9, 12, 15, 18]`.
2. `natija = [soz.upper() for soz in sozlar if len(soz) > 3]` → `['OLMA', 'DASTURLASH', 'PYTHON']`.
3. `tub_sonlar = [son for son in range(2, 51) if all(son % b != 0 for b in range(2, int(son**0.5)+1))]` — bu yerda `all(...)` ichidagi generator expression har bir bo'luvchi uchun `son % b != 0` ekanini tekshiradi, barchasi rost bo'lsagina `son` tub hisoblanadi.

## Qisqacha xulosa

Comprehension'lar (`[... for ... in ... if ...]`, `{k: v for ...}`, `{... for ...}`) — ro'yxat, lug'at va to'plamlarni oddiy `for` siklidan qisqaroq va ko'pincha o'qilishi osonroq tarzda yaratish usuli; ular filtrlash (`if`) va shart bo'yicha tanlash (`ifoda1 if shart else ifoda2`)ni birlashtira oladi, lekin murakkablik oshsa oddiy `for` siklga qaytish — "Pythonic" bo'lishdan ko'ra tushunarli bo'lish muhimroq ekanini yodda tutish kerak.
