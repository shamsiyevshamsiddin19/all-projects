### `argparse` — buyruq qatori interfeysi (CLI) yaratish

Standart kutubxonaning `argparse` moduli — terminal buyruqlariga argument va bayroqlar (flags) qo'shish imkonini beradi:

```python
import argparse

parser = argparse.ArgumentParser(description="Oddiy vazifa boshqaruvchi")
parser.add_argument("amal", choices=["qosh", "royxat", "bajarildi"], help="Bajariladigan amal")
parser.add_argument("--nom", type=str, help="Vazifa nomi (qosh uchun)")
parser.add_argument("--id", type=int, help="Vazifa ID (bajarildi uchun)")
parser.add_argument("-v", "--verbose", action="store_true", help="Batafsil chiqish")

args = parser.parse_args()

print(args.amal)       # buyruq qatoridan olingan qiymat
print(args.nom)
print(args.verbose)     # True yoki False (--verbose berilgan-berilmaganiga qarab)
```

Terminaldan ishga tushirish:

```bash
python3 cli.py qosh --nom "Uyga vazifa qilish"
python3 cli.py royxat -v
python3 cli.py bajarildi --id 3
```

### Zamonaviy CLI — `uv` bilan ishga tushiriladigan buyruq

`pyproject.toml`da CLI buyrug'ini ro'yxatga olish orqali, loyihani `python3 cli.py` o'rniga to'g'ridan-to'g'ri buyruq nomi bilan ishga tushirish mumkin bo'ladi:

```toml
[project]
name = "vazifa-boshqaruvchi"
version = "0.1.0"
requires-python = ">=3.12"

[project.scripts]
vazifa = "vazifa_boshqaruvchi.cli:main"    # 'vazifa' buyrug'i -> cli.py dagi main() funksiyasi

[build-system]
requires = ["hatchling"]
build-backend = "hatchling.build"
```

```bash
uv sync              # loyihani "o'rnatadi", shu jumladan CLI buyrug'ini
uv run vazifa qosh --nom "Non olish"    # endi 'vazifa' buyrug'i to'g'ridan-to'g'ri ishlaydi
```

### Loyihani PyPI'ga chiqarish — qisqacha umumiy tasavvur

Agar loyihangizni boshqa dasturchilar `pip install loyiha-nomi` orqali o'rnatishini xohlasangiz, uni **PyPI** (Python Package Index)ga yuklash mumkin:

```bash
uv build              # pyproject.toml asosida taqsimlanadigan paket (.whl, .tar.gz) yaratadi
uv publish             # PyPI'ga yuklaydi (PyPI hisobi va API token talab qiladi)
```

> 📌 Bu kursda PyPI'ga chiqarishning barcha bosqichlari (hisob yaratish, token olish) batafsil ko'rilmaydi — bu, odatda, loyiha allaqachon barqaror va boshqalar bilan ulashishga tayyor bo'lganda amalga oshiriladigan **keyingi qadam**. Muhimi — bu jarayon `uv` bilan sezilarli soddalashtirilgan, avvalgi (`setup.py`+`twine`) usulga qaraganda ancha kam qadam talab qiladi.

## Amaliy misol — Yakuniy loyiha: "Vazifa boshqaruvchi" (Task Manager CLI)

Bu loyiha — butun kursda o'rganilgan deyarli barcha mavzularni birlashtiradi: `@dataclass`, `Enum`, fayllar/JSON, `argparse`, istisnolar, type hints.

```python
# modellar.py
from dataclasses import dataclass, field
from enum import Enum
from datetime import datetime


class Holat(Enum):
    KUTILMOQDA = "kutilmoqda"
    BAJARILDI = "bajarildi"


@dataclass
class Vazifa:
    id: int
    nom: str
    holat: Holat = Holat.KUTILMOQDA
    yaratilgan_vaqt: str = field(default_factory=lambda: datetime.now().strftime("%Y-%m-%d %H:%M"))

    def to_dict(self) -> dict:
        return {
            "id": self.id,
            "nom": self.nom,
            "holat": self.holat.value,
            "yaratilgan_vaqt": self.yaratilgan_vaqt,
        }

    @classmethod
    def from_dict(cls, malumot: dict) -> "Vazifa":
        return cls(
            id=malumot["id"],
            nom=malumot["nom"],
            holat=Holat(malumot["holat"]),
            yaratilgan_vaqt=malumot["yaratilgan_vaqt"],
        )
```

```python
# saqlash.py
import json
from pathlib import Path
from modellar import Vazifa

FAYL_NOMI = Path("vazifalar.json")


def hammasini_yukla() -> list[Vazifa]:
    if not FAYL_NOMI.exists():
        return []
    with open(FAYL_NOMI, "r", encoding="utf-8") as fayl:
        malumot = json.load(fayl)
        return [Vazifa.from_dict(v) for v in malumot]


def hammasini_saqlash(vazifalar: list[Vazifa]) -> None:
    with open(FAYL_NOMI, "w", encoding="utf-8") as fayl:
        json.dump([v.to_dict() for v in vazifalar], fayl, ensure_ascii=False, indent=2)


def keyingi_id(vazifalar: list[Vazifa]) -> int:
    if not vazifalar:
        return 1
    return max(v.id for v in vazifalar) + 1
```

```python
# cli.py
import argparse
import logging
from modellar import Vazifa, Holat
from saqlash import hammasini_yukla, hammasini_saqlash, keyingi_id

logging.basicConfig(level=logging.INFO, format="%(asctime)s - %(levelname)s - %(message)s")
logger = logging.getLogger(__name__)


def vazifa_qosh(nom: str) -> None:
    vazifalar = hammasini_yukla()
    yangi_vazifa = Vazifa(id=keyingi_id(vazifalar), nom=nom)
    vazifalar.append(yangi_vazifa)
    hammasini_saqlash(vazifalar)
    logger.info(f"Vazifa qo'shildi: #{yangi_vazifa.id} — {nom}")


def vazifalarni_royxat_qil() -> None:
    vazifalar = hammasini_yukla()
    if not vazifalar:
        print("Hozircha vazifalar yo'q.")
        return
    for vazifa in vazifalar:
        belgi = "✅" if vazifa.holat == Holat.BAJARILDI else "⬜"
        print(f"{belgi} #{vazifa.id} {vazifa.nom} ({vazifa.yaratilgan_vaqt})")


def vazifani_bajarildi_deb_belgilash(vazifa_id: int) -> None:
    vazifalar = hammasini_yukla()
    for vazifa in vazifalar:
        if vazifa.id == vazifa_id:
            vazifa.holat = Holat.BAJARILDI
            hammasini_saqlash(vazifalar)
            logger.info(f"Vazifa #{vazifa_id} bajarildi deb belgilandi")
            return
    logger.warning(f"Vazifa #{vazifa_id} topilmadi")


def main() -> None:
    parser = argparse.ArgumentParser(description="Oddiy vazifa boshqaruvchi (Task Manager)")
    parser.add_argument("amal", choices=["qosh", "royxat", "bajarildi"], help="Bajariladigan amal")
    parser.add_argument("--nom", type=str, help="Yangi vazifa nomi ('qosh' uchun majburiy)")
    parser.add_argument("--id", type=int, help="Vazifa ID ('bajarildi' uchun majburiy)")

    args = parser.parse_args()

    if args.amal == "qosh":
        if not args.nom:
            parser.error("'qosh' amali uchun --nom majburiy")
        vazifa_qosh(args.nom)
    elif args.amal == "royxat":
        vazifalarni_royxat_qil()
    elif args.amal == "bajarildi":
        if args.id is None:
            parser.error("'bajarildi' amali uchun --id majburiy")
        vazifani_bajarildi_deb_belgilash(args.id)


if __name__ == "__main__":
    main()
```

## Keng tarqalgan xatolar

**Xato 1:** `argparse`da majburiy argumentlarni tekshirmaslik.
❌ `parser.add_argument("--nom")` — standart holda ixtiyoriy, agar kod ichida `if not args.nom:` bilan tekshirilmasa, `vazifa_qosh(None)` chaqirilib, keyinroq tushunarsiz xatoga olib kelishi mumkin.
✅ To'g'ri: yoki `required=True` parametrini qo'shing (`parser.add_argument("--nom", required=True)`), yoki yuqoridagi misoldagi kabi qo'lda tekshiring va `parser.error(...)` bilan aniq xabar bering.

**Xato 2:** loyiha strukturasini "tekis" (barcha fayllar bitta papkada, aralash) qilib qoldirish.
❌ 20-30 ta fayl bitta papkada, testlar ham asosiy kod bilan aralash — loyiha kattalashgach navigatsiya qiyinlashadi.
✅ To'g'ri: boshidanoq `src/`, `tests/` kabi mantiqiy papkalarga ajrating — bu odat kichik loyihada ortiqcha tuyulishi mumkin, lekin loyiha o'sishi bilan o'zini oqlaydi.

**Xato 3:** `Enum` qiymatlarini JSON'ga to'g'ridan-to'g'ri saqlashga urinish.
❌ `json.dump({"holat": Holat.BAJARILDI}, fayl)` — `TypeError: Object of type Holat is not JSON serializable`, chunki JSON `Enum` obyektlarini tushunmaydi.
✅ To'g'ri: yuqoridagi `to_dict()`/`from_dict()` naqshida ko'rganimizdek, saqlashdan oldin `.value`ga (`Holat.BAJARILDI.value` → `"bajarildi"`), yuklashda esa qayta `Holat(...)`ga o'girish kerak.

## Mashq/topshiriq

**(Oson)** Yakuniy loyihaga `--nom` orqali vazifani **o'chirish** (`ochir`) amalini qo'shing — `argparse`ga yangi `choices` qiymatini va mos funksiyani qo'shing.

**(O'rtacha)** `vazifalarni_royxat_qil()` funksiyasiga `--faqat-bajarilmagan` bayrog'ini (flag, `action="store_true"`) qo'shing — agar bu bayroq berilsa, faqat `Holat.KUTILMOQDA` holatidagi vazifalarni ko'rsatsin.

**(Qiyin)** Loyihaga `tests/test_modellar.py` fayli qo'shib, `Vazifa.to_dict()` va `Vazifa.from_dict()` metodlari uchun `pytest` testlarini yozing — jumladan, `to_dict()` bilan hosil qilingan lug'atni qayta `from_dict()`ga berganda, asl `Vazifa` obyekti bilan bir xil natija (barcha maydonlar bo'yicha) chiqishini tekshiring.
