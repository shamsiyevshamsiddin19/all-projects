# Birinchi dastur, REPL va kod uslubi

## Bu darsda nimalarni o'rganasiz

- Birinchi Python dasturingizni yoza va ishga tushira olasiz
- Python REPL (interaktiv rejim) nima ekanini va uni qachon ishlatishni bilasiz
- `.py` fayl bilan REPL orasidagi farqni tushuntira olasiz
- PEP 8 va "Zen of Python" nima ekanini, nega ularga amal qilish kerakligini tushuntira olasiz

## Nazariy qism

### Birinchi dastur — `main.py`

Har qanday matn muharriri (VS Code, PyCharm yoki oddiy `nano`) yordamida `main.py` nomli fayl yarating:

```python
print("Salom, Python!")
```

Terminalda faylni ishga tushirish:

```bash
python3 main.py
```

Natija:

```
Salom, Python!
```

`print()` — Python'ning **built-in** (o'rnatilgan) funksiyasi bo'lib, qavs ichidagi qiymatni ekranga chiqaradi. Har bir Python buyrug'i (statement) alohida qatorda yoziladi, va (C++ yoki Java'dan farqli o'laroq) qator oxirida `;` shart emas.

### REPL — interaktiv Python muhiti

**REPL** (Read-Eval-Print Loop) — terminalga `python3` deb yozib kiritiladigan interaktiv rejim, bu yerda har bir qatorni yozib **darhol** natijani ko'rasiz:

```bash
python3
```

```python
>>> 2 + 2
4
>>> print("Salom")
Salom
>>> ismlar = ["Ali", "Vali", "Guli"]
>>> len(ismlar)
3
>>> exit()
```

`exit()` yoki `Ctrl+D` — REPL'dan chiqish. REPL — g'oyalarni tezda sinab ko'rish, kichik hisob-kitoblar yoki bitta funksiyaning ishlashini tekshirish uchun juda qulay, lekin **haqiqiy loyihalar** har doim `.py` fayllarda yoziladi, chunki fayl saqlanadi, versiyalash (Git) mumkin va qayta-qayta ishga tushirish oson.

| Xususiyat | REPL | `.py` fayl |
|---|---|---|
| Natija ko'rinishi | Darhol, har qatordan keyin | Faqat `print()` chaqirilganda |
| Saqlanishi | Yo'q — sessiya tugasa, yo'qoladi | Ha, diskda saqlanadi |
| Ishlatilishi | Tezkor sinov, o'rganish | Haqiqiy dasturlar, loyihalar |

### IPython — REPL'ning kuchaytirilgan versiyasi

Standart REPL o'rniga ko'p dasturchilar **IPython**dan foydalanadi — u avtomatik to'ldirish, rangli chiqish va qulayroq xato xabarlarini beradi:

### Kod fayllarini ishga tushirishning ikkinchi yo'li — argument bilan

```bash
python3 -c "print('Bir qatorlik kod')"
```

`-c` bayrog'i — Python'ga fayl o'rniga to'g'ridan-to'g'ri buyruq qatoridan bitta qatorlik kodni bajarishni buyuradi. Bu tezkor tekshiruvlar uchun foydali.

### PEP 8 — Python'ning rasmiy uslub qo'llanmasi

**PEP** (Python Enhancement Proposal) — Python tilining rasmiy taklif/hujjat tizimi. **PEP 8** — eng mashhur PEP bo'lib, kod qanday yozilishi kerakligi haqidagi qoidalar to'plamini beradi. Asosiy qoidalar:

- Chekinish (indentatsiya) — **4 ta bo'sh joy** (tab emas)
- O'zgaruvchi va funksiya nomlari — `snake_case` (masalan, `foydalanuvchi_nomi`, `hisoblash_narxi`)
- Klass nomlari — `PascalCase` (masalan, `FoydalanuvchiProfili`)
- Doimiylar (constants) — `UPPER_CASE` (masalan, `MAX_URINISHLAR = 3`)
- Qator uzunligi — tavsiyan 79-99 belgidan oshmasin
- `=` atrofida bo'sh joy: `x = 5`, `x=5` emas

```python
# ❌ PEP 8'ga mos emas
def hisoblaNarx(mahsulotSoni,narxBirlik):
    return mahsulotSoni*narxBirlik

# ✅ PEP 8'ga mos
def hisobla_narx(mahsulot_soni, narx_birlik):
    return mahsulot_soni * narx_birlik
```

### Zen of Python — Python falsafasi

REPL'da quyidagini yozib ko'ring:

```python
>>> import this
```

Bu Python'ning norasmiy "falsafasi" — 19 ta qisqa qoidani chiqaradi. Eng muhimlari:

- *"Beautiful is better than ugly"* — Chiroyli kod xunukdan yaxshiroq
- *"Simple is better than complex"* — Oddiy kod murakkabdan yaxshiroq
- *"Readability counts"* — O'qilishi oson bo'lishi muhim
- *"There should be one — and preferably only one — obvious way to do it"* — Har bir masalani yechishning bitta aniq yo'li bo'lishi kerak

Bu falsafa Python kodining nega ko'pincha boshqa tillardagidan qisqaroq va o'qilishi osonroq bo'lishini tushuntiradi.

### Izohlar (comments)

```python
# Bu bitta qatorlik izoh — kod bajarilmaydi, faqat tushuntirish uchun

"""
Bu ko'p qatorlik izoh (docstring uslubida),
odatda fayl yoki funksiya boshida ishlatiladi.
"""

narx = 15000  # Narx so'mda
```

Izohlar — kodni **nima** qilayotganini emas, **nega** shunday qilinayotganini tushuntirish uchun ishlatilishi kerak (masalan, `narx = narx * 1.12  # 12% QQS qo'shildi`).

## Amaliy misol

`salomlashuv.py` nomli fayl yaratamiz:

```python
# salomlashuv.py
# Foydalanuvchi bilan oddiy salomlashuv dasturi
```

Ishga tushirish:


Diqqat qiling: `print()` funksiyasiga bir nechta qiymat vergul bilan berilsa, ular orasiga avtomatik bo'sh joy qo'yib chiqariladi.

## Keng tarqalgan xatolar

**Xato 1:** faylni saqlamasdan ishga tushirishga urinish.
❌ Matn muharritida o'zgartirish kiritilgan, lekin `Ctrl+S` bilan saqlanmagan, so'ng `python3 fayl.py` eski (saqlanmagan) natijani ko'rsatadi.
✅ To'g'ri: har doim faylni saqlagach ishga tushiring — ko'pchilik zamonaviy muharrirlar (VS Code) "avtomatik saqlash" (auto save) imkoniyatiga ega, uni yoqib qo'yish tavsiya etiladi.

**Xato 2:** `print` so'zini Python 2 uslubida, qavssiz ishlatish.
❌ `print "Salom"` — bu Python 3'da `SyntaxError: Missing parentheses in call to 'print'` xatosini beradi.
✅ To'g'ri: Python 3'da `print` — oddiy funksiya, har doim qavs bilan chaqiriladi: `print("Salom")`.

**Xato 3:** fayl nomini Python o'zining ichki modul nomlari bilan bir xil qilib qo'yish (masalan, `random.py`, `test.py`).
❌ Agar loyihada `random.py` nomli fayl yaratilsa va o'sha faylda `import random` yozilsa, Python **standart kutubxonadagi** `random` modulini emas, sizning **o'z faylingizni** import qiladi — bu tushunarsiz xatolarga olib keladi.
✅ To'g'ri: standart kutubxona modullari bilan bir xil nomdagi fayllardan saqlaning (`random.py`, `math.py`, `json.py`, `os.py` kabi nomlarni ishlatmang).

## Qisqacha xulosa

Python dasturlari `.py` fayllarda yoziladi va `python3 fayl.py` orqali ishga tushiriladi, REPL (`python3` interaktiv rejimi) esa tezkor sinov va o'rganish uchun ishlatiladi; **PEP 8** — kodni izchil va o'qilishi oson yozish uchun rasmiy uslub qo'llanmasi (4 bo'sh joy chekinish, `snake_case` nomlash), **Zen of Python** (`import this`) esa Python dasturchilarining "oddiylik va o'qilishi osonlik" falsafasini ifodalaydi — bu ikkalasi butun kurs davomida yozadigan har bir kod qatoriga asos bo'ladi.
