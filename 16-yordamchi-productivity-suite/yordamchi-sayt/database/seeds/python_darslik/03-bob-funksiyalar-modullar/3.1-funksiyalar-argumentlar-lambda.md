# Funksiyalar, argumentlar va lambda

## Bu darsda nimalarni o'rganasiz

- `def` yordamida o'z funksiyalaringizni yoza olasiz
- Pozitsion, kalit so'zli, standart va `*args`/`**kwargs` argumentlarni farqlay olasiz
- `return`ning ishlash prinsipini va bir nechta qiymat qaytarishni tushuntira olasiz
- `lambda` (anonim funksiya) qachon foydali ekanini bilasiz

## Nazariy qism

### Oddiy funksiya

```python
def salomlash(ism):
    """Berilgan ism bilan salomlashuv matnini chiqaradi."""
    print(f"Salom, {ism}!")

salomlash("Ali")     # Salom, Ali!
salomlash("Vali")     # Salom, Vali!
```

Funksiya — bir necha marta qayta ishlatiladigan kod bo'lagi. `"""..."""` — funksiyaning **docstring**i, uning nima qilishini tushuntiradi (`help(salomlash)` orqali ko'rish mumkin).

### `return` — natija qaytarish

```python
def kvadrat(son):
    return son ** 2

natija = kvadrat(5)
print(natija)    # 25
```

> ⚠️ **`print` va `return`ni chalkashtirmang.** `print()` — ekranga chiqaradi, lekin qiymatni qaytarmaydi (funksiyadan tashqarida ishlatib bo'lmaydi). `return` — qiymatni funksiyani chaqirgan joyga **qaytaradi**, uni o'zgaruvchiga saqlash yoki boshqa hisoblashda ishlatish mumkin. `return`siz funksiya avtomatik `None` qaytaradi.

### Bir nechta qiymat qaytarish (tuple orqali)

```python
def minmax(sonlar):
    return min(sonlar), max(sonlar)

kichik, katta = minmax([5, 2, 8, 1])
print(kichik, katta)    # 1 8
```

### Standart (default) qiymatli argumentlar

```python
def salomlash(ism, salom_matni="Salom"):
    print(f"{salom_matni}, {ism}!")

salomlash("Ali")                    # Salom, Ali!
salomlash("Vali", "Xayrli kun")     # Xayrli kun, Vali!
```

> ⚠️ **Muhim: mutable standart qiymatdan saqlaning.** `def funksiya(royxat=[]):` — bu **klassik Python xatosi**! Standart qiymat faqat **bir marta**, funksiya e'lon qilinganda yaratiladi va barcha chaqiriqlar orasida **umumiy** bo'lib qoladi:
```python
def qosh_element(element, royxat=[]):   # ❌ XATO namunasi
    royxat.append(element)
    return royxat

print(qosh_element(1))    # [1]
print(qosh_element(2))    # [1, 2] — kutilgan [2] emas!
```
✅ To'g'ri yechim — standart qiymat sifatida `None` ishlating:
```python
def qosh_element(element, royxat=None):
    if royxat is None:
        royxat = []
    royxat.append(element)
    return royxat
```

### Kalit so'zli (keyword) argumentlar

```python
def profil_yarat(ism, yosh, shahar):
    print(f"{ism}, {yosh} yosh, {shahar}")

profil_yarat("Ali", 25, "Toshkent")                        # pozitsion
profil_yarat(ism="Ali", shahar="Toshkent", yosh=25)         # kalit so'zli — tartib muhim emas
profil_yarat("Ali", shahar="Toshkent", yosh=25)              # aralash — pozitsion birinchi bo'lishi kerak
```

### `*args` — noma'lum sondagi pozitsion argumentlar

```python
def yigindi(*sonlar):
    return sum(sonlar)

print(yigindi(1, 2))          # 3
print(yigindi(1, 2, 3, 4, 5)) # 15
```

`*args` ichida barcha qo'shimcha pozitsion argumentlar **tuple** sifatida yig'iladi (`args` — konvensiya nomi, istalgan nom bo'lishi mumkin).

### `**kwargs` — noma'lum sondagi kalit so'zli argumentlar

```python
def profil_chiqar(**malumotlar):
    for kalit, qiymat in malumotlar.items():
        print(f"{kalit}: {qiymat}")

profil_chiqar(ism="Ali", yosh=25, shahar="Toshkent")
# ism: Ali
# yosh: 25
# shahar: Toshkent
```

`**kwargs` ichida barcha qo'shimcha kalit so'zli argumentlar **dict** sifatida yig'iladi.

### Argumentlar tartibi — barchasi birgalikda

```python
def murakkab_funksiya(a, b, *args, c=10, **kwargs):
    print(a, b, args, c, kwargs)

murakkab_funksiya(1, 2, 3, 4, c=99, d=5, e=6)
# 1 2 (3, 4) 99 {'d': 5, 'e': 6}
```

Tartib qat'iy: **oddiy pozitsion → `*args` → standart qiymatli → `**kwargs`**.

### `lambda` — anonim (bir qatorlik) funksiya

```python
kvadrat = lambda x: x ** 2
print(kvadrat(5))    # 25

# Oddiy funksiya bilan solishtirish:
def kvadrat_oddiy(x):
    return x ** 2
```

`lambda` — nomsiz, bitta ifodali funksiya yaratadi. U asosan boshqa funksiyalarga (`sorted()`, `max()`, `filter()`, `map()`) **argument sifatida** qisqa vaqtga kerak bo'lganda ishlatiladi:

```python
odamlar = [{"ism": "Ali", "yosh": 30}, {"ism": "Vali", "yosh": 20}]

# lambda yordamida yosh bo'yicha saralash
odamlar_saralangan = sorted(odamlar, key=lambda odam: odam["yosh"])
print(odamlar_saralangan)   # avval Vali (20), keyin Ali (30)

# map() va filter() bilan
sonlar = [1, 2, 3, 4, 5]
kvadratlar = list(map(lambda x: x ** 2, sonlar))
juftlar = list(filter(lambda x: x % 2 == 0, sonlar))
print(kvadratlar)   # [1, 4, 9, 16, 25]
print(juftlar)       # [2, 4]
```

> 📌 **Qachon `lambda`, qachon oddiy `def`:** agar funksiya bitta ifodadan iborat va faqat bir joyda, tez kerak bo'lsa (masalan, `sorted()`ning `key`si) — `lambda`. Agar funksiya nomlanishi, qayta ishlatilishi yoki bir nechta qatordan iborat bo'lishi kerak bo'lsa — har doim oddiy `def` ishlating. Ko'pchilik holatlarda, ayniqsa 2.4-darsda ko'rgan list comprehension ham `map()`/`filter()` + `lambda`ga qaraganda o'qilishi osonroq alternativa hisoblanadi.

## Amaliy misol

Oddiy kalkulyator funksiyalar to'plami:

```python
# kalkulyator.py

def qosh(*sonlar):
    return sum(sonlar)

def ayir(a, b):
    return a - b

def kopaytir(*sonlar):
    natija = 1
    for son in sonlar:
        natija *= son
    return natija

def hisobla(amal, *sonlar, yaxlitlash=None):
    amallar = {
        "qoshish": qosh,
        "kopaytirish": kopaytir,
    }
    if amal not in amallar:
        return None
    natija = amallar[amal](*sonlar)
    if yaxlitlash is not None:
        natija = round(natija, yaxlitlash)
    return natija


print(hisobla("qoshish", 1, 2, 3, 4))                 # 10
print(hisobla("kopaytirish", 2, 3, 4))                 # 24
print(hisobla("qoshish", 1.5, 2.333, yaxlitlash=2))    # 3.83
```

Diqqat qiling: `amallar[amal](*sonlar)` — lug'atdan olingan funksiyani `*sonlar` orqali chaqirish; `*` bu yerda ro'yxatni **"yoyib"** (unpack qilib) alohida argumentlarga aylantiradi.

## Keng tarqalgan xatolar

**Xato 1:** mutable (`list`, `dict`) standart qiymat ishlatish.
❌ `def funksiya(royxat=[]):` — yuqorida ko'rsatilgan sababga ko'ra, chaqiriqlar orasida "xotira" saqlanib qoladi.
✅ To'g'ri: standart qiymat sifatida `None` ishlating, funksiya ichida `if royxat is None: royxat = []`.

**Xato 2:** `return`ni unutib, funksiya `None` qaytarishini kutmaslik.
❌ 
```python
def kvadrat(x):
    x ** 2    # return yo'q!

natija = kvadrat(5)
print(natija)    # None — kutilgan 25 emas
```
✅ To'g'ri: qiymat qaytarish kerak bo'lgan har bir funksiyada `return` yozishni unutmang.

**Xato 3:** `*args`dan keyin standart qiymatsiz oddiy argument qo'shishga urinish.
❌ `def funksiya(*args, b):` — bu holda `b` **majburiy kalit so'zli argumentga** aylanadi (`funksiya(1, 2, b=3)` deb chaqirish kerak), oddiy pozitsion sifatida chaqirib bo'lmaydi — bu ko'p dasturchini chalg'itadi.
✅ To'g'ri: agar `*args`dan keyin argument kerak bo'lsa, uni har doim kalit so'zi bilan chaqirishni unutmang, yoki funksiya signaturasini qayta ko'rib chiqing.

## Mashq/topshiriq

**(Oson)** `daraja(asos, korsatkich=2)` funksiyasini yozing — standart holda kvadratni, agar `korsatkich` berilsa, shu darajani hisoblasin.

**(O'rtacha)** `eng_kop_uchraydigan(*elementlar)` funksiyasini yozing — berilgan barcha elementlar ichidan eng ko'p takrorlangan qiymatni qaytarsin (`max()` va `key=elementlar.count` yoki lug'at bilan).

**(Qiyin)** `filtrla_va_transformatsiya(royxat, filtr_funksiya, transform_funksiya)` nomli funksiya yozing — `filtr_funksiya` (masalan, `lambda x: x > 0`) orqali ro'yxatni filtrlasin, so'ng qolgan elementlarga `transform_funksiya`ni (masalan, `lambda x: x * 2`) qo'llab, natija ro'yxatini qaytarsin. Buni chaqirishda `lambda` ishlating.

## Qisqacha xulosa

Funksiyalar (`def`) — kodni qayta ishlatish va tuzilmalashtirish uchun asosiy vosita bo'lib, `return` orqali natija qaytaradi (bir nechta qiymat — `tuple` orqali), standart qiymatlar (`=standart`, lekin hech qachon mutable emas), `*args` (qo'shimcha pozitsion) va `**kwargs` (qo'shimcha kalit so'zli) argumentlar moslashuvchan interfeys yaratadi; `lambda` esa — bitta ifodali, qisqa muddatli funksiyalar (masalan, `sorted()`ning `key`si) uchun qulay qisqartma, lekin murakkab mantiq uchun har doim oddiy `def` afzal.
