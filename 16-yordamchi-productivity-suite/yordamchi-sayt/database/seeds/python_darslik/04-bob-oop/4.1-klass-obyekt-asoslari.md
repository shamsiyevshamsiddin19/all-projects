# Klass va obyekt asoslari

## Bu darsda nimalarni o'rganasiz

- Klass (class) va obyekt (object) orasidagi farqni tushuntira olasiz
- `__init__` konstruktorini va `self` parametrini to'g'ri qo'llay olasiz
- Instance (obyekt) va klass atributlari orasidagi farqni bilasiz
- O'z metodlaringizni yozib, obyekt xatti-harakatini belgilay olasiz

## Nazariy qism

### Klass va obyekt nima

**Klass** (class) — obyekt yaratish uchun "andoza" yoki "chizma" (masalan, "uy loyihasi"). **Obyekt** (instance) — shu andoza asosida yaratilgan **haqiqiy narsa** (masalan, "loyiha asosida qurilgan aniq uy"). OOP (Object-Oriented Programming — obyektga yo'naltirilgan dasturlash) — ma'lumot (atributlar) va uni boshqaruvchi funksiyalar (metodlar)ni bitta birlikka (klass) birlashtirish g'oyasiga asoslanadi.

```python
class Mashina:
    pass    # hozircha bo'sh klass

mening_mashinam = Mashina()      # obyekt (instance) yaratish
sizning_mashinangiz = Mashina()   # yana bir, mustaqil obyekt

print(type(mening_mashinam))      # <class '__main__.Mashina'>
print(mening_mashinam is sizning_mashinangiz)   # False — ikkalasi turli obyektlar
```

### `__init__` — konstruktor

`__init__` — obyekt yaratilganda **avtomatik** chaqiriladigan maxsus metod, unda obyektning boshlang'ich holatini (atributlarini) belgilaymiz:

```python
class Mashina:
    def __init__(self, marka, model, yil):
        self.marka = marka    # self.marka — obyektning ATRIBUTI
        self.model = model
        self.yil = yil
        self.tezlik = 0        # boshlang'ich qiymat, argument sifatida berilmagan

mashina1 = Mashina("Chevrolet", "Cobalt", 2023)
mashina2 = Mashina("Toyota", "Camry", 2022)

print(mashina1.marka)    # Chevrolet
print(mashina2.marka)    # Toyota — har bir obyekt o'z alohida ma'lumotiga ega
```

### `self` — bu nima va nega har bir metodda kerak

`self` — metod ichida **"aynan shu obyektning o'zi"**ga ishora qiladi. Python'da metod chaqirilganda (`mashina1.tezlan()`), Python avtomatik ravishda `mashina1`ni birinchi argument (`self`) sifatida uzatadi — buni qo'lda yozish shart emas, lekin metod **ta'rifida** `self` har doim birinchi parametr bo'lishi kerak:

```python
class Mashina:
    def __init__(self, marka, tezlik=0):
        self.marka = marka
        self.tezlik = tezlik

    def tezlan(self, qiymat):
        self.tezlik += qiymat
        print(f"{self.marka} tezligi: {self.tezlik} km/soat")

    def tormozla(self):
        self.tezlik = 0
        print(f"{self.marka} to'xtadi")


mashina1 = Mashina("Chevrolet")
mashina1.tezlan(50)     # Python avtomatik: Mashina.tezlan(mashina1, 50)
mashina1.tezlan(30)
mashina1.tormozla()
```

### Instance atributlari vs klass atributlari

```python
class Mashina:
    gildirak_soni = 4    # KLASS atributi — barcha obyektlar orasida UMUMIY

    def __init__(self, marka):
        self.marka = marka    # INSTANCE atributi — har bir obyektga XOS

mashina1 = Mashina("Chevrolet")
mashina2 = Mashina("Toyota")

print(mashina1.gildirak_soni)   # 4 — klass atributiga har ikkalasi ham murojaat qiladi
print(mashina2.gildirak_soni)   # 4

Mashina.gildirak_soni = 6        # klass atributini o'zgartirish — HAMMASIGA ta'sir qiladi
print(mashina1.gildirak_soni)   # 6
print(mashina2.gildirak_soni)   # 6

mashina1.gildirak_soni = 3        # bu FAQAT mashina1 uchun YANGI instance atribut yaratadi!
print(mashina1.gildirak_soni)   # 3
print(mashina2.gildirak_soni)   # 6 — o'zgarmadi
```

Klass atributlari — barcha obyektlar orasida **umumiy**, o'zgarmas yoki kamdan-kam o'zgaradigan ma'lumotlar uchun (masalan, doimiylar, standart sozlamalar) ishlatiladi.

### `__str__` — obyektni chiroyli chiqarish

```python
class Mashina:
    def __init__(self, marka, model):
        self.marka = marka
        self.model = model

    def __str__(self):
        return f"{self.marka} {self.model}"


mashina1 = Mashina("Chevrolet", "Cobalt")
print(mashina1)    # Chevrolet Cobalt — __str__ avtomatik chaqiriladi

# __str__siz:
# print(mashina1)  ->  <__main__.Mashina object at 0x7f...> — foydasiz manzil
```

`__str__` — Python'ning "magic method"laridan biri (5-bobning oxirida yana ko'p magic metodlarni ko'ramiz), `print()` yoki `str()` obyektga qo'llanganda avtomatik chaqiriladi.

### Metodlar ichida boshqa metodlarni chaqirish

```python
class BankHisobi:
    def __init__(self, egasi, balans=0):
        self.egasi = egasi
        self.balans = balans

    def tolov_qil(self, summa):
        if summa > self.balans:
            print("Balansda yetarli mablag' yo'q!")
            return False
        self.balans -= summa
        self._tarix_yoz(f"To'lov: -{summa}")
        return True

    def toldirish(self, summa):
        self.balans += summa
        self._tarix_yoz(f"To'ldirish: +{summa}")

    def _tarix_yoz(self, xabar):     # boshida _ — "ichki, tashqaridan chaqirilmasin" konvensiyasi
        print(f"[{self.egasi}] {xabar}, yangi balans: {self.balans}")


hisob = BankHisobi("Ali", 100000)
hisob.toldirish(50000)
hisob.tolov_qil(30000)
```

`_tarix_yoz` — boshida bitta pastki chiziq (`_`) bilan boshlangan metod nomi — Python'da **konvensiya** bo'yicha "bu metod klass ichidan foydalanish uchun, tashqaridan to'g'ridan-to'g'ri chaqirilmasin" degan ma'noni bildiradi (lekin texnik jihatdan bu hech narsani majburlamaydi — Python'da haqiqiy "private" tushunchasi yo'q, bu shunchaki kelishuv).

## Amaliy misol

Oddiy "Kitob" va "Kutubxona" klasslari:

```python
# kutubxona_oop.py

class Kitob:
    def __init__(self, nom, muallif, sahifalar):
        self.nom = nom
        self.muallif = muallif
        self.sahifalar = sahifalar
        self.oqilgan = False

    def __str__(self):
        holat = "o'qilgan" if self.oqilgan else "o'qilmagan"
        return f"«{self.nom}» — {self.muallif} ({self.sahifalar} bet, {holat})"

    def oqib_chiq(self):
        self.oqilgan = True


class Kutubxona:
    def __init__(self, nomi):
        self.nomi = nomi
        self.kitoblar = []

    def kitob_qosh(self, kitob):
        self.kitoblar.append(kitob)
        print(f"«{kitob.nom}» kutubxonaga qo'shildi.")

    def oqilganlar_soni(self):
        return sum(1 for kitob in self.kitoblar if kitob.oqilgan)

    def hammasini_korsat(self):
        for kitob in self.kitoblar:
            print(f"  {kitob}")


kutubxona = Kutubxona("Mahalla kutubxonasi")
kitob1 = Kitob("O'tkan kunlar", "Abdulla Qodiriy", 320)
kitob2 = Kitob("Sariq devni minib", "X. To'xtaboyev", 280)

kutubxona.kitob_qosh(kitob1)
kutubxona.kitob_qosh(kitob2)

kitob1.oqib_chiq()

kutubxona.hammasini_korsat()
print(f"O'qilgan kitoblar soni: {kutubxona.oqilganlar_soni()} / {len(kutubxona.kitoblar)}")
```

## Keng tarqalgan xatolar

**Xato 1:** metod ta'rifida `self`ni yozishni unutish.
❌ 
```python
class Mashina:
    def tezlan(qiymat):    # self yo'q!
        ...
```
`mashina1.tezlan(50)` chaqirilganda `TypeError: tezlan() takes 1 positional argument but 2 were given` xatosi chiqadi (chunki Python baribir `mashina1`ni birinchi argument sifatida uzatadi, lekin metod uni kutmagan).
✅ To'g'ri: har bir instance metodida birinchi parametr har doim `self` bo'lishi kerak.

**Xato 2:** `__init__` ichida `self.`ni unutib, oddiy lokal o'zgaruvchi yaratish.
❌ 
```python
def __init__(self, marka):
    marka = marka    # bu FAQAT lokal o'zgaruvchi, obyektga saqlanmaydi!
```
Bu holda `mashina1.marka` chaqirilganda `AttributeError` beradi, chunki `self.marka` hech qachon o'rnatilmagan.
✅ To'g'ri: obyektga saqlash uchun har doim `self.marka = marka` yozing (chap tomonda `self.` bo'lishi shart).

**Xato 3:** klass atributini instance darajasida "o'zgartirish" deb o'ylab, aslida yangi instance atribut yaratib qo'yish.
❌ Yuqoridagi misolda ko'rganimizdek, `mashina1.gildirak_soni = 3` — bu `Mashina.gildirak_soni`ni o'zgartirmaydi, faqat `mashina1` uchun **yangi, alohida** instance atribut yaratadi.
✅ To'g'ri: agar barcha obyektlarga tegishli qiymatni o'zgartirish kerak bo'lsa, klass nomi orqali murojaat qiling: `Mashina.gildirak_soni = 6`.

## Mashq/topshiriq

**(Oson)** `Talaba` klassini yozing — `ism`, `yosh` va `fakultet` atributlari bilan, va `tanishtir(self)` metodi bilan — bu metod `"Salom, men <ism>, <yosh> yoshdaman, <fakultet> fakultetida o'qiyman"` deb chiqarsin.

**(O'rtacha)** `Hisoblagich` klassini yozing — `qiymat=0` bilan boshlanadigan, `oshir(self, miqdor=1)` va `kamaytir(self, miqdor=1)` metodlari bilan, va `__str__` orqali joriy qiymatni chiroyli chiqaradigan qilib.

**(Qiyin)** `Savat` (xarid savati) klassini yozing — `mahsulotlar` (dict: nom -> narx) instance atributi bilan boshlanadi (bo'sh dict), `qosh(self, nom, narx)`, `ochir(self, nom)` va `jami_narx(self)` (barcha mahsulotlar narxi yig'indisini qaytaruvchi) metodlari bilan; `__str__` orqali savatdagi barcha mahsulotlar va jami narxni chiroyli chiqaring.

## Qisqacha xulosa

Klass — obyekt yaratish andozasi, obyekt (instance) — shu andoza asosida yaratilgan haqiqiy narsa; `__init__` — obyekt yaratilganda avtomatik chaqiriladigan konstruktor, `self` — metod ichida "aynan shu obyekt"ga ishora qiladi; instance atributlari (`self.x`) har bir obyektga xos, klass atributlari esa barcha obyektlar orasida umumiy — bu farqni tushunish OOP'ning butun qolgan qismi (meros, inkapsulyatsiya, polimorfizm) uchun poydevor bo'lib xizmat qiladi.
