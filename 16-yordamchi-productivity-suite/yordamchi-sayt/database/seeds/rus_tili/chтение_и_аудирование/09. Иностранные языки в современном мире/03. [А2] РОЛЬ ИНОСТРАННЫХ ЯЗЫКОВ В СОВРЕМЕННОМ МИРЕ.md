# [А2] РОЛЬ ИНОСТРАННЫХ ЯЗЫКОВ В СОВРЕМЕННОМ МИРЕ

:: Zamonaviy odamning chet tilini bilmasdan o'sishi va rivojlanishi qiyin.
Иностра́нные языки́ {игра́ют|o'ynash} {о́чень|juda} {ва́жную|muhim} {роль|roli} {в|da / ga} {на́шей|bizning} {жи́зни|hayot}.
:: Chet tillari hayotimizda juda muhim o‘rin tutadi.
{Одни́|yolg'iz} начина́ют {изуче́ние|o'rganish} {иностра́нных|xorijiy} языко́в, {потому́|shu uchun} {что|nima / deb} {э́ти|bular} {зна́ния|bilim} необходи́мы {на|da / ustida} рабо́те, {други́е|boshqalar} у́чат {иностра́нный|xorijiy}, {потому́|shu uchun} {что|nima / deb} {их|ularni / ularning} {жизнь|hayot} свя́зана {с|bilan / dan} путеше́ствиями, {есть|ha} {и|va} таки́е, {для|uchun} {кото́рых|qaysi} {изуче́ние|o'rganish} языко́в – {про́сто|shunchaki} хо́бби.
:: Ba'zi odamlar chet tillarini o'rganishni boshlaydilar, chunki bu bilim ishda kerak, boshqalari chet tilini o'rganishadi, chunki ularning hayoti sayohat bilan bog'liq, shuningdek, til o'rganish shunchaki sevimli mashg'ulot bo'lganlar ham bor.
{Лю́ди|odamlar}, {кото́рые|qaysi} владе́ют иностра́нными языка́ми, {мо́гут|mumkin} {свобо́дно|erkin} {обща́ться|muloqot qilmoq} {с|bilan / dan} {людьми́|odamlar} {из|dan} {други́х|boshqalar} {стран|mamlakatlar}, {чита́ть|o'qimoq} произведе́ния {иностра́нных|xorijiy} {а́второв|mualliflar} {в|da / ga} оригина́ле {и|va} т. {д|d}., {что|nima / deb} {значи́тельно|sezilarli darajada} расширя́ет {их|ularni / ularning} кругозо́р.
:: Chet tillarida so'zlashadigan odamlar boshqa mamlakatlardan kelgan odamlar bilan bemalol muloqot qilishlari, chet el mualliflarining asarlarini asl nusxada o'qishlari va hokazolar, bu ularning dunyoqarashini sezilarli darajada kengaytiradi.

Са́мыми популя́рными языка́ми {в|da / ga} {ми́ре|dunyo} {на|da / ustida} {сего́дняшний|bugungi} {день|kun} явля́ются {францу́зский|frantsuzcha}, {италья́нский|italyancha}, {испа́нский|ispancha}, {англи́йский|inglizcha}, {ру́сский|rus}, {неме́цкий|nemis} {и|va} {други́е|boshqalar} языки́.
:: Bugungi kunda dunyodagi eng mashhur tillar - frantsuz, italyan, ispan, ingliz, rus, nemis va boshqa tillar.
{Восто́чные|sharqiy} языки́ {та́кже|shuningdek} набира́ют популя́рность.
:: Sharq tillari ham ommalashib bormoqda.
{К|ga / tomon} приме́ру, {о́чень|juda} {распространено́|keng tarqalgan} {изуче́ние|o'rganish} {кита́йского|xitoy} языка́.
:: Misol uchun, xitoy tilini o'rganish juda keng tarqalgan.
{Но|lekin} {восто́чные|sharqiy} языки́ вы́учить сложне́е, так {как|qanday / kabi} {они́|ular} облада́ют {абсолю́тно|mutlaqo} {друго́й|boshqa} систе́мой {письма́|harflar}, произноше́нием зву́ков {и|va} интона́цией.
:: Ammo sharq tillarini o'rganish qiyinroq, chunki ularda yozuv tizimi, tovushlarning talaffuzi va intonatsiyasi mutlaqo boshqacha.

{Есть|ha} {и|va} така́я {гру́ппа|guruh} языко́в, {как|qanday / kabi} {мёртвые|o'lik} языки́, {они́|ular} представля́ют собо́й {интере́с|qiziqish} {для|uchun} специали́стов-фило́логов, {а|esa / lekin} {та́кже|shuningdek} {для|uchun} {люде́й|odamlar}, {изуча́ющих|o'qish} {исто́рию|tarix} {дре́вних|qadimiy} цивилиза́ций.
:: O'lik tillar kabi tillar guruhi ham mavjud; ular filologlar, shuningdek, qadimgi sivilizatsiyalar tarixini o'rganuvchi odamlar uchun qiziqish uyg'otadi.
{Мно́гие|ko`pi} {́студе́нты|talabalar}, {кото́рые|qaysi} поступа́ют {в|da / ga} Гро́дненский {госуда́рственный|davlat} {университе́т|universitet} {и́мени|nomi} Я́нки Купа́лы, {изуча́ют|o'rganish} {лати́нский|lotin} {язы́к|til}.
:: Grodnodagi Yanka Kupala davlat universitetiga kirgan ko'plab talabalar lotin tilini o'rganishadi.

Тот {факт|dalil}, {что|nima / deb} {всё|hammasi} {бо́льше|ko'proq} {люде́й|odamlar} выбира́ют иностра́нные языки́ {в|da / ga} {ка́честве|sifat} {своего́|uning} хо́бби, объясня́ется тем, {что|nima / deb} {изуче́ние|o'rganish} {иностра́нных|xorijiy} языко́в {поле́зно|foydali} {не|emas / -ma} {то́лько|faqat} {для|uchun} бу́дущей профе́ссии {и|va} учёбы, {но|lekin} {и|va} {для|uchun} разви́тия мо́зга челове́ка.
:: Ko'proq odamlar chet tillarini sevimli mashg'uloti sifatida tanlayotgani, chet tillarini o'rganish nafaqat kelajakdagi kasb va o'qish uchun, balki inson miyasini rivojlantirish uchun ham foydali ekanligi bilan izohlanadi.
{Чем|нима билан} {бо́льше|ko'proq} {иностра́нных|xorijiy} языко́в {мы|biz} изуча́ем, тем {бо́льше|ko'proq} ша́нсов {на|da / ustida} то, {что|nima / deb} {мы|biz} {доживём|yashaymiz} {до|gacha} глубо́кой ста́рости {в|da / ga} здра́вом уме́ {и|va} {при|huzurida} хоро́шей па́мяти.
:: Qanchalik ko'p chet tillarini o'rgansak, sog'lom aql va yaxshi xotiraga ega bo'lgan etuk yoshga qadar yashash imkoniyati shunchalik ko'p bo'ladi.
