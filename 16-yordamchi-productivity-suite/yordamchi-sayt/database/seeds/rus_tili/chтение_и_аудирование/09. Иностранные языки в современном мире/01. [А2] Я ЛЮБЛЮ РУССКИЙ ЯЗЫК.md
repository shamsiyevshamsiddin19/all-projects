# [А2] Я ЛЮБЛЮ РУССКИЙ ЯЗЫК

{Одна́жды|bir marta}, {когда́|qachon} {я|men} {была|edi} {в|da / ga} Ве́нгрии, {я|men} познако́милась {с|bilan / dan} одно́й {знамени́той|mashhur} же́нщиной, {кото́рую|қайси …ни} {зову́т|chaqirishadi / ismi} {Като́|kato} {Ломб|lomb}.
:: Bir kuni men Vengriyada bo'lganimda Kato Lomb ismli mashhur ayolni uchratdim.
{Э́та|bu} {же́нщина|ayol kishi} рабо́тает перево́дчицей.
:: Bu ayol tarjimon bo'lib ishlaydi.
{Она́|u} {зна́ет|biladi}  языко́в.
:: U 16 ta tilni biladi.

– {Во́семь|8} языко́в {я|men} {зна́ю|bilaman} {акти́вно|faol tarzda}, {а|esa / lekin} {во́семь|8} пасси́вно, – {говори́т|deydi} {она́|u}.
:: "Men sakkizta tilni faol, sakkiztasini passiv bilaman", deydi u.
{Она́|u} {зна́ет|biladi} {акти́вно|faol tarzda} {францу́зский|frantsuzcha}, {англи́йский|inglizcha}, {испа́нский|ispancha}, {неме́цкий|nemis}, {кита́йский|xitoycha}, {русский|rus}, {япо́нский|yapon}, {а|esa / lekin} пасси́вно – {лати́нский|lotin}, румы́нский, {по́льский|polshaniki}, болга́рский {и|va} {други́е|boshqalar} языки́.
:: U fransuz, ingliz, ispan, nemis, xitoy, rus, yapon tillarini faol biladi va passiv ravishda lotin, rumin, polyak, bolgar va boshqa tillarni biladi.

{Като́|kato} изуча́ла {в|da / ga} шко́ле {два|2} языка́: {францу́зский|frantsuzcha} {и|va} {лати́нский|lotin}.
:: Kato maktabda ikki tilni o'rgangan: frantsuz va lotin.
{Кита́йский|xitoycha} {язы́к|til} {она́|u} изуча́ла {с|bilan / dan} учи́тельницей, {а|esa / lekin} {все́|hamma / barcha} {остальны́е|qolganlari} языки́ {она́|u} изуча́ла {самостоя́тельно|mustaqil}.
:: U o'qituvchi bilan xitoy tilini o'rgangan va boshqa barcha tillarni mustaqil o'rgangan.

– {Мой|mening} са́мый {люби́мый|sevimli} {язы́к|til} – {ру́сский|rus}, – {говори́т|deydi} {Като́|kato} {Ломб|lomb}.
:: "Mening sevimli tilim rus tili", deydi Kato Lomb.
{Э́то|bu} {язы́к|til}, {у|huzurida / da} {кото́рого|қайси …нинг} са́мая тру́дная {структу́ра|tuzilish}, {э́то|bu} са́мый {краси́вый|chiroyli} {язы́к|til}.
:: Bu eng qiyin tuzilishga ega bo'lgan til, eng go'zal tildir.

{Като́|kato} {говори́т|deydi} {по|bo'ylab / bo'yicha}-ру́сски {пра́вильно|to`g`ri}, {без|siz} {оши́бок|xatolar}, {иногда́|ba'zan} {то́лько|faqat} {де́лает|qiladi} непра́вильное ударе́ние.
:: Kato rus tilida to'g'ri, xatosiz gapiradi, ba'zida u shunchaki noto'g'ri urg'u qo'yadi.

– {Я|men} {была́|edi} {во|da / ga} {мно́гих|ko'p} {стра́нах|mamlakatlar} {и|va} встреча́лась {с|bilan / dan} разли́чными {людьми́|odamlar}.
:: – Ko‘p mamlakatlarda bo‘lganman, turli odamlar bilan tanishganman.
{Я|men} ду́маю, {что|nima / deb} {сейча́с|hozir} {зна́ние|bilim} языко́в {как|qanday / kabi} {никогда́|hechqachon} {ва́жно|muhim}.
:: Menimcha, hozir tillarni bilish har qachongidan ham muhimroq.
{Мир|jahon} {на|da / ustida} {земле́|yer} {не|emas / -ma} {мо́жет|balki} {быть|bo'lmoq} {без|siz} понима́ния {друг|do'st} {дру́га|do'st}, {без|siz} {встреч|uchrashuvlar}, {без|siz} понима́ния {и|va} {зна́ния|bilim} разли́чных культу́р.
:: Bir-birini tushunmasdan, uchrashuvlarsiz, turli madaniyatlarni tushunmasdan va bilmasdan turib, er yuzida tinchlik bo'lmaydi.
{Что́бы|maqsadida} {понима́ть|tushunmoq} {друг|do'st} {дру́га|do'st}, {мы|biz} {должны́|kerak} {знать|bilish} языки́.
:: Bir-birimizni tushunishimiz uchun tillarni bilishimiz kerak.

{Като́|kato} {Ломб|lomb} – {челове́к|odam}, {кото́рый|қайси} {не|emas / -ma} {то́лько|faqat} {лю́бит|sevadi} {свою́|sizning} рабо́ту, {но|lekin} {и|va} увлека́ется {е́ю|u bilan}.
:: Kato Lomb nafaqat o'z ishini yaxshi ko'radigan, balki unga ishtiyoqli odam.
{Она́|u} подари́ла {мне|menga} {кни́гу|kitob}, {кото́рую|қайси …ни} {она́|u} написа́ла.
:: U menga yozgan kitobini berdi.
{Кни́га|kitob} {называ́ется|chaqirdi} «{Как|qanday / kabi} {я|men} вы́учила  языко́в».
:: Kitob "Men 16 ta tilni qanday o'rgandim" deb nomlangan.
{Като́|kato} {Ломб|lomb} {лю́бит|sevadi} литерату́ру, {мно́го|ko'p} чита́ет, {занима́ется|shug'ullanadi} гимна́стикой.
:: Kato Lomb adabiyotni yaxshi ko'radi, ko'p o'qiydi va gimnastika bilan shug'ullanadi.
{Я|men} спроси́л {Като́|kato}, {как|qanday / kabi} {она́|u} изуча́ет иностра́нные языки́.
:: Men Katodan chet tillarini qanday o'rganishini so'radim.
{Она́|u} сказа́ла: – {Что́бы|maqsadida} {хорошо́|yaxshi} {знать|bilish} {язы́к|til}, {ну́жно|kerak} {занима́ться|shug`ullanmoq} {ка́ждый|hamma} {день|kun}.
:: U shunday dedi: "Tilni yaxshi bilish uchun har kuni o'qish kerak."
{Челове́к|odam} {до́лжен|bo'lishi kerak} {испо́льзовать|foydalanmoq} {всё|hammasi}, {что|nima / deb} {даёт|beradi} совреме́нная те́хника: фи́льмы, {му́зыку|musiqa}.
:: Inson zamonaviy texnologiya taqdim etadigan hamma narsadan foydalanishi kerak: filmlar, musiqa.
{На́до|zarur} {слу́шать|tinglamoq}, {чита́ть|o'qimoq}, {говори́ть|gapirmoq}.
:: Siz tinglashingiz, o'qishingiz, gapirishingiz kerak.
{Что́бы|maqsadida} изучи́ть {язы́к|til}, {ну́жно|kerak} {то́лько|faqat} {большо́е|katta} {жела́ние|istak} {знать|bilish} {его́|uni / uning}.
:: Tilni o'rganish uchun faqat uni bilishga bo'lgan katta istak kerak.
{Я|men} {не|emas / -ma} встреча́ла {ни|hech / na} {одного́|bitta} челове́ка, {кото́рый|қайси} {не|emas / -ma} {мог|mumkin} вы́учить {язы́к|til}.
:: Til o‘rgana olmagan birorta odamni uchratmadim.
