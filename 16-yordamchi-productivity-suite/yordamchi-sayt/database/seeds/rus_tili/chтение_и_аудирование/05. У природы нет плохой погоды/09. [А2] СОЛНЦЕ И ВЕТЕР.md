{Они́|ular} {до́лго|uzoq} {спо́рили|bahslashdi} {и|va} {наконе́ц|nihoyat} {реши́ли|qaror qildi} {прове́рить|tekshirish} {свою́|sizning} {силу́|kuch} {на|da / ustida / ga} {челове́ке|odam}, {кото́рый|qaysi} {в|da / ga / ichida} {э́то|bu} {вре́мя|vaqt} {е́хал|haydab ketayotgan edi} {на|da / ustida / ga} {ло́шади|otlar} {по|bo'yicha} {доро́ге|yo'l}.
:: Ular uzoq tortishib, nihoyat, o‘sha paytda yo‘l bo‘ylab ot mingan odamda kuchini sinab ko‘rishga qaror qilishdi.

– {Посмотри́|qarang}, – {сказа́л|dedi} {Ве́тер|shamol}, – {как|qanday / kabi} {бы́стро|tez} {я|men} {сниму́|men uni yechib tashlayman} {с|bilan / dan} {него́|uni / uning} {пальто́|palto}.

{Сказа́л|dedi} – {и|va} {на́чал|boshlandi} {о́чень|juda} {си́льно|kuchli} {дуть|zarba}.
:: - dedi va juda qattiq zarba bera boshladi.
{Но́|lekin} {че́м|dan} {бо́льше|ko'proq} {стара́лся|harakat qildi} {Ве́тер|shamol}, {тем|o'sha bilan} {кре́пче|kuchliroq} {держа́л|o'tkazildi} {своё|o'z} {пальто́|palto} {челове́к|odam}.

{Он|u} {жа́ловался|shikoyat qildi} {на|da / ustida / ga} {непого́ду|yomon ob-havo}, {но|lekin} {е́хал|haydab ketayotgan edi} {всё|hammasi} {да́льше|yana} {и|va} {да́льше|yana}.
:: U ob-havoning yomonligidan shikoyat qildi, lekin minib yurdi.
{Ве́тер|shamol} {серди́лся|g'azablangan}, {сыпа́л|sepilgan} {на|da / ustida / ga} {бе́дного|kambag'al} {челове́ка|odam} {дождём|yomg'ir} {и|va} {сне́гом|qor}.
:: Shamol g'azablanib, kambag'alning ustiga yomg'ir va qor yog'di.
{Челове́к|odam} {держа́л|o'tkazildi} {пальто́|palto} {ещё|yana / hali} {кре́пче|kuchliroq}.
:: Erkak paltosini yanada qattiqroq ushlab oldi.
{Тогда́|keyin} {Ве́тер|shamol} {убеди́лся|ishonch hosil qilgan}, {что|nima / deb} {ему́|unga} {не|emas / -ma} {уда́стся|muvaffaqiyatga erishadi} {снять|olib tashlash} {с|bilan / dan} {челове́ка|odam} {пальто́|palto}.
:: Shunda Shamol odamning ko'ylagini yecha olmasligiga amin bo'ldi.

{Со́лнце|quyosh}, {кото́рое|qaysi} {ви́дело|ko'rgan}, {что|nima / deb} {Ве́тер|shamol} {ничего́|hech narsa} {не|emas / -ma} {мо́жет|oladi / mumkin} {сде́лать|qilmoq}, {улыбну́лось|tabassum qildi}, {вы́глянуло|tashqariga qaradi} {и́з-за|sababli / orqasidan} {облако́в|bulutlar}, {нагре́ло|qizdirilgan} {зе́млю|yer}, {а|esa / lekin} {вме́сте|birga} {с|bilan / dan} {ней|unda / u haqida} {и|va} {бе́дного|kambag'al} {челове́ка|odam}.
:: Shamolning hech narsa qila olmasligini ko'rgan Quyosh jilmayib, bulutlar ortidan qaradi, yerni qizdirdi va u bilan bechora.

:: Erkak iliqlikni his qilganda, u xursand bo'ldi va Quyoshga minnatdorchilik bildirdi.

:: Keyin paltosini yechdi.
