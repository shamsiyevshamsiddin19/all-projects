# Birinchi FastAPI ilovasi va avtomatik hujjatlar

## Bu darsda nimalarni o'rganasiz

- Birinchi FastAPI ilovasini yozasiz va ishga tushirasiz
- `fastapi dev` buyrug'i orqali development serverini boshqarasiz
- Path operation (yo'l amali) va HTTP metodlari tushunchasini o'rganasiz
- Avtomatik Swagger UI va ReDoc hujjatlaridan foydalanishni bilasiz

## Nazariy qism

### Minimal FastAPI ilovasi

FastAPI ilovasi — bitta `FastAPI` obyektini yaratishdan boshlanadi:

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def bosh_sahifa():
    return {"xabar": "Salom, FastAPI!"}
```

Bu — to'liq, ishlaydigan API. E'tibor bering:

| Qism | Vazifasi |
|---|---|
| `FastAPI()` | Ilovaning asosiy obyekti — barcha yo'llar shu obyekt orqali ro'yxatga olinadi |
| `@app.get("/")` | **Dekorator** — "GET so'rovi `/` manziliga kelganda, quyidagi funksiyani chaqir" degan ma'noni bildiradi |
| `def bosh_sahifa()` | **Path operation function** — so'rovni qayta ishlovchi oddiy Python funksiyasi |
| `return {...}` | Python lug'ati (dict) — FastAPI buni **avtomatik** JSON'ga aylantiradi |

### Ilovani ishga tushirish

```bash
uv run fastapi dev main.py
```

| Buyruq qismi | Vazifasi |
|---|---|
| `fastapi dev` | Development (rivojlantirish) rejimida serverni ishga tushiradi — kod o'zgarganda avtomatik qayta yuklanadi (hot reload) |
| `main.py` | `app` obyekti joylashgan fayl |

Konsolda quyidagiga o'xshash chiqish paydo bo'ladi:

```
INFO     Uvicorn running on http://127.0.0.1:8000
```

Brauzerda `http://127.0.0.1:8000` manzilini ochsangiz, `{"xabar": "Salom, FastAPI!"}` JSON javobini ko'rasiz.

> 📌 **`fastapi dev` vs `fastapi run`:** `fastapi dev` — faqat rivojlantirish (development) uchun, avtomatik qayta yuklash bilan; `fastapi run` — production uchun mo'ljallangan, optimallashtirilgan rejim (7-bobda batafsil ko'riladi).

### HTTP metodlari — asosiy tushuncha

REST API'lar, odatda to'rtta asosiy HTTP metodidan foydalanadi:

| Metod | Vazifasi | FastAPI dekoratori |
|---|---|---|
| `GET` | Ma'lumot olish (o'qish) | `@app.get(...)` |
| `POST` | Yangi ma'lumot yaratish | `@app.post(...)` |
| `PUT` | Mavjud ma'lumotni to'liq yangilash | `@app.put(...)` |
| `PATCH` | Mavjud ma'lumotni qisman yangilash | `@app.patch(...)` |
| `DELETE` | Ma'lumotni o'chirish | `@app.delete(...)` |

```python
@app.get("/mahsulotlar")
def mahsulotlar_royxati():
    return {"mahsulotlar": ["noutbuk", "telefon"]}

@app.post("/mahsulotlar")
def yangi_mahsulot():
    return {"xabar": "Mahsulot yaratildi"}
```

### Avtomatik interaktiv hujjatlar — FastAPI'ning eng katta afzalligi

Server ishga tushgach, ikkita **avtomatik yaratilgan** hujjat sahifasi mavjud bo'ladi — bironta qo'shimcha kod yozmasdan:

| Manzil | Vositasi |
|---|---|
| `http://127.0.0.1:8000/docs` | **Swagger UI** — interaktiv, har bir endpoint'ni to'g'ridan-to'g'ri brauzerda "sinab ko'rish" (Try it out) imkoni bilan |
| `http://127.0.0.1:8000/redoc` | **ReDoc** — o'qish uchun qulayroq, statik hujjat ko'rinishi |
| `http://127.0.0.1:8000/openapi.json` | Xom **OpenAPI sxemasi** (JSON formatida) — bu ikkala hujjat sahifasi ham shu sxema asosida avtomatik quriladi |

Swagger UI'da, har bir endpoint kengaytirilishi, so'rov parametrlari ko'rinishi, va **"Try it out"** tugmasi orqali, brauzerdan chiqmasdan, to'g'ridan-to'g'ri so'rov yuborib ko'rish mumkin.

> 📌 **Nima uchun bu muhim:** an'anaviy framework'larda (Flask, Express.js), API hujjatlarini qo'lda yozish va ularni kod bilan **sinxron holda saqlash** — doimiy muammo hisoblanadi (kod o'zgaradi, hujjat eskiradi). FastAPI'da hujjat — to'g'ridan-to'g'ri kodning o'zidan (type hint'lar, funksiya imzolaridan) avtomatik generatsiya qilinadi, shuning uchun u **hech qachon** kod bilan mos kelmasligi mumkin emas.

### `app.py` yoki `main.py` — fayl nomlash konvensiyasi

FastAPI loyihalarida, asosiy fayl odatda `main.py` deb nomlanadi (ba'zan `app.py`), ichida `app` nomli `FastAPI` obyekti bilan. Bu — `fastapi dev main.py` buyrug'i tomonidan avtomatik qidiriladigan standart nom.

### Status kodlar — birinchi tanishuv

Har bir HTTP javobi — **status kod** bilan birga keladi (masalan, `200 OK`, `404 Not Found`). FastAPI, standart holda, `GET` uchun `200`, yangi resurs yaratuvchi `POST` uchun ham odatda `200` (buni keyingi darsda `201`ga o'zgartirishni ko'ramiz) qaytaradi:

```python
from fastapi import FastAPI, status

app = FastAPI()

@app.post("/mahsulotlar", status_code=status.HTTP_201_CREATED)
def yangi_mahsulot():
    return {"xabar": "Mahsulot yaratildi"}
```

## Amaliy misol

To'liq, birinchi ilovani yaratish va sinash:

```bash
mkdir birinchi-api && cd birinchi-api
uv init
uv add "fastapi[standard]"
```

`main.py` fayli:

```python
from fastapi import FastAPI, status

app = FastAPI(title="Mening birinchi API'im", version="1.0.0")

@app.get("/")
def bosh_sahifa():
    return {"xabar": "API ishlayapti!"}

@app.get("/salom/{ism}")
def salomlashish(ism: str):
    return {"xabar": f"Salom, {ism}!"}

@app.get("/mahsulotlar")
def mahsulotlar_royxati():
    return {
        "mahsulotlar": [
            {"id": 1, "nomi": "Noutbuk"},
            {"id": 2, "nomi": "Sichqoncha"},
        ]
    }

@app.post("/mahsulotlar", status_code=status.HTTP_201_CREATED)
def yangi_mahsulot():
    return {"xabar": "Yangi mahsulot yaratildi"}
```

Ishga tushirish:

```bash
uv run fastapi dev main.py
```

Sinash (boshqa terminal oynasida, `curl` orqali):

```bash
curl http://127.0.0.1:8000/
# {"xabar":"API ishlayapti!"}

curl http://127.0.0.1:8000/salom/Shamsiddin
# {"xabar":"Salom, Shamsiddin!"}

curl -X POST http://127.0.0.1:8000/mahsulotlar
# {"xabar":"Yangi mahsulot yaratildi"}
```

Brauzerda `http://127.0.0.1:8000/docs` sahifasini ochib, barcha to'rtta endpoint'ning avtomatik yaratilgan, interaktiv hujjatini ko'rish mumkin — `title` va `version` parametrlari, hujjat sahifasining sarlavhasida ko'rinadi.

## Keng tarqalgan xatolar

**Xato 1:** `uvicorn main:app --reload` (eski, an'anaviy usul) va `fastapi dev main.py` (yangi, CLI usuli) buyruqlarini chalkashtirib, noto'g'ri sintaksis bilan xato olish.
❌ `uvicorn` buyrug'i — `modul_nomi:obyekt_nomi` formatini talab qiladi (masalan, `main:app`), `fastapi dev` esa shunchaki fayl yo'lini oladi (`main.py`).
✅ To'g'ri: yangi loyihalarda soddaligi uchun `fastapi dev main.py` ishlatilishi tavsiya etiladi; `uvicorn main:app --reload` — hali ham to'liq ishlaydi va ba'zi murakkab sozlashlarda (masalan, production'da, 7-bobda ko'riladi) alohida ishlatiladi.

**Xato 2:** funksiyadan Python obyektini (masalan, `dict` o'rniga maxsus klass namunasi) qaytarib, uni FastAPI JSON'ga aylantira olmasligidan xato olish.
❌ FastAPI — `dict`, `list`, Pydantic modellari va oddiy Python turlarini (str, int, va h.k.) avtomatik JSON'ga aylantiradi, lekin har qanday murakkab, maxsus klassni emas.
✅ To'g'ri: funksiyadan har doim `dict`, `list` yoki Pydantic modeli (keyingi darsda ko'riladi) qaytaring — bu, FastAPI'ning avtomatik serializatsiya qilishi uchun kerak.

**Xato 3:** `/docs` sahifasini ko'rmasdan, har bir endpoint'ni faqat `curl` yoki tashqi vositalar (Postman) orqali qo'lda sinab ko'rish.
❌ Bu — FastAPI'ning eng katta amaliy afzalligini (tezkor, brauzer ichidagi sinov) e'tiborsiz qoldirishga olib keladi, ayniqsa rivojlantirish jarayonida vaqtni behuda sarflaydi.
✅ To'g'ri: rivojlantirish paytida, har doim `/docs` sahifasini ochiq holda saqlang — u yerda har bir yangi endpoint darhol ko'rinadi va "Try it out" orqali bir necha soniyada sinab ko'rish mumkin.

## Mashq/topshiriq

**(Oson)** `uv init` va `uv add "fastapi[standard]"` orqali yangi loyiha yarating, ichida `/` manziliga GET so'rovi uchun, o'zingiz haqingizda ma'lumot qaytaruvchi (`ism`, `kasb` maydonlari bilan) endpoint yozing.

**(O'rtacha)** Ikkita qo'shimcha endpoint qo'shing: `GET /vaqt` (joriy vaqtni qaytaruvchi) va `POST /xabar` (`201 Created` status kodi bilan). `fastapi dev` orqali ishga tushirib, `/docs` sahifasida ikkalasini ham sinab ko'ring.

**(Qiyin)** `main.py`da 5 ta turli endpoint yarating (masalan, kichik "kutubxona" mavzusida: kitoblar ro'yxati, bitta kitobni ID orqali olish, yangi kitob qo'shish, va h.k.). `http://127.0.0.1:8000/openapi.json` manzilini brauzerda ochib, xom OpenAPI sxemasini ko'ring va u bilan `/docs` sahifasidagi Swagger UI orasidagi bog'liqlikni tushuntirib bering.

## Qisqacha xulosa

FastAPI ilovasi — `FastAPI()` obyektini yaratib, `@app.get()`, `@app.post()` kabi dekoratorlar orqali HTTP metodlariga mos funksiyalarni belgilashdan boshlanadi; ilova `fastapi dev main.py` buyrug'i orqali, avtomatik qayta yuklash (hot reload) bilan ishga tushiriladi. FastAPI'ning eng katta amaliy afzalligi — `/docs` (Swagger UI) va `/redoc` manzillarida, hech qanday qo'shimcha kod yozmasdan, to'liq interaktiv va har doim kod bilan sinxron API hujjatlarining avtomatik yaratilishi; bu hujjatlar, `/openapi.json`dagi xom OpenAPI sxemasi asosida quriladi. Keyingi darsda, path va query parametrlar orqali, endpoint'larga qanday dinamik ma'lumot uzatishni chuqurroq o'rganamiz.
