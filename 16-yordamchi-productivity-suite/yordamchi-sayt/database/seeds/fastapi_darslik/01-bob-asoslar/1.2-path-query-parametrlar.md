# Path va Query parametrlar

## Bu darsda nimalarni o'rganasiz

- Path (yo'l) parametrlari orqali dinamik URL'lar yaratasiz
- Query (so'rov) parametrlarini majburiy va ixtiyoriy tarzda qo'llashni o'rganasiz
- Type hint'lar orqali avtomatik validatsiya va tur o'girishni tushunasiz
- `Query`/`Path` funksiyalari orqali qo'shimcha validatsiya qoidalarini belgilaysiz

## Nazariy qism

### Path parametrlar — URL ichidagi dinamik qism

**Path parametr** — URL manzilining o'zida, jingalak qavslar ichida belgilanadigan qism:

```python
@app.get("/foydalanuvchilar/{foydalanuvchi_id}")
def foydalanuvchini_olish(foydalanuvchi_id: int):
    return {"foydalanuvchi_id": foydalanuvchi_id}
```

`/foydalanuvchilar/42` so'rovi yuborilsa, `foydalanuvchi_id` — avtomatik ravishda **butun son** (`42`, matn emas) sifatida funksiyaga uzatiladi.

### Avtomatik tur tekshiruvi — amalda

```bash
curl http://127.0.0.1:8000/foydalanuvchilar/42
# {"foydalanuvchi_id": 42}   - ishlaydi, 42 - butun son

curl http://127.0.0.1:8000/foydalanuvchilar/matn
# 422 Unprocessable Entity - "matn" butun songa aylantirilmaydi
```

Agar `foydalanuvchi_id: int` o'rniga mos kelmaydigan qiymat yuborilsa, FastAPI **avtomatik ravishda**, tushunarli xato xabari bilan (`422` status kod) so'rovni rad etadi — bu tekshiruvni qo'lda yozish shart emas.

### Bir nechta path parametr

```python
@app.get("/foydalanuvchilar/{foydalanuvchi_id}/buyurtmalar/{buyurtma_id}")
def buyurtmani_olish(foydalanuvchi_id: int, buyurtma_id: int):
    return {"foydalanuvchi_id": foydalanuvchi_id, "buyurtma_id": buyurtma_id}
```

### Path parametrlarni oldindan belgilangan qiymatlar bilan cheklash (`Enum`)

Agar path parametr faqat muayyan qiymatlardan birini qabul qilishi kerak bo'lsa, Python'ning `Enum` klassi ishlatiladi:

```python
from enum import Enum

class Turkum(str, Enum):
    elektronika = "elektronika"
    kiyim = "kiyim"
    kitob = "kitob"

@app.get("/turkumlar/{turkum}")
def turkum_boyicha(turkum: Turkum):
    return {"tanlangan_turkum": turkum}
```

Bu holda, Swagger UI'da avtomatik ravishda **tanlov ro'yxati** (dropdown) ko'rsatiladi, va noto'g'ri qiymat yuborilsa, `422` xatosi qaytariladi.

### Query parametrlar — URL'dan keyingi `?` qismi

**Query parametr** — funksiya imzosida, path'da ko'rsatilmagan har qanday oddiy parametr, avtomatik ravishda query parametr sifatida qabul qilinadi:

```python
@app.get("/mahsulotlar")
def mahsulotlar_royxati(sahifa: int = 1, hajmi: int = 10):
    return {"sahifa": sahifa, "hajmi": hajmi}
```

So'rov: `GET /mahsulotlar?sahifa=2&hajmi=20`

```json
{"sahifa": 2, "hajmi": 20}
```

Agar so'rovda query parametr ko'rsatilmasa, standart qiymat (`1`, `10`) ishlatiladi.

### Majburiy va ixtiyoriy query parametrlar

| Yozilishi | Ma'nosi |
|---|---|
| `hajmi: int` | **Majburiy** — agar so'rovda bo'lmasa, `422` xatosi |
| `hajmi: int = 10` | **Ixtiyoriy**, standart qiymat `10` |
| `hajmi: int \| None = None` | **Ixtiyoriy**, standart qiymati `None` (mavjud bo'lmasligi ham mumkin) |

```python
@app.get("/qidiruv")
def qidirish(matn: str, til: str | None = None):
    natija = {"qidiruv_matni": matn}
    if til:
        natija["til"] = til
    return natija
```

`matn` — majburiy (`GET /qidiruv?matn=python` kerak, aks holda xato), `til` — ixtiyoriy.

### `Query()` va `Path()` — qo'shimcha validatsiya

Oddiy standart qiymatlardan tashqari, FastAPI — qo'shimcha validatsiya qoidalarini (uzunlik, son chegaralari, tavsif) belgilash uchun maxsus `Query()` va `Path()` funksiyalarini taqdim etadi:

```python
from typing import Annotated
from fastapi import FastAPI, Query, Path

app = FastAPI()

@app.get("/mahsulotlar")
def mahsulotlar_royxati(
    qidiruv: Annotated[str | None, Query(max_length=50, description="Mahsulot nomi bo'yicha qidirish")] = None,
    sahifa: Annotated[int, Query(ge=1, description="Sahifa raqami, 1 dan boshlanadi")] = 1,
):
    return {"qidiruv": qidiruv, "sahifa": sahifa}

@app.get("/mahsulotlar/{mahsulot_id}")
def mahsulotni_olish(
    mahsulot_id: Annotated[int, Path(gt=0, description="Mahsulot ID'si, 0 dan katta bo'lishi kerak")]
):
    return {"mahsulot_id": mahsulot_id}
```

> 📌 **`Annotated` — zamonaviy, tavsiya etiladigan uslub:** yuqoridagi `Annotated[tur, Query(...)]` yozilishi — FastAPI'ning hozirgi rasmiy hujjatlarida **birinchi tavsiya etiladigan** uslub hisoblanadi (eski uslubda `parametr: str = Query(...)` ko'rinishida yozilar edi — bu hali ham ishlaydi, lekin `Annotated` afzalroq, chunki u type checker vositalari — masalan, `mypy` — bilan yaxshiroq ishlaydi).

### `Query`/`Path` validatsiya parametrlari

| Parametr | Vazifasi | Misol |
|---|---|---|
| `min_length`, `max_length` | Matn uzunligi chegarasi | `Query(min_length=3, max_length=50)` |
| `ge`, `le` | Son uchun "kattaroq yoki teng" / "kichikroq yoki teng" | `Query(ge=1, le=100)` |
| `gt`, `lt` | Son uchun "qat'iy kattaroq" / "qat'iy kichikroq" | `Path(gt=0)` |
| `pattern` | Regulyar ifoda (regex) bo'yicha tekshirish | `Query(pattern=r"^[a-z]+$")` |
| `description` | Hujjat sahifasida ko'rinadigan tavsif | `Query(description="...")` |

### Bir nomli query parametrni bir nechta marta qabul qilish (ro'yxat)

```python
from typing import Annotated
from fastapi import Query

@app.get("/mahsulotlar/filtr")
def filtrlash(teglar: Annotated[list[str] | None, Query()] = None):
    return {"teglar": teglar}
```

So'rov: `GET /mahsulotlar/filtr?teglar=arzon&teglar=yangi` → `{"teglar": ["arzon", "yangi"]}`

## Amaliy misol

To'liq, path va query parametrlarni birlashtiruvchi amaliy endpoint:

```python
from typing import Annotated
from enum import Enum
from fastapi import FastAPI, Query, Path

app = FastAPI()

class Saralash(str, Enum):
    narx_osish = "narx_osish"
    narx_kamayish = "narx_kamayish"
    nom_boyicha = "nom_boyicha"

MAHSULOTLAR = [
    {"id": 1, "nomi": "Noutbuk", "narx": 8500000, "turkum": "elektronika"},
    {"id": 2, "nomi": "Futbolka", "narx": 120000, "turkum": "kiyim"},
    {"id": 3, "nomi": "Sichqoncha", "narx": 250000, "turkum": "elektronika"},
]

@app.get("/turkumlar/{turkum}/mahsulotlar")
def turkum_mahsulotlari(
    turkum: Annotated[str, Path(description="Mahsulot turkumi, masalan: elektronika")],
    saralash: Annotated[Saralash | None, Query(description="Natijalarni saralash usuli")] = None,
    min_narx: Annotated[int | None, Query(ge=0, description="Minimal narx filtri")] = None,
):
    natijalar = [m for m in MAHSULOTLAR if m["turkum"] == turkum]

    if min_narx is not None:
        natijalar = [m for m in natijalar if m["narx"] >= min_narx]

    if saralash == Saralash.narx_osish:
        natijalar.sort(key=lambda m: m["narx"])
    elif saralash == Saralash.narx_kamayish:
        natijalar.sort(key=lambda m: m["narx"], reverse=True)
    elif saralash == Saralash.nom_boyicha:
        natijalar.sort(key=lambda m: m["nomi"])

    return {"turkum": turkum, "soni": len(natijalar), "mahsulotlar": natijalar}
```

Sinash:

```bash
curl "http://127.0.0.1:8000/turkumlar/elektronika/mahsulotlar?saralash=narx_kamayish&min_narx=200000"
```

Natija — faqat `elektronika` turkumidagi, narxi 200000 dan yuqori bo'lgan mahsulotlar, narx bo'yicha kamayish tartibida saralangan holda qaytariladi.

## Keng tarqalgan xatolar

**Xato 1:** query parametrni majburiy qilib qoldirib (standart qiymatsiz), lekin so'rovda uni har doim yubormaslikni kutish.
❌ `def f(hajmi: int)` — `hajmi` avtomatik ravishda **majburiy** hisoblanadi; agar so'rovda bo'lmasa, `422 Unprocessable Entity` xatosi qaytariladi.
✅ To'g'ri: ixtiyoriy query parametrlar uchun har doim standart qiymat belgilang (`hajmi: int = 10`) yoki `| None = None` bilan aniq ixtiyoriy ekanini bildiring.

**Xato 2:** path parametr nomini, `@app.get()` ichidagi jingalak qavs nomiga mos kelmaydigan holda yozish.
❌ `@app.get("/foydalanuvchilar/{id}")` deb yozib, funksiyada `def f(foydalanuvchi_id: int)` deb nomlash — FastAPI bu ikkisini bog'lay olmaydi va xato beradi (yoki `id` query parametr sifatida talab qilinadi).
✅ To'g'ri: jingalak qavs ichidagi nom (`{id}`) va funksiya parametrining nomi (`id: int`) **aynan bir xil** bo'lishi shart.

**Xato 3:** `Query()`/`Path()` funksiyalarini eski uslubda (standart qiymat sifatida to'g'ridan-to'g'ri), `Annotated`siz ishlatishda, standart qiymatni ikki marta (ham `Query()` ichida, ham tashqarida) yozib chalkashtirish.
❌ Masalan, `def f(x: int = Query(default=5, ge=0) = 10)` — bunday yozish sintaktik xato yoki chalkash xulq-atvorga olib keladi.
✅ To'g'ri: `Annotated` uslubidan foydalaning: `x: Annotated[int, Query(ge=0)] = 5` — standart qiymat faqat **bitta joyda**, `Annotated`dan tashqarida, `=` belgisidan keyin yoziladi.

## Mashq/topshiriq

**(Oson)** `/kitoblar/{kitob_id}` path parametrli endpoint yarating, `kitob_id` — butun son bo'lishi va `0`dan katta bo'lishi shart (`Path(gt=0)` orqali).

**(O'rtacha)** `/kitoblar` endpoint'iga ikkita ixtiyoriy query parametr qo'shing: `muallif` (matn, ixtiyoriy) va `nashr_yili` (butun son, `1450` dan `2026` gacha bo'lgan oraliqda, `Query(ge=1450, le=2026)` orqali).

**(Qiyin)** `Enum` klassidan foydalanib, `/buyurtmalar/{holat}` endpoint yarating (`holat` — `"kutilmoqda"`, `"yuborilgan"`, `"yetkazilgan"` qiymatlaridan birini qabul qilishi kerak). Qo'shimcha ravishda, `sahifa` (standart `1`, `ge=1`) va `hajmi` (standart `10`, `ge=1`, `le=100`) query parametrlarini `Annotated` uslubida qo'shing va noto'g'ri `holat` qiymati yuborilganda nima sodir bo'lishini tushuntiring.

## Qisqacha xulosa

Path parametrlar — URL manzilining o'zida (`{parametr}` ko'rinishida) belgilanib, odatda muayyan resursni (masalan, ID orqali) aniqlash uchun ishlatiladi, query parametrlar esa — `?kalit=qiymat` ko'rinishida, odatda filtrlash, saralash yoki sahifalash uchun ishlatiladi; ikkalasi ham, funksiya imzosidagi oddiy Python type hint'lari orqali, FastAPI tomonidan avtomatik aniqlanadi va validatsiya qilinadi. `Query()` va `Path()` funksiyalari (`Annotated` uslubida ishlatilganda) — uzunlik, son chegaralari va tavsif kabi qo'shimcha validatsiya qoidalarini qo'shish, hamda `Enum` klasslari esa — qiymatni oldindan belgilangan ro'yxat bilan cheklash imkonini beradi. Keyingi darsda, murakkabroq ma'lumotlarni (JSON request body) qabul qilish uchun Pydantic modellaridan qanday foydalanishni o'rganamiz.
